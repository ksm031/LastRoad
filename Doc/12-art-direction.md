# 12. 아트 디렉션

## 비주얼 스타일

**픽셀아트 + Pseudo 3D 빌보드 + 무채색화 시스템**

연옥의 도로를 픽셀아트로 재현한다. 고해상도 리얼리즘이 아니라, **저해상도 픽셀의 거칠함이 연옥의 황량함과 맞물리는 미학**을 추구한다. 정신력이 낮아질수록 세상의 색이 빠져나가고 붉은 것들만 남는다. 모든 오브젝트는 빌보드 방식으로 처리되어 항상 카메라를 향한다.

---

## 픽셀아트 규격

| 항목 | 값 | 비고 |
|------|-----|------|
| 기본 해상도 | 1280×720 | 720p 네이티브. 업스케일 없음 |
| 렌더링 방식 | 네이티브 720p | 스프라이트 자체의 픽셀 크기로 픽셀아트 느낌 구현 |
| 캐릭터 단위 크기 | 32×64px (기본 인물) | 거리에 따라 scale 조절 |
| 팔레트 제한 | 오브젝트당 최대 8색 | 야간 + VHS 특성상 어두운 색 위주 |
| 아웃라인 | 없음 | 실루엣이 어둠에 녹아들도록 |
| 텍스처 필터 | Nearest Neighbor | 픽셀 블러 없음 |

720p 네이티브 렌더링으로 스프라이트의 픽셀이 화면에 그대로 노출된다. 업스케일 없이도 스프라이트 자체의 픽셀 크기가 픽셀아트 느낌을 만든다. 정신력이 낮아질수록 무채색화가 심해지면서 픽셀 경계의 색 대비가 줄어들고, 붉은 것만 남아 더욱 또렷해진다.

---

## 빌보드 처리

모든 도로 위 오브젝트(컬트·사슴머리·폐차·장애물 등)는 빌보드 스프라이트로 처리된다. Pseudo 3D 공간에서 항상 카메라(플레이어 시점)를 향해 정면을 유지한다.

### 구현 방식 (Godot 2D)

```gdscript
# 빌보드: z_value에 따라 scale + y_pos 조정
# 항상 정면 스프라이트 하나만 사용. 회전 없음.
func update_billboard(z_value: float):
    var scale_factor = lerp(0.05, 1.0, z_value)
    var y_pos = lerp(HORIZON_Y, ROAD_BOTTOM, z_value)
    sprite.scale = Vector2(scale_factor, scale_factor)
    sprite.position.y = y_pos
    # 픽셀아트 업스케일 깨짐 방지
    sprite.texture_filter = CanvasItem.TEXTURE_FILTER_NEAREST
```

### 빌보드의 공포 효과

픽셀아트 빌보드는 멀리 있을 때 2~3픽셀짜리 덩어리로 보인다. "저게 사람인가?" 라는 판단을 플레이어가 직접 해야 한다. 가까워질수록 픽셀이 선명해지면서 형태가 드러나는 구조가 자연스러운 공포 점층을 만든다.

| 거리(z값) | 스프라이트 크기 | 식별 가능 여부 |
|---------|------------|------------|
| 0.05 (매우 먼) | 4~6px | 점. 사람인지 모름 |
| 0.2 | 12~16px | 윤곽. 서있는 것 같음 |
| 0.5 | 32px | 인물임을 인식 |
| 0.8 | 52px | 디테일 식별. 공포 시작 |
| 1.0 (바로 앞) | 64px+ | 클로즈업 |

## 무채색화 시스템 (정신력 시각화)

정신력이 낮아질수록 세상의 색이 빠져나간다. **붉은색(Hue 330°~30°)은 채도 감소에서 제외된다.**

세상이 회색으로 변해갈 때 붉은 것들만 점점 선명하게 부각된다.

| 정신력 | 채도 | 상태 |
|-------|------|------|
| 100~70 | 100% | 정상 |
| 70~50 | 100%→70% | 서서히 탈색. 의식하지 않으면 모름 |
| 50~30 | 70%→40% | 뚜렷한 탈색. 붉은색만 선명하게 남음 |
| 30~10 | 40%→15% | 거의 흑백. 붉은 것들이 강조되어 보임 |
| 10~0 | 15%→5% | 완전에 가까운 흑백. 붉은색 대비 극대화 |

픽셀아트와 무채색화의 조합: 채도가 낮아지면 픽셀 경계의 색 대비가 줄어들고 실루엣만 남는다. 정지 이미지보다 움직임이 있을 때 더 두드러진다.

> 시스템 상세 및 셰이더 구현은 [07-sanity-visuals.md](07-sanity-visuals.md) 참조.
