# 12. 아트 디렉션

## 비주얼 스타일

**픽셀아트 + Pseudo 3D 빌보드 + VHS 색수차**

레퍼런스 영상(새벽 국도 블랙박스)의 질감을 픽셀아트로 재현한다. 고해상도 리얼리즘이 아니라, **저해상도 픽셀이 VHS 글리치와 만나 더 무서워지는 미학**을 추구한다. 모든 오브젝트는 빌보드 방식으로 처리되어 항상 카메라를 향한다.

---

## 픽셀아트 규격

| 항목 | 값 | 비고 |
|------|-----|------|
| 기본 해상도 | 1280×720 | 720p 네이티브. 업스케일 없음 |
| 렌더링 방식 | 네이티브 720p | 스프라이트 자체의 픽셀 크기로 픽셀아트 느낌 구현 |
| 캐릭터 단위 크기 | 32×64px (기본 인물) | 거리에 따라 scale 조절 |
| 팔레트 제한 | 오브젝트당 최대 8색 | 야간 + VHS 특성상 어두운 색 위주 |
| 아웃라인 | 없음 | 실루엣이 어둠에 녹아들도록 |
| 텍스처 필터 | Nearest Neighbor | 픽셀 블러 없음 |

720p 네이티브 렌더링으로 스프라이트의 픽셀이 화면에 그대로 노출된다. 업스케일 없이도 스프라이트 자체의 픽셀 크기가 픽셀아트 느낌을 만든다. VHS 스캔라인·색수차가 픽셀 경계와 섞이면서 "테이프에 녹화된 것" 같은 질감이 생긴다.

---

## 빌보드 처리

모든 도로 위 오브젝트(컬트·사슴머리·폐차·장애물 등)는 빌보드 스프라이트로 처리된다. Pseudo 3D 공간에서 항상 카메라(플레이어 시점)를 향해 정면을 유지한다.

### 구현 방식 (Godot 2D)

```gdscript
# 빌보드: z_value에 따라 scale + y_pos 조정
# 항상 정면 스프라이트 하나만 사용. 회전 없음.
func update_billboard(z_value: float):
    var scale_factor = lerp(0.05, 1.0, z_value)
    var y_pos = lerp(HORIZON_Y, ROAD_BOTTOM, z_value)
    sprite.scale = Vector2(scale_factor, scale_factor)
    sprite.position.y = y_pos
    # 픽셀아트 업스케일 깨짐 방지
    sprite.texture_filter = CanvasItem.TEXTURE_FILTER_NEAREST
```

### 빌보드의 공포 효과

픽셀아트 빌보드는 멀리 있을 때 2~3픽셀짜리 덩어리로 보인다. "저게 사람인가?" 라는 판단을 플레이어가 직접 해야 한다. 가까워질수록 픽셀이 선명해지면서 형태가 드러나는 구조가 자연스러운 공포 점층을 만든다.

| 거리(z값) | 스프라이트 크기 | 식별 가능 여부 |
|---------|------------|------------|
| 0.05 (매우 먼) | 4~6px | 점. 사람인지 모름 |
| 0.2 | 12~16px | 윤곽. 서있는 것 같음 |
| 0.5 | 32px | 인물임을 인식 |
| 0.8 | 52px | 디테일 식별. 공포 시작 |
| 1.0 (바로 앞) | 64px+ | 클로즈업 |

## 색수차 (Chromatic Aberration) 시스템

색수차는 VHS 연출의 핵심 레이어다. 기존 GDD의 "정신력 50 이하 시 시작"에서 **항상 존재하되 강도가 변하는 방식**으로 재설계한다.

### 기본 적용 (항상)

```
R 채널: +2px 우측 오프셋
G 채널: 기준
B 채널: +2px 좌측 오프셋
강도: 0.3 (미세하게 존재. 의식하지 않으면 모름)
```

픽셀아트와 색수차의 조합: 픽셀 경계선이 RGB로 분리되면서 "진짜 테이프" 질감이 강화된다. 정지 이미지보다 움직임이 있을 때 더 두드러진다.

### 상태별 강도 변화

| 상태 | 색수차 강도 | R/B 오프셋 | 추가 효과 |
|------|-----------|----------|---------|
| 기본 (항상) | 0.3 | ±2px | — |
| 정신력 70 이하 | 0.6 | ±4px | 오프셋 미세 진동 |
| 정신력 50 이하 | 1.2 | ±8px | 수직 색 분리 시작 |
| 정신력 30 이하 | 2.0 | ±14px | 프레임마다 오프셋 랜덤 변동 |
| 정신력 10 이하 | 3.5 | ±22px | R/G/B 각각 독립 진동. 화면 식별 한계 |
| 괴물 임박 단계 | +1.0 추가 | 정신력 강도에 누적 | 오프셋 방향이 불규칙해짐 |
| 충돌 순간 | 순간 5.0 | ±30px, 0.2초 | 충격 피드백 |

### Godot 셰이더 구현 개요

```glsl
// 색수차 셰이더 (스크린 포스트프로세싱)
uniform float aberration_strength = 0.3;
uniform vec2 r_offset = vec2(0.002, 0.0);
uniform vec2 b_offset = vec2(-0.002, 0.0);

void fragment() {
    float r = texture(SCREEN_TEXTURE, UV + r_offset * aberration_strength).r;
    float g = texture(SCREEN_TEXTURE, UV).g;
    float b = texture(SCREEN_TEXTURE, UV + b_offset * aberration_strength).b;
    COLOR = vec4(r, g, b, 1.0);
}
```

## 안티 레퍼런스 (이것은 아닙니다)

- 고해상도 스무딩 픽셀아트 (Linear 필터)
- 밝고 선명한 색감
- 캐릭터의 얼굴·표정이 보임
- 명확한 몬스터 디자인
- 색수차 없는 깨끗한 화면
