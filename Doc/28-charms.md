# 28. 부적 (Charms) 시스템

**목적**: 매 런마다 다른 빌드를 구축할 수 있는 핵심 시스템. 단순 수치 버프가 아닌 **조건부 효과 + 부적 간 시너지**를 통해 의미 있는 선택을 만든다. 영구 강화(파츠 업그레이드, 메타 퍽)는 안정적인 진행 곡선을 담당하고, 부적은 매 런의 정체성을 담당한다.

---

## 기본 원칙

- **런 단위**: 부적은 런이 끝나면 모두 소멸한다. 다음 런은 빈 슬롯에서 시작.
- **슬롯 6개**: 차량 내부에 시각적으로 배치된다 (백미러·대시보드·송풍구·조수석 등).
- **인벤 보관 불가**: 트렁크에 넣을 수 없음. 슬롯에 장착되어 있거나, 소멸한 것이거나 둘 중 하나.
- **6개 초과 시 교체 UI**: 7번째 부적 획득 시 즉시 팝업. 기존 1개 파기 또는 신규 포기.
- **교체 시점**: 정비 구간에서만 자유 교체. 주행 중에는 새 부적 획득 시 즉시 결정만 가능.
- **트레이드오프 우선**: 대부분의 부적은 버프와 페널티를 함께 가진다. 일방적인 업그레이드는 최소화.

---

## 시너지 메커닉 (5종)

부적 간 상호작용은 다섯 가지 방식으로 일어난다. 플레이어는 32종 중 6개를 골라 이 다섯 축 위에서 빌드를 만든다.

### 1. 태그 스택 (Tag Stack)
같은 태그를 공유하는 부적이 N개 이상 장착되면 효과가 강화되거나 패널티가 약해진다.

> 예: `SPEED` 태그 부적 3개 이상 장착 시 "부서진 속도계"의 라디오 조작 불가 패널티 무효.

### 2. 시너지 페어 (Duo)
특정 두 부적을 동시에 장착하면 숨겨진 보너스 효과가 발동한다. Hades의 듀오 보온과 동일한 구조. 본 문서 하단에 듀오 목록 명시.

> 예: `흔들리는 강아지 인형` + `아드레날린 주사기` → 충돌 시 정신력 +10 추가 회복.

### 3. 연쇄 트리거 (Chain Trigger)
부적 A의 발동 조건이 부적 B의 효과 트리거가 된다. 자동 연쇄 콤보.

> 예: `마모된 브레이크 패드`의 가속 게이지 만렙 도달 시 → `타버린 클러치`의 연료 임계점 -5% 추가 적용.

### 4. 상호 보완 (Complementary)
한 부적의 페널티를 다른 부적이 무효화하거나 자원으로 전환한다.

> 예: `거꾸로 달린 부적` 장착 시 다른 모든 부적의 페널티 -50% (보너스도 -25%).

### 5. 안티 시너지 (Anti-synergy)
어떤 두 부적은 상호 효과를 약화시킨다. 의도적 설계로 무지성 스택을 막는다.

> 예: `무거운 추` + `부서진 속도계` 동시 장착 시 두 효과 모두 -50%.

## 태그 시스템

각 부적은 1~3개의 태그를 가진다. 태그가 빌드 정체성과 시너지의 매개체다.

| 태그 | 의미 | 대표 빌드 |
|------|------|---------|
| `SPEED` | 속도·가속·고속 보상 | 스피드광 |
| `SCAVENGE` | 수색·경제·자원 획득 | 하이에나 |
| `SANITY` | 정신력 관리·환각·라디오 | 어둠의 적응 |
| `DURABILITY` | 차체 내구·충돌 방어 | 생존형 |
| `RISK` | 의도적 위험 감수 | 위험 빌드 |
| `LUCK` | 확률·뽑기 | 운빨형 |
| `DEATH` | 게임오버·종말 시점 발동 | 절체절명형 |

## 시너지 페어 (Duo) 목록

특정 부적 2개를 동시 장착했을 때 발동하는 숨겨진 효과. 플레이어는 우연히 발견하거나, 이 문서를 참조해 의도적으로 조합한다.

| 페어 | 보너스 효과 |
|------|----------|
| 흔들리는 강아지 인형 + 아드레날린 주사기 | 충돌 시 정신력 +10 추가 회복 |
| 부서진 속도계 + 타버린 클러치 | 연료 30% 미만 시 최고속도 보너스 +20% → +35% |
| 마모된 브레이크 패드 + 낡은 나침반 | 가속 게이지 만렙 도달 시 커브 안정성 +100% (그 게이지 유지 중) |
| 피 묻은 동전 + 안전운전 부적 | 5개 부품 모두 100% 유지 시 괴물 접근 속도 보너스가 패널티 상쇄 (실질 ±0) |
| 자석 고양이 + 카니발 입장권 | 빈 칸 발견 확률 효과 발동 시 다음 폐차 거리 -30% 추가 발동 |
| 수상한 영수증 묶음 + 황금 톱니바퀴 | 정비소 거래 시 잡품 판매가 추가 +25% |
| 기괴한 안테나 + 일그러진 룸미러 | 점퍼 제거 성공 시 죽음의 주파수가 안전 주파수로 1회 강제 전환 |
| 눈먼 부엉이 조각 + 피우다 만 담배꽁초 | 헤드라이트 끈 채 담배 사용 시 60초 회복량 두 배 (+80) |
| 찢어진 사진 + 빈 약통 | 정신력 20 이하 시 환각이 보이지 않음 + 연료 소모 -30% 동시 발동 |
| 무거운 추 + 두꺼운 타이어 패치 | 타이어 손상 시 내구도 감소량 -25% (즉, 같은 충돌에도 펑크에 도달하기 더 어려워짐) |
| 단단한 더미 인형 + 금속 십자가 | 더미 인형 발동 후 게임오버 직전이면 십자가도 즉시 자동 발동 |
| 묶인 손목시계 + 녹슨 면도날 | 정차 시간이 길수록 면도날의 ₩500 확률 +1%씩 누적 (최대 50%) |
| 역풍의 부적 + 무거운 추 | 창 명중 후 관성 주행 시간 6초 → 10초 (감속 -50% 효과로 운동에너지 더 오래 보존) |
| 역풍의 부적 + 거꾸로 달린 부적 | 관성 무동력 시간 6초 → 3초 (페널티 절반) + 400km/h 가속 보너스 -25% 적용 안 함 (예외 처리) |

## 안티 시너지 페어 목록

의도적으로 충돌하는 페어. 두 부적을 함께 장착하면 양쪽 효과가 약화된다.

| 페어 | 결과 |
|------|------|
| 무거운 추 + 부서진 속도계 | 양쪽 효과 -50% (속도 트레이드오프 자체가 무의미해짐) |
| 눈먼 부엉이 조각 + 낡은 와이퍼 모터 | 헤드라이트 끄면 와이퍼 야광 효과 무효 (시각 정보가 대립) |
| 구멍 난 양철통 + 마모된 브레이크 패드 | 가속을 멈춰야 하는 부적과 멈추면 안 되는 부적의 충돌. 둘 다 효과 -30% |
| 역풍의 부적 + 일그러진 룸미러 | 일그러진 룸미러의 자동 회피 보조로 창을 너무 잘 피하게 되어 역풍 부적 트리거 빈도 -70% (사실상 잠자는 부적) |

| **갓길 폐차 수색** | 폐차 1대당 약 3% 확률 | 잡품 풀 안에 1슬롯 점유 |
| **정비 구간 상점** | 스테이지당 2개 진열 (랜덤) | 8~20 BO (등급별) |
| **녹슨 슬롯머신** | 정비 구간 고정 1대 | 1회 ₩3,000 (현금). 70% 무작위 부적, 30% 꽝 (₩500 환급) |
| **진엔딩 퍽 보너스** | 런 시작 시 1회 지급 | 메타 퍽 '잠긴 칸' 활성화 시 무작위 1개 |

### 슬롯머신 — 도박꾼 NPC 대체

수상한 도박꾼 NPC 대신, 정비 구간 구석에 **녹슨 슬롯머신** 1대가 고정 배치된다. 누가 갖다 놓았는지 설명하지 않는다. 손잡이를 당기면 회전 후 부적 1개를 토해내거나, 동전 한 닢을 게워낸다. 슬롯머신은 말하지 않는다.

- 한 정비 구간에서 슬롯머신 사용 가능 횟수: 무제한 (₩만 있다면)
- **슬롯머신은 현금(₩)으로만 작동**. 블러드 오브 사용 불가
- 1회 비용: ₩3,000
- 70% 성공: 무작위 부적 1개
- 30% 꽝: ₩500 환급
- 같은 부적 중복 획득 시 즉시 ₩2,500 환급 후 사라짐 (중복 무의미)
- 32종 부적 풀에서 균등 추첨 (가중치 없음)

## 등급 / 가격

부적은 효과 강도가 아닌 **시너지 잠재력**으로 분류되지 않는다. 모두 동일 등급으로 취급한다. 다만 상점 가격은 다음 기준으로 산출:

| 가격대 | 기준 | BO 가격 |
|-------|------|--------|
| 8 BO | 단일 효과, 트레이드오프 약함 | 낡은 와이퍼 모터, 카니발 입장권 |
| 12 BO | 강한 효과 + 명확한 페널티 | 부서진 속도계, 피 묻은 동전 |
| 18 BO | 시너지 의존도 높음 (스택 효과) | 흔들리는 강아지 인형, 거꾸로 달린 부적 |
| 20 BO | 위험 빌드 핵심 / `DEATH` 태그 | 금속 십자가, 시계 반대방향 인형 |

폐차·슬롯머신에서는 등급과 무관하게 균등 추첨. 슬롯머신은 **현금(₩)으로만** 작동 — 블러드 오브 사용 불가.

## UX 피드백 (조건의 가시화)

이 게임은 HUD에 수치를 표시하지 않는다. 따라서 조건부 부적의 발동 상태를 알리는 별도 시각 언어가 필요하다.

| 상태 | 부적 시각 표현 |
|------|-------------|
| 조건 미충족 | 부적이 정적 상태로 매달려 있음 |
| 조건 충족 (효과 발동 중) | 부적이 살짝 흔들리거나, 미세한 빛/색이 부적 주변에 펄스 |
| 게이지 누적 중 (예: 마모된 브레이크 패드) | 부적에 점진적으로 빛이 차오름 |
| 효과 발동 순간 (예: 단단한 더미 인형) | 부적이 짧게 빛난 뒤 색이 빠짐 (이번 스테이지에서 소진) |
| 듀오 시너지 활성 | 페어 부적 둘이 같은 색 펄스로 동기화 |

정확한 수치는 표시하지 않지만, **"지금 효과가 작동 중인가"는 항상 알 수 있도록** 한다. 이것이 부적 시스템 디자인의 절대 규칙.

## 빌드 예시

### 빌드 A — "고속 자가치유"
`흔들리는 강아지 인형 + 부서진 속도계 + 마모된 브레이크 패드 + 낡은 나침반 + 아드레날린 주사기 + 안전운전 부적`

`SPEED` 4개 → 부서진 속도계의 라디오 패널티 무효. 80% 속도 유지하면서 정신력 +2.2/초 회복. 충돌해도 속도 안 죽고, 5개 부품 모두 100% 유지하면 적이 천천히 옴.

### 빌드 B — "정신력 마조히스트"
`찢어진 사진 + 빈 약통 + 눈먼 부엉이 조각 + 피우다 만 담배꽁초 + 기괴한 안테나 + 금이 간 손거울`

정신력 20 이하 진입을 의도적으로 유지하는 빌드. 환각이 안 보이고, 연료 효율 +30%, 헤드라이트 끄면 정신력 보존, 환각 충돌 시 정신력 회복. 듀오 시너지 (찢어진 사진 + 빈 약통) 자동 발동.

### 빌드 C — "위험 외줄타기"
`거꾸로 달린 부적 + 무거운 추 + 부서진 속도계 + 피 묻은 동전 + 금속 십자가 + 시계 반대방향 인형`

페널티 -50% (거꾸로 달린 부적) → 무거운 추와 부서진 속도계의 안티시너지조차 약해짐. 빠르게 달리면서 위험하게 파밍. 마지막 보험 두 장으로 죽기 직전까지 버틴다.

## roguelite.md 원칙과의 정합성

본 시스템은 `roguelite.md`의 다음 원칙을 따른다.

- **입력 무작위성 우선**: 부적 효과는 거의 모두 "조건 → 효과" 결정론. 출력 RNG (도박사의 주사위 식) 제거.
- **시너지 천장 들어 올리기**: 듀오·스택·연쇄 트리거로 빌드 정점이 명확하게 폭발.
- **직교 축 5개**: 5개 빌드 카테고리가 서로 간섭 없이 결합 가능.
- **선택 가능한 무작위성**: 슬롯머신은 옵션, 상점은 2개 진열에서 선택, 폐차는 거부 가능.
- **가장 약한 빌드 보장**: 어떤 6개 조합이어도 최소 1~2개 시너지 가능. 완전 망한 빌드 없음.
- **천장과 바닥 모두 관리**: 등급별 가격으로 천장 빌드 진입에 의도적 마찰 부여.
