# 22. 진엔딩 시스템

**목적**: 메타 진행 완주 보상으로 게임의 진실에 접근할 수 있는 별도 분기를 제공한다. 트렁크 인벤토리라는 게임플레이 핵심 시스템과 결합해 "발견하는 행위"와 "처리하는 선택"이 모두 메커닉으로 표현된다.

> 진엔딩 시스템은 메타 진행 잠금 해제 전까지는 존재 자체가 노출되지 않는다. 첫 런부터 일반 플레이에는 영향이 없다.

---

## 활성화 조건

`21-meta-progression.md`의 4브랜치 × 5퍽 = **모든 20퍽 해금 시** 스킬 트리에 21번째 노드 **잠긴 칸(Locked Slot)** 이 별도 위치에 자동 등장한다.

| 항목 | 값 |
|------|-----|
| 해금 조건 | 메타 퍽 20개 전부 해금 |
| 가격 | 0pt (조건 충족 시 자유 활성화) |
| 위치 | 메인 메뉴 스킬 트리. 4브랜치와 분리된 별도 노드 |
| 효과 | 트렁크 숨겨진 1칸 해제 → 다음 런부터 시체 발견 |

활성화 후엔 영구히 적용되며 비활성화할 수 없다.

---

## 시체 발견 — 컷신 1회

잠긴 칸 활성화 후 **다음 런의 첫 정차 시점**에 컷신이 1회 재생된다.

```
[정차 직후 인벤토리 진입]
1. 트렁크 그리드의 우측 하단 1칸이 자동으로 페이드인
   → 그 칸에 검은 비닐로 감싼 형체가 들어 있음
2. VHS 효과 일시 해제: 색수차 0.0 / 글리치 0 (0.7초 단 한 번)
3. 운전자 혼잣말: (3초 침묵) "...이거 뭐야."
4. 짧은 화면 글리치 → 평소 VHS 강도로 복귀
5. 룸미러 얼굴이 강제로 공포 표정으로 1.5초 전환 후 정상 흐름 복귀
```

컷신은 **첫 1회만** 재생된다. 이후 모든 런에서 시체는 트렁크에 이미 존재한 상태로 시작한다.

---

## 트렁크 점유

| 항목 | 값 |
|------|-----|
| 점유 칸 수 | 1칸 (영구) |
| 위치 | 우측 하단 고정 슬롯 |
| 메타 퍽과의 관계 | "큰 트렁크 +1" 등으로 트렁크가 확장되어도 시체 슬롯은 별도 1칸 점유 유지 |
| 표시 | 검은 비닐 픽셀 아이콘. 클릭 시 "..." 텍스트만 표시. 자세한 정보 없음 |

기본 20칸 → effective 19칸. **죄를 짊어지고 달리는 게임플레이 비용**으로 표현.

---

## 시체 처리 액션

매 런마다 시체를 어떻게 다루느냐에 따라 그 런의 엔딩이 결정된다. 처리 방법은 두 가지이며, 둘 다 **A 엔딩(유기)** 으로 이어진다.

| 행동 | 트리거 | 결과 |
|------|--------|------|
| **인벤 버리기 영역에 드롭** | 주행 중 또는 정차 중 트렁크 열기 → 시체 슬롯 드래그 → 하단 버리기 영역 | 시체 즉시 사라짐. A 분기 확정 |
| **정비 구간 상점에 판매** | 정비 구간 잡품 판매 메뉴에서 시체 선택 → 판매 | ₩0 수령. 상인은 아무 말도, 표정 변화도 없음. A 분기 확정 |
| **처리하지 않음** | — | 6스테이지 끝까지 안고 감 → B 분기 진입 |

> 상점 판매 시 ₩0이라는 것이 중요한 단서다. 시체에 가격을 매기지 않는 게 아니라, **상인이 가격을 매길 수 없는 무언가**라는 암시.

처리한 그 런만 A 엔딩으로 분기. 시체는 다음 런 시작 시 트렁크에 다시 존재한다 (잠긴 칸은 영구 활성).

---

## 엔딩 분기

| 엔딩 | 조건 | 비고 |
|------|------|------|
| **A — 유기 엔딩** | 6스테이지 도착 시 트렁크에 시체 없음 | 진엔딩 퍽 해금 후만 활성 |
| **B — 진엔딩 (인정)** | 6스테이지 사슴머리 정면 통과 + 시체 보유 | 진엔딩 퍽 해금 후만 활성 |
| **E — 따라잡힘** | 괴물에게 따라잡힘 (룸미러 밖으로 넘침) | 모든 런에서 가능. [08-monster-chase.md](08-monster-chase.md) 참조 |

진엔딩 퍽 해금 **전**에는 6스테이지 클리어 시 일반 종료 화면(루프 지속을 암시하는 페이드아웃 + 출발지 깜빡 컷)이 표시된다. 분기 없음.

### A — 유기 엔딩

```
6스테이지 끝 사슴머리 통과 (시체 없음)
  → 화면 일반 페이드아웃
  → 시동음 한 번 들림
  → 출발지 화면으로 깜빡 전환
  → "다음 런으로" 알림 없이 곧바로 메인 메뉴
운전자 혼잣말 (다음 런 시작 시):
  "...버렸구나. 그래도 되는 건가."
라디오 죽음의 주파수 텍스트 변화 (다음 런부터):
  → 자기 이름 호명 빈도 증가
  → 한국어 명료한 부분이 한 단어씩 늘어남
```

A 엔딩은 **반복적**이다. 다시 시작되며 시체는 트렁크에 또 등장한다. 의미: *부정·도주.*

### B — 진엔딩 (인정)

```
6스테이지 끝 사슴머리 정면 통과 (시체 보유)
  → 통과 순간 단 한 번 일어나는 일:
     · VHS 효과 0.0 (색수차 / 글리치 / 그레인 전부 일시 정지)
     · 라디오 죽음의 주파수에서 자기 이름이 명료하게 호명됨 (단 1회)
     · 화면이 처음으로 또렷해짐 (0.7초)
  → 차량 자동 정지. 엔진 끊김
  → 타임코드 02:47:33이 처음으로 흐르기 시작
     · 02:47:34 → 35 → 36...
     · VHS 그대로 복귀하나 색수차는 영구 0.0
  → 차량 외부로 카메라 이동 (게임 최초의 외부 시점)
  → 27번 국도 표지판. 새벽 안개. 차량은 갓길에 정지
  → 검은 화면
  → 라디오 일반 주파수 1곡(새벽 발라드)이 끝까지 재생됨
  → 크레딧
```

B 엔딩은 **루프를 종료**한다. 다음 런 시작 시 메인 메뉴 배경이 변경됨 (영구 변경). 의미: *수용·해방.*

> 능동적인 행동(시체 처리)이 A로 이어지고, 아무것도 하지 않는 것이 B로 이어지는 구조. **진실을 마주하기 위해 필요한 건 외면하지 않는 것뿐**이라는 메시지.

## 단서 조합 시스템

시체의 정체, "내가 죽였는가" 여부는 **확정하지 않는다**. 다음 단서들이 흩뿌려져 있으며, 플레이어가 조합해 추리한다. 어떤 해석도 강제되지 않는다.

| 카테고리 | 단서 | 해석 가능 방향 |
|---------|------|-------------|
| 라디오 일반 주파수 | "27번 국도 일대 실종 신고 이번 달만 **네 건**" (퍽 해금 후 숫자 +1) | 자신을 포함한 숫자? |
| 라디오 죽음의 주파수 | 자기 이름 호명. 점차 명료 | 자기를 부르는 것 |
| 컬트 행동 | 일부 컬트가 손가락으로 트렁크 방향을 가리킴 (퍽 해금 후) | 시체를 알고 있음 |
| 사슴머리 응시 | 6스테이지 사슴머리가 차량 안의 시체를 정면 응시 (시체 보유 시 한정) | 사슴머리는 시체를 안다 |
| 시체 외형 | 검은 비닐. 얼굴 식별 불가. 인벤 클릭 시 "..." | 자기 자신일 수도, 타인일 수도 |
| 거점 거울 | 정비 구간 거울에 시체와 같은 옷을 입은 자기 모습이 반사 | 자기 시체? |
| 운전자 혼잣말 | 발견 직후 "이거 누구야?" → 5번째 런 즈음 "이거... 나야?" → 10번째 런 즈음 침묵 | 점진적 자각 |
| 사슴머리 정체 | 통과할 때 뿔이 가장 마지막에 보인다 ([03-driving.md](03-driving.md)) | 심판자? 자기 자신의 다른 형태? |

> 두 가지 핵심 해석이 모두 가능하도록 설계: **(a) 주인공이 누군가를 죽이고 도주 중 사고로 죽음** / **(b) 주인공 본인이 사고 시신이며 트렁크의 시체는 자기 자신**. 어느 쪽이 진실인지 게임은 답하지 않는다.

## 라디오 텍스트 변화 (퍽 해금 전후)

```
[퍽 해금 전 — 일반 주파수]
"27번 국도 일대 실종 신고가 이번 달만 세 건..."

[퍽 해금 후 — 일반 주파수]
"27번 국도 일대 실종 신고가 이번 달만 네 건..."

[퍽 해금 전 — 죽음의 주파수]
(이름 같은 소리. 불명확)

[퍽 해금 후 — 죽음의 주파수, 1차]
(이름 같은 소리. 단 한 음절만 또렷)

[퍽 해금 후 — 죽음의 주파수, A 엔딩 후 다음 런]
(이름 같은 소리. 두 음절 또렷)

[퍽 해금 후 — 죽음의 주파수, B 엔딩 진입 순간]
[자기 이름 풀네임 명료하게 호명 — 단 1회]
```

A 엔딩을 반복할수록 라디오가 점점 분명해지지만 도로는 끝나지 않는다. **반복이 진실을 데려오지만, 진실을 외면하면 반복은 끝나지 않는다.**
