# 29. 도로의 먹잇감 (Roadside Prey)

**목적**: 회피 게임을 사냥 게임으로 만든다. 단, 일반적인 "픽업 오브젝트"가 아니라 **이 게임만의 시그니처 메커닉**과 결합한 능동 행위로 설계한다.

---

## 핵심 컨셉 — 사냥당하는 자가 사냥한다

이 게임의 정체성:
- 트렁크에 시체를 싣고 달리는 남자
- 뒤에서 괴물이 항상 따라옴
- 룸미러가 핵심 UI
- 조수석 환영
- 죽음의 주파수 라디오

본 시스템은 위 다섯 가지를 **모두** 게임플레이에 끌어들인다. 평범한 콜렉터블이 아니라, 이 게임에서만 작동하는 구조.

### 디자인 원칙

1. **모든 사냥은 다른 시스템과 엮인다**: 보닛·트렁크·룸미러·조수석·라디오 중 최소 하나와 직결.
2. **수동 회수가 아닌 능동 던지기**: 잡은 것을 들고 다니다가 적절한 순간에 풀어준다.
3. **죄의 거울 구조**: 트렁크의 그녀 ↔ 보닛 위의 시체. 숨긴 죄 ↔ 드러난 죄.

---

## 중심 메커닉: 보닛 위의 시체 (Corpse on Hood)

**모든 사냥의 결과물은 보닛 위에 쌓인다.** 트렁크가 아니다. 차의 앞부분, 운전자가 항상 보는 자리.

### 동작

| 상태 | 효과 |
|------|------|
| 보닛 비어있음 | 시야 정상 |
| 보닛 위 시체 1구 | 앞유리 하단 ~20% 가림. 정신력 -1/5초 (인간 시체 한정) |
| 새 시체 충돌 | 기존 시체 자동 이탈 (도로에 떨어짐, 그냥 사라짐) |

### 처리 — 던지기 (Release)

**G키**로 보닛 시체를 후방으로 던진다.

```
G키 입력
  → 차량 후방으로 시체가 떨어짐
  → 괴물이 시체를 발견하고 멈춰서 먹기 시작
  → 괴물 추격 일시 정지 (시체 등급별 시간)
  → 먹는 동안 시야에서 사라짐 → 룸미러에 안 보임
```

### 시체 등급별 미끼 효과

| 시체 종류 | 괴물 정지 시간 | 정신력 비용 (들고 다니는 동안) |
|---------|------------|---------------------------|
| 작은 짐승 (두꺼비·뱀·너구리) | 3초 | 0 |
| 중형 짐승 (들개·여우) | 6초 | 0 |
| 큰 짐승 (사슴) | 10초 | -0.5/5초 |
| 컬트 행렬원 | 15초 | -2/5초 |
| 봉헌물 (특수 — 행렬 우두머리에게서) | 25초 | -4/5초. 죽음의 주파수 일시 무효 |

### 의도

플레이어는 매 순간 결정한다:
- "지금 던질까?" — 괴물이 너무 가까울 때 던져야 한다
- "더 큰 걸 잡아서 바꿀까?" — 작은 걸 들고 다니면 큰 게 나올 때 손해
- "이걸 들고 다닐 정신력이 되나?" — 인간 시체는 코스트가 있음

**트렁크의 그녀를 들고 다니는 메인 서사가 게임플레이로 거울처럼 반사된다.** 보닛 위에 시체 한 구가 항상 있는 상태가 디폴트가 되도록 설계.

### 조수석 환영 반응

조수석에 그녀의 환영이 나와있는 상태(정신력 30 이하)에서 인간 시체를 보닛에 올리면, **그녀가 그쪽을 바라본다.** 평소엔 앞만 보던 환영이 고개를 옆으로 살짝 돌린다. 던지면 다시 앞을 본다. 게임은 설명하지 않는다.

## 사냥 대상 5종

### 1. 도로의 짐승 (Wildlife)

평범한 야생 동물. 작은 미끼 공급원.

| 동물 | 등급 | 잡품 자동 입고 |
|------|------|------------|
| 두꺼비·뱀 | 작은 짐승 | 약초 ₩300 |
| 너구리 | 작은 짐승 | 모피 조각 ₩1,500 |
| 들개 | 중형 짐승 | 가죽 조각 ₩2,500 |
| 여우 | 중형 짐승 | 모피 ₩4,000 |
| 사슴 | 큰 짐승 | 큰 모피 ₩8,000 |

> 잡품은 트렁크로 자동, 시체 자체는 보닛에 올라간다. 동시 처리.

연출: 충돌 순간 붉은 피만 또렷이 보존(무채색화). 보닛 위에 사체 실루엣이 픽셀로 누워 있음.

---

### 2. 광신도 행렬 (Cult Procession)

도로를 가로지르는 컬트 행렬. 외줄 한 줄로 천천히 걸어간다. **이 게임의 시그니처 사냥 이벤트.**

#### 구조

```
도로 좌측 갓길 ━━━ ▽ ━━━ ▽ ━━━ ▽ ━━━ ▽ ━━━ ▽ ━━━ ▣ ━━━ 도로 우측 갓길
                후미   후미   후미   후미   후미   우두머리
                                                 (봉헌물 들고 있음)
```

- 후드 쓴 컬트 5~6명이 한 줄로 걷는다
- 가장 앞에 있는 **우두머리**가 무언가를 안고 있다 (검은 비닐 묶음 — 형체는 작다)
- 행렬 속도 1 m/s. 도로 횡단에 약 4초 소요
- 차량은 이 구간을 약 0.5초 만에 통과

#### 플레이어 선택

| 행동 | 결과 |
|------|------|
| **회피** (속도 유지하며 빈 공간 통과) | 아무 일 없음. 정신력 -2 (그들이 노려본다) |
| **후미만 치고 통과** | 후미 1~2명 보닛으로. 정신력 -10. 컬트 분노 30초 |
| **전 행렬 관통** | 전원 흩어짐. 보닛에 한 명만 남음. 정신력 -25. 컬트 분노 60초 |
| **우두머리만 정확히 치기** | 봉헌물이 보닛에 올라감. 정신력 -15. 컬트 분노 90초 |

#### 봉헌물 (Offering)

우두머리가 안고 있던 검은 비닐 묶음. 보닛에 올라간다.

- **던지면**: 괴물 25초간 정지 + 죽음의 주파수 일시 무효
- **던지지 않고 6스테이지 도착 시**: 정비 구간 상점에서 ₩20,000에 팔린다. 상인은 받지 않으려다가 마지못해 받는다. 가격은 묻지 않는다.
- **내용물**: 게임은 끝까지 보여주지 않는다

#### 시각 연출

행렬 등장 시:
- 죽음의 주파수가 미세하게 점유 시도 (지직)
- 차량이 접근할수록 컬트가 한 명씩 고개를 돌려 차를 본다 (도미노)
- 우두머리는 끝까지 정면을 본다 (자신의 길을 간다)

---

### 3. 히치하이커 (Hitchhiker)

도로 갓길에 사람이 서 있다. 엄지를 들고 있다. 조수석을 비워둔 채 달리던 남자에게 가장 위험한 만남.

#### 동작

- 일정 거리에서 발견 가능 (헤드라이트 범위)
- 시각적으로는 그냥 사람. 의심스러운 특징은 없다 (혹은 있어도 자신할 수 없다)
- 정차해서 태우거나, 그냥 지나친다

#### 정차 후 — 조수석 룰렛

조수석에 태우면 차량 출발. 그 순간 정체는 결정되지만 즉시 드러나지 않는다.

| 정체 | 확률 | 결과 |
|------|------|------|
| **일반인** | 50% | 다음 정비 구간까지 동승. 정신력 +30 일시 보너스. 정비 구간에서 ₩5,000 사례 후 하차 |
| **컬트원** | 25% | 약 30초 후 후드를 쓴다. 정신력 -50/분. 강제 정차(브레이크 풀밟기)로 하차시켜야 함 |
| **그녀** | 10% | 침묵. 끝까지 같이 간다. 모든 부적 효과 +20%. 단, 보닛 위 인간 시체가 있으면 즉시 사라짐 |
| **환영** (애초에 없음) | 15% | 태웠는데 차에 아무도 없다. 정신력 -15. 룸미러로 봐도 조수석 비어있음 |

#### 조수석 환영 시스템과의 충돌

- 평소 정신력 30 이하에서 발생하는 조수석 환영(그녀의 실루엣)이, 히치하이커 태우는 순간 **사라진다** (실제 사람이 그 자리에)
- 컬트원·환영 경우엔 사라졌다가 그녀의 실루엣이 가끔 컬트원의 모습에 겹쳐 보임
- 그녀가 태워진 경우(10%) 환영이 아닌 실제처럼 행동: 가끔 운전자를 본다, 가끔 창밖을 본다

#### 정차의 비용

태우려면 완전 정지. 평소 갓길 수색과 동일한 비용 — **괴물 접근**. 위험 대비 보상이 큰 도박.

### 4. 후방 그림자 (Rearview Stranger)

룸미러에만 보이는 것. **F키 포커싱 모드에서만 발견되는 사냥감.**

#### 동작

- 차량 후방 100~200m 도로 위에 가끔 등장
- 보통 시야에서는 안 보임. F키 포커싱 모드에서만 보임
- 형체는 사람 같지만 한쪽 다리를 끄는 것처럼 걷고 있다
- 차량 속도보다 느리므로 그냥 두면 멀어진다

#### 사냥 방법 — 후진 접촉

이 게임에서 거의 유일하게 **속도를 줄이는 것이 보상**이 되는 메커닉.

```
F키 포커싱 → 후방 그림자 발견
  → 브레이크로 속도 감속
  → 그림자가 차량 후미와 접촉할 때까지 기다림
  → 접촉 순간 정신력 +25 + 보닛에 작은 짐승 등급 미끼 추가
  → 그림자 즉시 소멸
```

#### 위험

- 속도를 줄이는 동안 **앞에서 오는 회피 적과 충돌**할 위험
- F키 포커싱 중에는 전방 도로가 완전히 가려짐
- 일반 시야로 빠져나오는 데 0.4초 (08-monster-chase.md 포커싱 전환 타이밍)
- 게다가 괴물도 동시에 다가오므로 너무 오래 감속하면 잡힘

#### 의도

룸미러는 지금까지 "괴물 거리를 확인하는 도구"였다. 본 메커닉은 룸미러를 **사냥의 도구**로 확장한다. F키를 단순 경계가 아닌 능동적 행위로 사용하게 만든다.

---

### 5. 죽음의 주파수 글자 (Death Frequency Letters)

라디오가 죽음의 주파수에 점유된 상태에서만 도로에 등장하는 한국어 글자들.

#### 동작

- 죽음의 주파수가 켜진 동안 도로 노면에 붉은 글자가 떠오른다 (페인트 자국처럼)
- 글자는 사람 이름의 음절들 — "권", "정", "최", "민", "수", "현" 등
- 차량이 글자 위를 지나가면 글자가 사라지고 효과 발동

#### 효과

| 글자 종류 | 효과 |
|---------|------|
| **타인의 이름 음절** | 기름 +0.5L (작음). 라디오 죽음의 주파수에서 그 음절이 사라짐 |
| **자기 이름 음절** (진엔딩 퍽 해금 후) | 정신력 +15. 단, 다음 라디오 호명에서 그 음절은 더 또렷해짐 |

#### 의도

- 라디오를 능동적으로 켜놓을 이유를 만든다 (보통은 끄고 싶지만, 글자 줍기엔 켜야 함)
- 27번 라디오 시스템의 "이름 호명" 메커닉과 직결: 자기 이름 글자를 먹을수록 호명이 빨라진다 (양날의 검)
- 무채색화 환경에서 붉은 글자는 항상 또렷 — 라디오를 켜놓는 동안엔 도로가 붉은 글자로 어지러워짐

## 콤보 시스템 — 폭주 (Frenzy)

**조건**: 3초 안에 보닛 위 시체 등급을 **연쇄적으로 업그레이드**한다. 작은 짐승 → 중형 → 큰 짐승 → 인간 → 봉헌물 순.

| 업그레이드 콤보 | 보너스 |
|--------------|--------|
| 작은 → 중형 (1단 상승) | 다음 미끼 정지 시간 +2초 |
| 작은 → 큰 (2단 상승) | +5초 |
| 작은 → 인간 (3단 상승) | +10초 + 정신력 -10 즉시 |
| 작은 → 봉헌물 (4단 상승) | 다음 미끼 정지 시간 ×2 + 정신력 -30 |

콤보를 의식적으로 노리면 짧은 시간 안에 사냥감을 빠르게 갈아치우는 광기 어린 주행이 된다. 정신력 코스트가 폭주를 자제하게 만든다.

### 콤보 표시

- 화면에 숫자 표시 없음
- 룸미러 얼굴이 콤보 단계마다 표정 변화 (3단 상승부터 광기 어린 미소)
- 4단 상승 시 라디오에서 짧은 잡음 폭발

## 보닛 위 시체와 트렁크의 거울 구조

| 트렁크 | 보닛 |
|-------|------|
| 그녀의 시체 (단 한 번, 영구) | 사냥감의 시체 (반복, 매번) |
| 검은 비닐로 감싸짐 (보이지 않음) | 픽셀 실루엣 (앞유리 하단에 항상 보임) |
| 외면하기 위해 달림 | 보지 않을 수 없음 |
| 처리 = A 엔딩 (또 다른 유기) | 처리 = 던지기 (괴물에게 먹임) |
| 던질 수 없는 것 | 던질 수 있는 것 |
| 숨겨진 죄 | 드러난 죄 |

**그가 평생 도망친 그것을, 게임은 보닛 위에 항상 보이도록 올려놓는다.** 던질 때마다 그가 트렁크의 그녀에게 했던 것과 정확히 같은 행위를 반복한다. 도로에 시체를 떨어뜨리고 떠나간다.

게임은 이 거울을 설명하지 않는다.

## 부적 시너지 (28번과 연동)

| 부적 | 보닛 시스템과의 시너지 |
|------|---------------------|
| `흔들리는 강아지 인형` | 보닛 위 시체가 흔들리는 모션이 더 강해짐 (시각 효과) + 던질 때 정신력 +5 |
| `피 묻은 동전` | 보닛 위에 인간 시체 있을 때 잡품 판매가 +30% |
| `자석 고양이` | 죽음 글자에서 추가로 5% 확률로 잡품 발견 |
| `일그러진 룸미러` | 후방 그림자 발견 확률 +50% |
| `눈먼 부엉이 조각` | 헤드라이트 끄면 죽음 글자 자기 이름 음절이 안 보임 (보호) |
| `기괴한 안테나` | 죽음의 주파수 글자가 노이즈 구간에서도 발동 |
| `안전운전 부적` | 광신도 행렬 관통 후 컬트 분노 시간 -50% |
| `금속 십자가` | 게임오버 직전 발동 시 보닛 위 시체 자동 던짐 (괴물 정지 시간으로 부활 보조) |
| `거꾸로 달린 부적` | 보닛 위 시체 정신력 비용 -50% |
| `시계 반대방향 인형` | 부활 시 보닛 위 시체 유지됨 |

## 무채색화 시스템 정합

| 대상 | 색 처리 |
|------|---------|
| 짐승 사체 (보닛) | 피만 붉게 또렷, 사체 본체는 무채색으로 빠짐 |
| 광신도 행렬 | 후드는 검정. 우두머리의 봉헌물은 검은 비닐 (보존 컬러 없음 → 더 빨려나간 듯) |
| 히치하이커 | 옷 색 일반. 컬트원의 후드는 정신력 낮을수록 더 또렷이 드러남 |
| 후방 그림자 | 룸미러 안에서 형체만. 색은 안 보임 |
| 죽음 글자 | 항상 붉은색 (붉은 보존) — 정신력 낮을수록 더 또렷 |
| 봉헌물 | 검정 비닐. 무채색화 무관. 트렁크의 그녀와 정확히 같은 색 |

봉헌물과 트렁크의 그녀가 **같은 비주얼**이라는 사실은 게임 어디에도 명시되지 않는다.

## 사운드 디자인

| 대상 | 사운드 |
|------|-------|
| 짐승 충돌 → 보닛 안착 | 퍽 + 짧은 마찰음 (사체가 보닛에 미끄러져 멈춤) |
| 광신도 충돌 | 천 찢어지는 소리 + 신음. 행렬 다른 멤버들이 동시에 멈춤 |
| 봉헌물 보닛 안착 | 정적. 라디오 죽음의 주파수가 1초간 끊김 |
| G키 시체 던지기 | 차체 후방에서 둔탁한 충격음. 직후 괴물의 흡입음 (멀리서) |
| 히치하이커 컬트원 변모 | 옷 스치는 소리 + 후드가 올라가는 소리 |
| 후방 그림자 접촉 | 차량 후미에서 미세한 닿음. 정적. 사라짐 |
| 죽음 글자 흡수 | 라디오에서 그 음절이 짧게 끊김 (음원 글리치) |

## 설계 의도 정리

이 시스템의 모든 사냥은 **이 게임만이 할 수 있는 행위**다:

- 보닛 위 시체 = 트렁크의 그녀를 미러링 (서사 메커닉 일체화)
- 광신도 행렬 봉헌물 = 검은 비닐 = 트렁크의 그녀
- 히치하이커 그녀(10%) = 조수석 환영의 살아있는 버전
- 후방 그림자 = 룸미러 메커닉의 능동화
- 죽음 글자 = 라디오 시스템의 게임플레이화

회피 게임 → 회피+사냥 게임이 아니다. **회피 게임 → 그가 평생 도망친 것을 매 순간 보고, 던지고, 다시 마주하는 게임**이 된다.
