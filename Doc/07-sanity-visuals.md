# 7. 화면 상태 시스템

**목적**: HUD를 최소화하고 화면 자체가 자원 계기판이 되도록 설계.

## 자원 상태 → 화면 효과 매핑

| 자원 | 임계값 | 화면 효과 |
|------|--------|---------|
| 기름 | 40% 이하 | 화면 하단 서서히 어두워짐 |
| 기름 | 15% 이하 | 엔진 소리 변화 + 화면 전체 붉은 비네트 |
| 라디오 죽음의 주파수 | 활성 중 | 대시보드 전체에 붉은 조명. 라디오 디스플레이에서 새어나오는 빛. 안전 주파수 전환 즉시 소등 |
| 타이어 펑크 (2개 대각선) | 발생 시 | 화면 좌우 흔들림 지속 |
| 구동계 고장 | 발생 시 | 화면 미세 떨림 + RPM 게이지 폭주 |
| 정신력 | 70 이하 | 화면 채도 서서히 감소 시작 |
| 정신력 | 50 이하 | 채도 40%. 붉은색 계열만 선명하게 남기 시작 |
| 정신력 | 30 이하 | 채도 15%. 세상 거의 흑백. 붉은 것들 강조됨 |
| 정신력 | 10 이하 | 채도 5%. 완전에 가까운 흑백. 붉은색만 남음 |
| 빗물 누적 (와이퍼 끔) | 시야 50% 이하 | 앞유리 반투명 오버레이 |
| 빗물 누적 (와이퍼 끔) | 시야 0% | 앞유리 완전 불투명. 도로 식별 불가 |

## 무채색화 시스템 (정신력 시각화)

정신력이 낮아질수록 세상의 색이 빠져나간다. **붉은색(Hue 330°~30°)은 채도 감소에서 제외된다.**

세상이 회색으로 변해갈 때 붉은 것들만 점점 선명하게 부각된다.

| 정신력 | 채도 | 상태 |
|-------|------|------|
| 100~70 | 100% | 정상 |
| 70~50 | 100%→70% | 서서히 탈색. 의식하지 않으면 모름 |
| 50~30 | 70%→40% | 뚜렷한 탈색. 붉은색만 선명하게 남음 |
| 30~10 | 40%→15% | 거의 흑백. 붉은 것들이 강조되어 보임 |
| 10~0 | 15%→5% | 완전에 가까운 흑백. 붉은색 대비 극대화 |

### 붉은색 제외의 효과

정신력이 낮아진 상태에서 화면이 흑백에 가까워지면:
- 도로, 건물, 나무, 컬트 실루엣 → 회색
- 피, 경고등, 죽음의 주파수 붉은 조명, 충돌 이후 흔적 → 더욱 선명하게 대비

플레이어가 의도하지 않아도 "위험한 것"이 시각적으로 강조된다.

### Godot 셰이더 구현 개요

```gdscript
# 무채색화 셰이더 파라미터 (스크린 포스트프로세싱)
# uniform float desaturation: 0.0 (정상) → 1.0 (완전 흑백)
# 정신력 70→0 구간을 desaturation 0.0→1.0으로 선형 매핑
#
# 붉은색 보호 로직 (GLSL):
# red_dominance = max(0.0, R - max(G, B))
# local_desat = desaturation * (1.0 - clamp(red_dominance * 2.5, 0.0, 1.0))
# OUTPUT = mix(original_color, vec3(luminance), local_desat)
```

## 조수석 환영 (Passenger Hallucination)

정신력이 낮아질수록 조수석에 무언가가 점진적으로 나타난다. 환각 위협(도로 적 환각화)과 별개의 시스템. **충돌·게임플레이 효과 없음** — 순수 시각·심리 연출.

| 정신력 | 표현 | 사운드 |
|--------|------|--------|
| 50 이하 | 조수석 안전벨트 버클이 혼자 깜빡임 | 미세한 금속 클릭 (5초 주기) |
| 30 이하 | 깜빡임 + 실루엣 형성 (앞을 보고 있음) | 클릭 + 옷자락 스치는 소리 |
| 10 이하 | 실루엣 선명 + **천천히 고개를 돌려 운전자를 봄** | 정적 (모든 환경음 -50%) |

### 게임플레이 상호작용

- 조수석 환영은 **클릭/조작 불가능**. 그저 보일 뿐이다.
- 시야에 들어오려면 운전자가 조수석을 바라봐야 한다 (기본 시점에서는 시야 우측 가장자리에 부분적으로 보임).
- 환각 적과 달리 충돌·소멸 메커니즘 없음.
- 정신력 회복 시 단계가 역행 (10 이하 → 30 이하: 고개 다시 정면. 30 이하 → 50 이하: 실루엣 사라짐).

### 무채색화 정합

조수석 환영은 무채색화 영향을 받지만 **버클의 금속 광택과 안전벨트의 붉은 경고등 픽셀**은 보존 컬러로 처리되어 정신력이 낮을수록 더 또렷해진다. BO와 동일한 색 보존 규칙.

### 내러티브 연결

조수석 환영은 [24-story.md](24-story.md)의 "그녀가 항상 앉던 자리. 안전벨트를 풀었던 자리"와 연결된다. 정신력 10 이하에서 고개 돌림 순간 혼잣말 시스템이 **유일하게 강제 침묵을 출력**한다 — [26-monologue.md — 조수석 환영](26-monologue.md) 참조.
