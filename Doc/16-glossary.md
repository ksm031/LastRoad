# 16. 용어집

| 용어 | 정의 |
|------|------|
| **구간 (Stage)** | 거점과 거점 사이의 도로 구간 |
| **거점 (Rest Stop)** | 구간 사이 수리·보급·경로 선택 가능한 지점. 정비 구간 진입 시 괴물 추격이 일시 정지되며, 다음 스테이지 진입 시 괴물 거리가 초기화됨 |
| **소켓** | 차량의 6개 파츠 장착 슬롯 (엔진·타이어·브레이크·핸들·연료탱크·헤드라이트) |
| **파츠** | 소켓에 장착하는 부품 아이템. 등급과 내구도 보유 |
| **트렁크** | 미장착 파츠·기름통·소모품(담배)·잡품 보관 공간 (기본 20칸). 정비 구간에서 돈으로 추가 확장 가능 |
| **정신력 (Sanity)** | 공포 이벤트 목격 시 감소하는 자원. 채도 감소 강도 및 룸미러 얼굴 표정과 연동 |
| **컬트** | 국도에 출현하는 정체불명의 집단. 적대적이나 직접 공격하지 않음 |
| **사슴머리** | 스테이지 6에서 2~3회 고정 등장하는 보스형 위협. 도로 전 차선을 점유하며 회피 불가. 통과 속도가 낮을수록 정신력·파츠 피해 증가 |
| **환각 위협** | 정신력 40 이하 시 등장. 실제 위협과 구분 불가능 (외관 동일). 파츠 손상 없으나 회피 행동으로 갓길 충돌 유발 가능. 와쳐·러너만 환각으로 등장 |
| **무채색화 시스템** | 정신력 감소 시 세계에서 채도가 빠져나가는 연출 시스템. 붉은색 계열(Hue 330°–30°)은 채도 보존되어 더 선명해짐 |
| **빌보드** | 도로 위 오브젝트 렌더링 방식. 정면 스프라이트 하나가 항상 카메라를 향함. z값에 따라 크기와 위치 조정 |
| **내부 해상도** | 1280×720 네이티브. 업스케일 없이 스프라이트 픽셀이 화면에 직접 노출됨 |
| **괴물 (The Thing)** | 게임 시작부터 뒤에서 쫓아오는 존재. 스테이지가 깊어질수록 이동속도가 증가(1스테이지 70km/h → 6스테이지 120km/h). 정체 불명. 룸미러로만 확인 가능 |
| **룸미러** | 화면 상단 중앙 고정 UI. 기본 상태에서 주인공 얼굴(정신력 지표)을 표시. F키 또는 좌클릭으로 포커싱 모드 토글 |
| **포커싱 모드** | F키 토글 또는 룸미러 좌클릭으로 전환. 전체 화면이 후방 뷰로 전환되며 전방 도로가 완전히 차단된다. 우클릭 또는 F키 재입력으로 닫음 |
| **얼굴 잔상** | 정신력 30 이하에서 포커싱 해제 직후 괴물 실루엣이 얼굴 위에 0.5초간 겹쳐 보이는 연출 |
| **와이퍼 시스템** | 비 오는 구간에서 빗물 누적으로 인한 시야 저하를 Z키로 관리하는 시스템. 기름 소모 없음. 와이퍼 스윕 시 컬트 실루엣이 순간 노출되는 공포 연출 포함 |
| **아스팔트 타일** | 도로 노면을 구성하는 320×8px 가로 띠. 가장 가까운 z=1.0 기준으로 한 장만 제작하며 코드가 z값에 따라 세로 높이를 자동 축소 |
| **도로 배리에이션** | 기본·반사·균열·습기·오일 5종 아스팔트 타일. 차선 없이 순수 노면 질감만 담음 |
| **전봇대 간격** | 구간 내 전봇대 배치 간격. 기본 40m, 후반 구간으로 갈수록 넓어짐. 오브젝트 풀로 관리하며 화면에 최대 2~3개 동시 존재 |
| **전깃줄** | 인접한 두 전봇대 사이를 연결하는 동적 생성 곡선. 별도 이미지 없음. 매 프레임 베지어 곡선으로 코드가 그림. 720p 네이티브 기준 width=2px, antialiased=false로 픽셀아트 느낌 유지 |
| **헤드라이트 조명 시스템** | 오브젝트가 헤드라이트 범위에 들어오면 z값에 따라 아래→위로 빛이 올라오는 셰이더 효과. 별도 이미지 없음. 코드로 생성한 그라디언트 마스크를 실시간 적용. 라이트 파츠 내구도와 연동 |
| **빌보드 조명 마스크** | 각 오브젝트 스프라이트에 적용되는 ShaderMaterial. z값 → light_height 매핑으로 아래부터 위로 점진적 조명 표현 |
| **언덕 (Hill)** | 소실점 y좌표를 이동시켜 오르막·내리막을 표현하는 코드 기반 지형 연출. 커브(x오프셋)와 동시 적용 가능. 별도 이미지 불필요 |
| **시차 스크롤 (Parallax)** | 원경 레이어가 커브·언덕값에 비례해 다른 속도로 반응하는 원근 효과. 산 실루엣 0.3, 구름 0.1, 하늘 0.0 계수 적용. Godot ParallaxBackground 노드 활용 |
| **잠긴 칸 (Locked Slot)** | 메타 퍽 20개를 모두 해금하면 등장하는 21번째 노드. 트렁크의 숨겨진 1칸을 영구 해제하며, 활성화 후 다음 런부터 트렁크에 시체가 발견된다. 진엔딩 분기 트리거 |
| **시체 (The Cargo)** | 잠긴 칸 활성화 후 트렁크에 항상 존재하는 검은 비닐로 감싼 형체. 정체 미상. 인벤 버리기 또는 상점 판매로 처리 가능. 처리 여부에 따라 A/B 엔딩 분기 |
| **진엔딩 (B 엔딩)** | 시체를 처리하지 않고 6스테이지 사슴머리에게 정면 통과 시 도달. 루프를 종료하는 유일한 엔딩. 상세 [22-true-ending.md](22-true-ending.md) |
