# 3. Pseudo 3D 드라이빙

**목적**: 레퍼런스 영상(새벽 국도 + 헤드라이트 시야)을 게임으로 구현. 어둠 속에서 다가오는 위협의 공포감 극대화.

## 기본 구현 방식

Godot 2D에서 투영 트릭으로 구현. 실제 3D 불필요.

- **도로**: 사다리꼴 폴리곤 두 레이어 교차 배치로 원근감 표현. 짝수/홀수 스트라이프 색상 교번.
- **오브젝트**: 거리(z값)에 따라 `scale`과 `y position` 조절. z=0(화면 중앙 소실점)에서 z=1(화면 하단)으로 이동하며 커짐.
- **커브**: 도로 폴리곤 전체에 x 오프셋 적용. 좌/우 커브는 오프셋 방향으로 구분.

> 도로 렌더링·커브·언덕·시차 스크롤 상세는 [15-tech-overview.md](15-tech-overview.md) 참조.

## 조작 입력

### 주행 (왼손 — 키보드)

| 입력 | 행동 | 비고 |
|------|------|------|
| ← → (A/D) | 좌우 차선 이동 | 3레인 기준 |
| ↑ (W) | 가속 | 최고속도 제한 있음 |
| ↓ (S) | 감속 / 정지 | 정지 시 컬트 AI 활성화 |

### 보조 조작 (오른손 — 마우스)

| 입력 | 행동 | 비고 |
|------|------|------|
| 마우스 이동 | 화면 커서 이동 | 큰 원형 커서. 클릭 판정 후함 |
| 좌클릭 | 화면 오브젝트 줌인 / 토글 | 룸미러·라디오·와이퍼 |
| 우클릭 | 현재 열린 화면 닫기 | — |

키보드 단축키와 마우스 클릭은 병행 사용 가능. 어느 쪽으로도 동일한 조작이 된다.

## 화면 클릭 오브젝트

주행 중 마우스로 클릭할 수 있는 오브젝트. 좌클릭으로 열고, 우클릭 또는 동일 키 재입력으로 닫는다.

| 오브젝트 | 위치 | 클릭 효과 | 키보드 단축키 |
|---------|------|---------|------------|
| 룸미러 | 상단 중앙 | 전체 화면 후방 뷰 토글. 열면 전방 완전 차단 | F |
| 라디오 | 우상단 | 라디오 전체 화면 줌인 토글. 열면 전방 완전 차단 | V |
| 와이퍼 레버 | 좌하단 (TBD) | 와이퍼 단계 순환 (끔→1단→2단→끔) | Z |

룸미러·라디오는 열면 도로가 완전히 보이지 않는다. 둘 중 하나가 열린 상태에서 다른 것을 열면 현재 것이 닫히고 새것이 열린다.

## 타이어 펑크 시 주행 성능 변화

타이어 내구도 0 → 펑크. 공기압이 실시간으로 하락하며 주행 성능이 저하된다.

| 공기압 | 최고속도 | 가속도 | 핸들 응답 | 화면 흔들림 |
|--------|--------|--------|---------|-----------|
| 100% | 정상 | 정상 | 정상 | 없음 |
| 60% | ×0.85 | ×0.82 | ×0.85 | 눈에 띔 |
| 20% | ×0.50 | ×0.45 | ×0.50 | 매우 심함 |
| 0% | ×0.25 | ×0.20 | ×0.30 | 극심 |

공기압은 패치킷 사용 시 누출이 멈추지만 회복되지 않는다. 거점에서 타이어 교체 시에만 100%로 복구.

> 타이어 펑크 전체 흐름은 [05-parts.md](05-parts.md) — 타이어 펑크 & 공기압 시스템 참조.

## 예시 시나리오

> 플레이어가 도로 중앙에 무릎 꿇은 인물을 발견한다. 좌측 차선으로 핸들을 꺾어 회피하거나, 그냥 밟고 지나갈 수 있다. 회피 시 갓길 풀숲에 걸려 타이어 파츠 내구도 -5. 그냥 밟으면 충돌 이펙트 없이 지나쳐지고, 정신력 -15.

## 헤드라이트 조명 시스템

**목적**: 거리감을 직관적으로 전달하고 공포 점층을 강화. 오브젝트가 헤드라이트 범위에 들어오면 아래→위 방향으로 빛이 점진적으로 올라온다.

### 물리 근거

헤드라이트는 차 앞 낮은 위치에서 방사된다. 멀리 있는 물체는 빛이 하단에만 닿고, 가까워질수록 빛이 물체의 상단까지 올라온다.

```
z=0.3 (멀리)     z=0.6 (중간)     z=0.9 (가까이)
[어두움      ]   [어두움      ]   [빛 닿음     ]
[어두움      ]   [빛 닿음     ]   [빛 닿음     ]
[빛 닿음     ]   [빛 닿음     ]   [빛 닿음     ]
```

### 구현 방식

그라디언트 마스크를 코드로 생성한다. 별도 이미지 제작 불필요.

각 오브젝트 스프라이트에 `ShaderMaterial`을 적용. z값에 따라 셰이더가 아래→위 방향 조명 높이를 실시간으로 계산한다.

```glsl
// 헤드라이트 조명 셰이더
// light_height: 0.0 = 빛 없음, 1.0 = 전체 조명
uniform float light_height = 0.5;
uniform vec4 light_color = vec4(0.91, 0.78, 0.48, 1.0); // #E8C87A

void fragment() {
    vec4 tex = texture(TEXTURE, UV);

    // UV.y: 0.0=스프라이트 상단, 1.0=스프라이트 하단
    // 하단(1.0)부터 light_height 높이까지 빛 적용
    float lit = smoothstep(1.0 - light_height, 1.0 - light_height + 0.15, 1.0 - UV.y);

    vec4 lit_color = mix(tex * vec4(0.1, 0.1, 0.1, 1.0), tex * light_color, lit);
    COLOR = lit_color;
}
```

### z값 → light_height 매핑

| z값 (거리) | light_height | 빛 도달 위치 |
|-----------|-------------|------------|
| 0.0~0.3 (헤드라이트 범위 밖) | 0.0 | 완전 어둠 |
| 0.3 (범위 진입) | 0.05 | 발 아래 5% |
| 0.5 (중간) | 0.35 | 하단 35% |
| 0.7 | 0.65 | 하단 65% |
| 0.9 (바로 앞) | 0.90 | 거의 전체 |
| 1.0 (최근접) | 1.0 | 전체 조명 |

### 공포 연출 효과

컬트 실루엣이 멀리서는 완전한 검은 덩어리다. 가까워지면서 아래부터 형태가 드러나기 시작한다. 얼굴·머리 부분이 가장 마지막에 보인다. 사슴머리는 뿔이 마지막에 드러나는 구조가 된다.

### 라이트 파츠 연동

라이트 파츠 내구도에 따라 `light_height` 최대값이 제한된다.

| 라이트 파츠 상태 | light_height 최대값 |
|--------------|-------------------|
| 정상 | 1.0 |
| 내구도 50% | 0.7 |
| 내구도 20% | 0.4 |
| 내구도 0% | 0.1 (거의 어둠) |
