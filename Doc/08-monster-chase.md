# 8. 괴물 추격 시스템

**목적**: 게임 전체에 걸친 시간 압박 축. "지금 얼마나 여유가 있는가"를 플레이어가 룸미러로 감각적으로 판단하게 한다.

## 기본 구조

괴물은 게임 시작과 동시에 출발지 뒤편에서 등장한다. 일정한 속도로 꾸준히 접근하며, 결코 멈추지 않는다.

룸미러는 **두 가지 모드**로 동작한다.

---

## 룸미러 — 기본 상태 (얼굴 모드)

평소 룸미러에는 **주인공 얼굴 클로즈업**이 보인다. 얼굴 표정이 정신력 지표 역할을 하며, 괴물 거리의 간접 신호이기도 하다. 괴물을 보려면 플레이어가 직접 키를 눌러야 한다. **확인하는 행위 자체가 공포**다.

얼굴 표정 상세는 [04-resources.md](04-resources.md) — 정신력 섹션 참조.

---

## 룸미러 — 포커싱 모드 (괴물 확인)

`F` 키 또는 룸미러 오브젝트 좌클릭으로 토글. 열면 전방 도로가 완전히 가려지고 전체 화면이 후방 뷰로 전환된다. 동일 키 재입력 또는 우클릭으로 닫는다.

```
[열기]
1. 룸미러 0.3초에 걸쳐 전체 화면으로 확대
2. 얼굴 페이드아웃 (0.2초)
3. 후방 도로 장면 페이드인 — 괴물 현황 확인 가능. 전방 도로 완전 차단

[닫기] F 재입력 또는 우클릭
1. 후방 페이드아웃, 얼굴 페이드인 (0.2초)
2. 룸미러 전체 화면 → 원래 크기로 축소 (0.2초)
```

### 후방 씬 구현 방식

후방은 전방 도로를 정확히 재현하지 않는다. 움직임 느낌만 살리되 리소스를 최소화한다. SubViewport 안에서 단순화된 후방 Pseudo 3D를 렌더링한다.

```
SubViewport (룸미러 영역)
  └─ 후방 하늘 배경     ← 전방 하늘 이미지 재활용. 정적
  └─ 후방 도로 타일     ← 전방 타일 A(기본)만 재활용. 전방과 반대 방향 스크롤
  └─ 갓길 오브젝트      ← 전방 나무·전봇대 스프라이트 재활용. 밀도 낮춤
  └─ 괴물 스프라이트    ← 거리 단계에 따라 scale 변화
```

**후방 전용 신규 제작 리소스: 없음.** 전방 리소스를 그대로 재활용하되 아래 조건만 다르게 적용한다.

| 항목 | 전방 | 후방 |
|------|------|------|
| 도로 타일 종류 | A~E 배리에이션 | A(기본)만 |
| 차선 | 황색 점선 + 흰색 실선 | 생략 |
| 갓길 오브젝트 밀도 | 높음 | 낮음 (50% 수준) |
| 스크롤 방향 | 아래→위 (전방으로) | 위→아래 (후방으로) |
| 스크롤 속도 | 차량 속도에 비례 | 전방과 동일 속도 |
| 커브 | 구간별 적용 | 전방과 반대 방향 |

### 포커싱 중 페널티

- 전방 도로 완전 차단: 열려 있는 동안 장애물 감지 불가. 직접 닫기 전까지 유지
- 정신력 30 이하 포커싱 해제 후: 괴물 실루엣 잔상이 0.5초간 얼굴 위에 겹쳐 보임

### 괴물 거리 단계 (포커싱 시 룸미러 내 크기)

```
[안전]     룸미러: 수평선 위 희미한 점
[경계]     룸미러: 형태 윤곽. 다리가 여럿임
[위험]     룸미러: 거울 면적 40~60% 차지. 디테일 식별
[임박]     룸미러: 거울 거의 가득 참. 정신력 강제 감소 시작
[따라잡힘] 룸미러 밖으로 넘침 → 게임 오버 (엔딩 E)
```

## 괴물 이동 속도 파라미터

괴물의 이동속도는 **스테이지가 깊어질수록 빨라진다**. 초반에는 차량 기본 속도(80 km/h)만 유지해도 충분히 떨어뜨릴 수 있지만, 후반에는 업그레이드된 차량 최고속도로도 따돌리기 어렵다.

### 스테이지별 괴물 속도

| 스테이지 | 괴물 속도 | 기본 차량(80km/h) 기준 간격 변화 | 압박 강도 |
|---------|---------|-------------------------------|---------|
| 1 | 60 km/h | -5.5m/s (빠르게 멀어짐) | ★☆☆ 매우 여유. 갓길 수색 최적 |
| 2 | 70 km/h | -2.8m/s (천천히 멀어짐) | ★☆☆ 여유 있음. 수색 가능 |
| 3 | 80 km/h | 0 (간격 유지) | ★★☆ 기본 속도로는 동률. 감속 시 비용 발생 |
| 4 | 90 km/h | +2.8m/s (서서히 가까워짐) | ★★☆ 가속 필요 |
| 5 | 100 km/h | +5.5m/s | ★★★ 일반 최고속도(120) 이상 필요 |
| 6 | 110 km/h | +8.3m/s | ★★★ 업그레이드 차량 필수 + 사슴머리 동시 압박 |

수치는 구현 후 밸런스 조정.

### 차량 속도 vs 괴물 간격 변화 (스테이지 4, 괴물 90 km/h 기준 예시)

| 플레이어 속도 | 간격 변화율 | 룸미러 변화 |
|------------|-----------|-----------|
| 140 km/h (최고속) | -14m/s (빠르게 멀어짐) | 빠르게 작아짐 |
| 120 km/h (일반 최고) | -8m/s (멀어짐) | 천천히 작아짐 |
| 90 km/h | 간격 유지 | 변화 없음 |
| 80 km/h (기본) | +3m/s (가까워짐) | 서서히 커짐 |
| 50 km/h (감속) | +11m/s (빠르게 가까워짐) | 빠르게 커짐 |
| 0 km/h (갓길 정지) | +25m/s (매우 빠르게 가까워짐) | 급격히 커짐 |
| 거점 정박 중 | 정지 (추격 일시 정지) | 정비 구간 — 괴물 접근 없음 |

> 스테이지가 바뀌어 괴물 속도가 변경되더라도 **갓길 정지 시 가속도(8m/s 추가 접근)는 동일하게 적용**된다. 속도 차이에 정지 패널티가 더해지는 구조.

## 창 던지기 (Spear Throw)

괴물이 일정 거리 이내에 접근하면 **창을 던지는 공격**을 시작한다. 본 메커닉의 목적은 룸미러를 단순 정보창에서 **실시간 반응 게이지**로 격상시키는 것이다. 플레이어는 룸미러를 능동적으로 읽고, 어느 손이 들렸는지 보고, 정확한 방향으로 차선을 옮겨 회피해야 한다.

### 발동 조건

| 조건 | 동작 |
|------|------|
| 괴물 거리 단계 | 경계 이상 (안전 단계에서는 발동하지 않음) |
| 발동 주기 | 스테이지·거리 단계에 따라 다름 (아래 표) |
| 동시 발동 | 없음. 한 번에 한 발만 |

### 시퀀스 (총 약 3초)

```
[1단계 — 경고 (0.8초)]
  · 룸미러 프레임 가장자리가 붉게 펄스
  · 사운드: 깊은 들숨 (멀리서, 점진 증가)
  · 룸미러 안에서 괴물 실루엣이 한쪽 팔을 천천히 치켜듦

[2단계 — 윈드업 (0.7초)]
  · 괴물의 한쪽 팔이 머리 위까지 완전히 올라감 (좌·우 결정)
  · 사운드: 들숨 정점 → 짧은 정적
  · 일반 룸미러 시야에서는 작게 보임. F키 포커싱 시 또렷

[3단계 — 던지기 (0.3초)]
  · 팔이 빠르게 내려옴
  · 후방에서 검고 긴 형체가 발사됨

[4단계 — 비행 (0.8~1.2초)]
  · 창이 도로 한쪽 차선을 따라 직선으로 전진
  · 차량을 추월하는 순간 옆을 휙 지나감 → 전방으로 사라짐
  · 명중 시 차량 측면 강타
```

### 좌·우 판독 (룸미러 거울 논리)

룸미러는 좌우 반전 없이 표시된다 (운전자 시점에서 일관적). 따라서:

| 룸미러에 보이는 것 | 실제 괴물 상태 | 창이 오는 도로 측 | 회피 방향 |
|---------------|------------|--------------|---------|
| 오른손 들었음 (오른쪽 화면) | 괴물 오른팔 | 도로 오른쪽 차선 | **왼쪽으로 차선 변경** |
| 왼손 들었음 (왼쪽 화면) | 괴물 왼팔 | 도로 왼쪽 차선 | **오른쪽으로 차선 변경** |

> **규칙 한 줄 요약**: 룸미러에서 손이 보이는 쪽 — 그 반대로 피한다.

### F키 포커싱과의 트레이드오프

- **일반 시야**: 룸미러 작음. 어느 손인지 식별 어려움. 단, 전방 도로 동시 시인 가능
- **F키 포커싱**: 룸미러 전체화면. 손 또렷이 식별 가능. 단, 전방 완전 차단

플레이어는 매 경고마다 결정한다:
- 일반 시야로 빠르게 읽고 즉시 회피 (난이도 높지만 안전한 운전)
- F키로 정확히 보고 회피 (정확하지만 그 사이 전방 위험)

### 명중 시 효과

| 항목 | 값 |
|------|-----|
| 차체 내구도 | -25% |
| 정신력 | -25 |
| 앞유리 균열 | +1단계 |
| 차량 거동 | 0.5초간 핸들 흔들림 (조작 일시 불가) |
| 괴물 거리 변화 | 없음 (보너스 접근은 없음) |

명중은 치명적이지만 즉사는 아니다. 한두 번 맞아도 살아남을 수 있되 누적되면 차체가 파괴된다.

### 빗맞춤 시 연출

- 차량 옆을 도플러 효과로 휙 지나감 (좌측/우측 채널 사운드)
- 시야 가장자리에 검은 잔상 0.2초
- 전방으로 멀어지며 어둠 속으로 사라짐
- 정신력 회복 효과 없음 (회피 보상은 살아남았다는 사실 그 자체)

### 스테이지별 패턴

| 스테이지 | 발동 가능 | 윈드업 시간 | 빈도 | 특수 패턴 |
|---------|---------|-----------|------|---------|
| 1 | ✗ | — | — | 발동 안 함 |
| 2 | ✗ | — | — | 발동 안 함 |
| 3 | ✓ | 1.5초 (느림) | 40초당 1회 | 단발만 |
| 4 | ✓ | 1.2초 | 30초당 1회 | 단발만 |
| 5 | ✓ | 1.0초 | 25초당 1회 | 가끔 2연발 (0.8초 간격) |
| 6 | ✓ | 0.8초 (빠름) | 20초당 1회 | 2연발 + **페이크** 등장 |

### 페이크 패턴 (스테이지 6)

- 괴물이 한 손을 들었다가, **마지막 순간 다른 손으로 바꿔서 던진다**
- 페이크 발동 확률: 30%
- 미세한 시그널: 윈드업 중 괴물의 어깨 무게가 한쪽으로 살짝 기울었다가 반대로 이동
- 일반 시야에서는 식별 거의 불가능. **F키 포커싱 + 끝까지 지켜봐야** 페이크 판독 가능
- 페이크 판독 실패 시 잘못된 방향으로 회피 → 무조건 명중

### 거리 단계와의 관계

| 괴물 거리 단계 | 창 던지기 |
|-------------|---------|
| 안전 | 발동 안 함 (사정거리 밖) |
| 경계 | 발동 시작 |
| 위험 | 빈도 +50% |
| 임박 | 빈도 +100% (정신력 강제 감소와 동시 진행) |

플레이어가 속도를 늦춰 괴물이 가까워질수록 창 빈도가 증가한다. **속도 유지의 동기를 더 강하게 만든다.**

### 부적 시너지 (28번과 연동)

| 부적 | 효과 |
|------|------|
| `일그러진 룸미러` | 일반 시야 룸미러에서도 손이 또렷하게 보임 (F키 없이 판독 가능) |
| `안전운전 부적` | 차체 100% 유지 중 창 명중 시 차체 손상 -50% |
| `금속 십자가` | 스테이지당 1회, 첫 명중을 자동 빗맞춤으로 전환 |
| `눈먼 부엉이 조각` | 헤드라이트 끈 상태 시 창이 전방에서 사라지는 거리가 짧아져 시인성 ↓ |
| `시계 반대방향 인형` | 명중 직후 사망 시 부활 트리거 우선 적용 |
| `거꾸로 달린 부적` | 차체 손상 -50%, 정신력 손실 -25% (페널티 일괄 감소) |

### 사운드 디자인

| 단계 | 사운드 |
|------|-------|
| 경고 | 멀리서 들리는 깊은 들숨 (스테레오 후방) |
| 윈드업 정점 | 짧은 정적 (모든 환경음 약간 약해짐) |
| 던지기 | 짧은 휘파람 같은 절단음 |
| 비행 | 도플러 효과 (좌측 또는 우측 채널에서 시작 → 가까워졌다가 멀어짐) |
| 빗맞춤 | 도플러 휘이익 → 전방 어둠으로 멀어지는 잔향 |
| 명중 | 둔탁한 충격음 + 앞유리 균열 사운드 + 차체 진동 |

### 시각 디자인

- **창 자체**: 길고 뾰족한 검은 형체. 사람 키 정도의 길이. 끝부분이 들쭉날쭉. 정확한 형체는 보이지 않음 (속도 때문)
- **모션 블러**: 비행 중 검은 잔상이 길게 뻗음 — 도로 측면을 따라 일직선
- **무채색화 무관**: 항상 검정으로 또렷이 보임
- **궤적**: 도로 노면에서 1m 정도 높이로, 직선으로 전진. 곡선 없음

### 룸미러 시각 강조

경고 단계에서 룸미러 프레임이 펄스. 색은 정신력 상태와 무관하게 **항상 붉음** (무채색화 환경에서도 또렷이 보임).

```
경고 발동 순간:
  ┌─────────────┐
  │█████ 룸미러 █████│  ← 가장자리 붉은 펄스 0.8초
  │  주인공 얼굴  │
  │             │
  └─────────────┘
```

### 의도

이 메커닉이 게임에 추가하는 것:

1. **룸미러의 능동화**: 지금까지 룸미러는 "체크하면 좋은" 정보였음. 이제 "체크하지 않으면 죽는" 강제 인터랙션
2. **F키 사용 빈도 증가**: 단순 거리 확인이 아닌 정밀 판독 도구로 격상
3. **속도 유지 동기 강화**: 가까워질수록 창이 빨라지고 잦아짐 — 멈춰서 파밍하면 다음 구간이 지옥
4. **반응 + 판단 동시 시험**: 좌·우 판독은 거울 논리 이해를 요구. 페이크는 끝까지 지켜보는 인내를 요구
5. **사냥 시스템과의 결합**: 보닛에 시체가 있다면 명중 직전 G키로 던져 괴물을 멈출 수 있음 (창 자체는 막을 수 없지만 다음 발사 지연 가능)

## 괴물의 정체

명시하지 않는다. 포커싱 모드 룸미러로만 보인다. 설계 원칙:
- 형태: 거대하고 다리가 여럿. 천천히 움직이는데도 빠르다
- 소리: 없음. 가까워져도 엔진 소리만 들림
- 컬트와의 관계: 암시만. 컬트가 도로 밖으로 밀려나 있는 이유가 괴물 때문일 수 있으나 확정하지 않음

[임박 단계 — 얼굴이 먼저 공황 표정으로 바뀐 뒤]
운전자: "안 돼. 안 돼. 안 돼—"

[포커싱 해제 후 잔상 발생 시 (정신력 30 이하)]
운전자: "...아직 거기 있어?"

[정신력 30 이하 + 임박 단계]

## 엔딩 E — 따라잡힘

룸미러 포커싱 시 괴물이 화면 밖으로 넘치는 순간 화면 암전. 엔진 소리가 끊긴다. 시계가 멈춘다. 그 다음은 아무것도 없다.
