# 8. 괴물 추격 시스템

**목적**: 게임 전체에 걸친 시간 압박 축. "지금 얼마나 여유가 있는가"를 플레이어가 룸미러로 감각적으로 판단하게 한다.

## 기본 구조

괴물은 게임 시작과 동시에 출발지 뒤편에서 등장한다. 일정한 속도로 꾸준히 접근하며, 결코 멈추지 않는다.

룸미러는 **두 가지 모드**로 동작한다.

---

## 룸미러 — 기본 상태 (얼굴 모드)

평소 룸미러에는 **주인공 얼굴 클로즈업**이 보인다. 얼굴 표정이 정신력 지표 역할을 하며, 괴물 거리의 간접 신호이기도 하다. 괴물을 보려면 플레이어가 직접 키를 눌러야 한다. **확인하는 행위 자체가 공포**다.

얼굴 표정 상세는 [04-resources.md](04-resources.md) — 정신력 섹션 참조.

---

## 룸미러 — 포커싱 모드 (괴물 확인)

`F` 키를 누르는 동안 포커싱 모드로 전환.

```
1. 룸미러 0.3초에 걸쳐 확대 (1.0x → 1.8x)
2. 얼굴 페이드아웃 (0.2초)
3. 후방 도로 장면 페이드인 — 괴물 현황 확인 가능
4. F 키에서 손 떼면 0.2초에 걸쳐 얼굴 복귀
```

### 후방 씬 구현 방식

후방은 전방 도로를 정확히 재현하지 않는다. 움직임 느낌만 살리되 리소스를 최소화한다. SubViewport 안에서 단순화된 후방 Pseudo 3D를 렌더링한다.

```
SubViewport (룸미러 영역)
  └─ 후방 하늘 배경     ← 전방 하늘 이미지 재활용. 정적
  └─ 후방 도로 타일     ← 전방 타일 A(기본)만 재활용. 전방과 반대 방향 스크롤
  └─ 갓길 오브젝트      ← 전방 나무·전봇대 스프라이트 재활용. 밀도 낮춤
  └─ 괴물 스프라이트    ← 거리 단계에 따라 scale 변화
```

**후방 전용 신규 제작 리소스: 없음.** 전방 리소스를 그대로 재활용하되 아래 조건만 다르게 적용한다.

| 항목 | 전방 | 후방 |
|------|------|------|
| 도로 타일 종류 | A~E 배리에이션 | A(기본)만 |
| 차선 | 황색 점선 + 흰색 실선 | 생략 |
| 갓길 오브젝트 밀도 | 높음 | 낮음 (50% 수준) |
| 스크롤 방향 | 아래→위 (전방으로) | 위→아래 (후방으로) |
| 스크롤 속도 | 차량 속도에 비례 | 전방과 동일 속도 |
| 커브 | 구간별 적용 | 전방과 반대 방향 |

### 포커싱 중 페널티

- 전방 집중도 저하: 도로 위협 반응 판정 시간 +0.15초
- 정신력 30 이하 포커싱 해제 후: 괴물 실루엣 잔상이 0.5초간 얼굴 위에 겹쳐 보임

### 괴물 거리 단계 (포커싱 시 룸미러 내 크기)

```
[안전]     룸미러: 수평선 위 희미한 점
[경계]     룸미러: 형태 윤곽. 다리가 여럿임
[위험]     룸미러: 거울 면적 40~60% 차지. 디테일 식별
[임박]     룸미러: 거울 거의 가득 참. 정신력 강제 감소 시작
[따라잡힘] 룸미러 밖으로 넘침 → 게임 오버 (엔딩 E)
```

## 괴물 이동 속도 파라미터

괴물의 절대 이동속도: **90 km/h (고정)**. 플레이어 차량 속도와의 차이가 간격 변화를 결정한다.

| 플레이어 속도 | 간격 변화율 | 룸미러 변화 |
|------------|-----------|-----------|
| 140 km/h (최고속) | -2m/s (멀어짐) | 천천히 작아짐 |
| 120 km/h (일반 최고) | -0.5m/s (유지~멀어짐) | 거의 변화 없음 |
| 80 km/h (기본) | 간격 유지 | 변화 없음 |
| 50 km/h (감속) | +3m/s (가까워짐) | 서서히 커짐 |
| 0 km/h (갓길 정지) | +8m/s (빠르게 가까워짐) | 빠르게 커짐 |
| 거점 정박 중 | 정지 (추격 일시 정지) | 정비 구간 — 괴물 접근 없음 |

## 괴물의 정체

명시하지 않는다. 포커싱 모드 룸미러로만 보인다. 설계 원칙:
- 형태: 거대하고 다리가 여럿. 천천히 움직이는데도 빠르다
- 소리: 없음. 가까워져도 엔진 소리만 들림
- 컬트와의 관계: 암시만. 컬트가 도로 밖으로 밀려나 있는 이유가 괴물 때문일 수 있으나 확정하지 않음

## 괴물 관련 혼잣말 스크립트

```
[게임 시작, 처음으로 F 키를 누름]
운전자: (침묵. 대사 없음)

[경계 단계 — 얼굴이 긴장 표정으로 바뀜]
운전자: "...뒤 보지 마. 앞만 봐."

[위험 단계 진입]
운전자: "빨리. 더 빨리."

[임박 단계 — 얼굴이 먼저 공황 표정으로 바뀐 뒤]
운전자: "안 돼. 안 돼. 안 돼—"

[포커싱 해제 후 잔상 발생 시 (정신력 30 이하)]
운전자: "...아직 거기 있어?"

[정신력 30 이하 + 임박 단계]
운전자: "...다 왔어. 거의 다 왔어." (무엇이 다 왔는지 불명)
```

---

## 엔딩 E — 따라잡힘

룸미러 포커싱 시 괴물이 화면 밖으로 넘치는 순간 화면 암전. 엔진 소리가 끊긴다. 타임코드 정지. 그 다음은 아무것도 없다.

---

## 예시 시나리오

> 갓길에 희귀 파츠가 보인다. 룸미러엔 주인공 얼굴이 긴장 표정이다. F를 누르니 경계 단계. 멈추면 8m/s로 가까워진다. 30초 수색이면 약 240m 손실. 다음 거점까지 여유가 있을까? 고민하는 것도 시간이다.
