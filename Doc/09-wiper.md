# 9. 와이퍼 시스템

**목적**: 비 오는 구간에서 시야 관리를 플레이어가 직접 수행. 와이퍼 리듬이 공포 연출의 도구가 된다.

## 기본 구조

비가 오는 구간에서 빗물이 앞유리에 점점 쌓인다. 와이퍼를 켜지 않으면 시야가 서서히 흐려져 도로 위협 감지가 어려워진다. 기름 소모와는 무관하다.

## 조작

| 입력 | 동작 |
|------|------|
| `Z` 한 번 또는 와이퍼 오브젝트 좌클릭 | 와이퍼 1단 (느림) |
| `Z` 두 번 또는 좌클릭 | 와이퍼 2단 (빠름) |
| `Z` 세 번 또는 좌클릭 | 와이퍼 끔 |

## 빗물 누적 속도 vs 와이퍼 제거 속도

| 상태 | 시야 변화율 |
|------|-----------|
| 와이퍼 끔 | 시야 -3%/초 |
| 와이퍼 1단 | 시야 유지 (누적 = 제거) |
| 와이퍼 2단 | 시야 +2%/초 (빠르게 회복) |

시야 0% 도달 시 앞유리 완전 불투명. 도로·위협 식별 불가.

> 와이퍼는 부품 내구도(LF/RF/LB/RB/구동계)와 무관한 독립 시스템이다. 부품이 펑크 나거나 구동계가 망가져도 와이퍼는 정상 작동한다.

## 공포 연출 — 와이퍼 리듬

와이퍼가 한쪽으로 넘어가며 빗물을 걷어내는 순간 컬트 실루엣이 **0.5초간 선명하게** 드러났다가 다시 빗물에 흐려진다. 와이퍼 주기에 맞춰 보였다 안 보였다를 반복하는 구조.

```
[와이퍼 좌→우 스윕]
  → 빗물 제거, 컬트 실루엣 선명하게 등장 (0.5초)
[와이퍼 정지 구간]
  → 빗물 재적층, 실루엣 흐려짐
[와이퍼 우→좌 스윕]
  → 다시 선명해짐 — 실루엣이 더 가까워져 있음
```

## 라디오 연동

와이퍼 작동 중 라디오 수신 상태가 불안정해진다. 죽음의 주파수 전환 주기가 일시적으로 짧아지거나 안전 주파수가 잠깐 죽음의 주파수로 흔들리는 식으로 압박이 가중된다 ([18-radio.md](18-radio.md) — 와이퍼 연동 참조). 명시하지 않음. 플레이어가 패턴을 눈치채는 구조.

## 정신력 연동

정신력 50 이하에서 와이퍼가 걷어낸 자리에 없는 실루엣이 0.3초간 나타났다 사라진다. 실제 컬트와 픽셀 디테일이 동일해서 구분 불가.

## 채도 감소 시너지

빗물이 쌓인 유리 + 무채색화가 결합되면 세계가 더 빠르게 색을 잃는다. 시야가 흐릴수록 채도 감소 강도가 +0.2 추가 적용.

## 사운드

| 상황 | 사운드 |
|------|--------|
| 와이퍼 1단 | 규칙적인 저음 스윕음 (1.8초 주기) |
| 와이퍼 2단 | 빠른 스윕음 (0.9초 주기) |
| 빗소리 | 루프. 강도는 구간별 고정 |

## 예시 시나리오

> 2구간 진입 후 비가 내리기 시작한다. 와이퍼를 켜지 않으면 30초 후 시야 -90%. 1단으로 켜두면 시야는 유지되는데, 와이퍼가 스윕할 때마다 갓길 컬트가 잠깐씩 보인다. 2단으로 올리면 더 자주 보인다. 끄면 안 보이지만 시야가 막힌다.
