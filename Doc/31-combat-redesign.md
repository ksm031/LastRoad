# 31. 전투 재설계안 — 속도 처치 시스템

**상태**: 개선 제안 문서. 기존 문서(19-enemies, 29-blood-orb, 02-core-loop 등)를 직접 수정하지 않음. 구현 단계에서 검토 후 반영.

**설계 원칙**: 차는 무기다. 속도는 탄환이고, 내구도는 탄약이다.

---

## 1. 핵심 변경 — 속도 임계 처치

지금까지 "충돌 = 내구도 소모 + BO 획득 (정산)"이었던 걸, **속도에 따라 결과가 갈리는 처치 판정**으로 바꾼다.

### 임계 속도 (Kill Threshold)

| 충돌 속도 | 결과 | 내구도 소모 | BO | 속도 감소 |
|---------|------|-----------|-----|---------|
| **임계 이상** | 관통 처치 | 소량 (-1~2%) | 획득 (기존값) | 없음. 모멘텀 유지 |
| **임계 미만** | 충격 튕김 | 대량 (-4~8%) | 없음 | 급감속 (-30~40%) |

임계 속도 기준값: **80 km/h** (엔진 업그레이드로 최대 65 km/h까지 하향 가능).

### 설계 의도

"같은 적이 상황에 따라 사냥감이 되거나 흉기가 된다."

```
80 km/h 이상으로 달리던 중 와쳐 발견
  → 회피할 수도, 그냥 밀어버릴 수도 있다

50 km/h로 파밍 복귀 중 와쳐 발견
  → 반드시 피해야 한다. 치면 크게 다친다
```

속도 딜레마가 전투와 직결된다. 빠르면 사냥이 쉽고, 느리면 모든 적이 위협이다.

### 적별 임계 속도

| 적 | 기본 임계 (80 km/h 기준) | 비고 |
|----|----------------------|------|
| 와쳐 | 80 km/h | 정적 장애물 |
| 러너 | 85 km/h | 이동 중이라 상대 속도 고려 |
| 워커 | 80 km/h | 횡단 중 충돌 방향 따라 다름 |
| 앰부서 | 90 km/h | 갑작스럽게 뛰쳐나오므로 더 높은 속도 필요 |
| 컬트원 (행렬) | 75 km/h | 저항력이 낮은 인간형 |
| 컬트 우두머리 | 100 km/h | 단일 최고 임계값. 고속에서만 처치 가능 |
| 사슴머리 | 처치 불가 | 기존 통과 시스템 유지 |

## 2. 처치 피드백 (Juice)

"치는 것 자체가 기분 좋다"는 느낌. 이게 없으면 전투가 전산 처리로 남는다.

### 임계 이상 처치 시 (성공 킬)

| 요소 | 사양 |
|------|------|
| **히트스톱** | 0.05초. 화면 전체 순간 정지 |
| **카메라 셰이크** | 3픽셀 반경, 0.1초 |
| **붉은 안개** | 충돌 지점에서 파티클 분출 → 0.3초에 걸쳐 BO로 응축·흡수 |
| **사운드** | 충격음 (묵직한 타격음) + BO 흡수 '띵' |
| **BO 카운터** | 팝업 애니메이션 (+N) |

### 임계 미만 충돌 시 (실패 / 손상)

| 요소 | 사양 |
|------|------|
| 히트스톱 | 없음 |
| 카메라 셰이크 | 더 강하고 길게 (불쾌한 방향) |
| 사운드 | 금속 긁힘 + 차체 둔탁한 충격음 |
| 속도 표시 | 급감속 연출 (계기판 속도 빠르게 떨어짐) |

성공과 실패의 피드백이 명확히 다르다. 성공이 더 시원하고, 실패가 더 불쾌하게.

## 3. 숨겨진 콤보 (Hidden Combo)

**UI 없음.** 콤보 카운터·게이지 화면에 표시하지 않는다.

### 이유

콤보 UI는 분위기를 해친다. 공포 호러 게임에서 × 콤보 팝업은 게임성을 과하게 드러낸다. 또한 갓길 파밍이나 감속이 필요한 순간에 "콤보 유지"가 강제처럼 느껴질 수 있다.

숨겨진 콤보는 **잘하는 플레이어가 자연스럽게 체감하는 보상**이다. 알면 더 잘할 수 있지만 모르면 그냥 많이 버는 것처럼 느껴진다.

### 동작 방식

```
연속 처치 간격 4초 이내 → 내부 콤보 카운터 누적
처치 간 4초 초과 / 임계 미만 충돌 / 급감속 → 콤보 리셋
```

| 콤보 단계 | BO 배수 | 플레이어 단서 |
|---------|--------|------------|
| 없음 | ×1 | — |
| 2연속 | ×1.3 | BO 흡수 사운드 음높이 미세 상승 |
| 3연속 | ×1.6 | BO 흡수 사운드 음높이 추가 상승 |
| 4연속+ | ×2.0 | 사운드 최고조 (이 이상 배수 상승 없음) |

눈에 보이는 피드백은 없고 오직 BO 흡수 사운드 음높이만 올라간다. 감각으로 익히는 것.

## 4. 점퍼 재설계

### 기존 문제

현재 점퍼의 "핸들 흔들기 탈출"은 **수동적·지속적·집중도 낮은** 미니게임이다. 핸들을 좌우로 흔들면서 몇 초를 보내는 방식이 새 전투 방향과 맞지 않는다. 전투가 공격적·속도 중심으로 변하는데 점퍼만 "버텨내기" 패턴이다.

### 개선안

속도로 던져내기. **핸들 흔들기 게이지 삭제. 대신 임계 속도 돌파로 처리.**

```
점퍼와 충돌
  → 임계 속도 이상: 처치. 보닛에 올라타지 않음. 기존 킬 처리.
  → 임계 속도 미만: 보닛에 올라탐 (기존과 동일)
  
보닛 탑승 상태:
  → 100 km/h 이상 가속 달성 시: 점퍼 분리, 8 BO 획득
  → 100 km/h 미달 지속: 정신력 -1/초 (기존과 동일)
```

탈출 방법이 **"빠르게 달려라"**가 된다. 전투 방향과 일치한다.

| 상황 | 행동 | 결과 |
|------|------|------|
| 고속 진입 → 점퍼 발견 | 속도 유지 또는 상승 | 즉시 처치. 콤보 유지. |
| 감속 중 점퍼 충돌 | 즉시 가속 | 빠르게 달성하면 BO + 콤보 |
| 감속 중 점퍼 충돌 후 장애물 밀집 구간 | 가속이 어려운 상황 | 정신력 계속 깎이며 딜레마 |

점퍼가 "가속을 못하게 가로막는 존재"에서 "가속으로 해결하는 존재"로 전환된다.

---

## 5. 새로운 속도 딜레마 구조

속도 임계 처치 시스템이 추가되면 기존 속도 딜레마에 **전투 축**이 생긴다.

| 속도 | 기존 | 추가 |
|------|------|------|
| 고속 | 연료 소모↑, 반응시간↓, 괴물 거리 유지 | **적 처치 가능, 콤보 유지 가능, BO 획득** |
| 저속 | 파밍 가능, 괴물 접근 | **적 회피 필수, 피격 시 대량 손상** |

빠른 플레이의 보상이 생존(괴물 거리)에서 **전투+생존+수익** 세 축으로 확장된다.

## 6. 미구현 항목 (추후 문서화)

- 범퍼 파츠 신설 (임계 속도 하향, 관통 수 증가 — 무기 파츠)
- 전투 부적 아키타입 (콤보형, 임계형, 흡혈형, 관통형)
  - 흡혈형: "처치 시 내구도 회복"은 강력하므로 **발동 조건부** (예: 콤보 3이상 / 정신력 30 이하 / 스테이지 후반부 한정) 또는 **대가 있음** (예: 흡혈 시 정신력 -5) 으로 설계
- BO 충각 부스트 (런 중 BO 소비로 임계 속도 즉시 돌파)
- 스테이지 1 전투 튜닝 (임계 속도 환경에서 와쳐가 첫 사냥감으로 기능하도록)
