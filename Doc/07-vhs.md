# 7. VHS 연출 시스템

**목적**: HUD를 최소화하고 화면 자체가 자원 계기판이 되도록 설계.

## 자원 상태 → 화면 효과 매핑

| 자원 | 임계값 | 화면 효과 |
|------|--------|---------|
| 기름 | 40% 이하 | 화면 하단 서서히 어두워짐 |
| 기름 | 15% 이하 | 엔진 소리 변화 + 화면 전체 적색 비네트 |
| 라디오 죽음의 주파수 | 활성 중 | 대시보드 전체에 붉은 조명. 라디오 디스플레이에서 새어나오는 빛. 안전 주파수로 전환 즉시 소등 |
| 라이트 파츠 내구도 | 50% 이하 | 시야 범위 감소 시작 |
| 라이트 파츠 파괴 | — | 헤드라이트 소멸, 극단적 시야 제한 |
| 타이어 파츠 파괴 | — | 화면 좌우 흔들림 지속 |
| 정신력 | 70 이하 | VHS 그레인 강도 증가 + 색수차 강도 0.3→0.6 |
| 정신력 | 50 이하 | 색수차 강도 1.2, 수직 색 분리 시작 |
| 정신력 | 30 이하 | 색수차 강도 2.0, 간헐적 화면 롤링 |
| 정신력 | 10 이하 | 색수차 강도 3.5, 화면 거의 식별 불가 |
| 빗물 누적 (와이퍼 끔) | 시야 50% 이하 | 앞유리 반투명 오버레이 + 색수차 +0.2 |
| 빗물 누적 (와이퍼 끔) | 시야 0% | 앞유리 완전 불투명. 도로 식별 불가 |

> 색수차 상세 수치 및 셰이더 구현은 [12-art-direction.md](12-art-direction.md) 참조.

## VHS 기본 레이어 (항상 적용)

- 스캔라인 오버레이 (불투명도 15%)
- 필름 그레인 (강도 0.08)
- 색온도 웜톤 (노란빛 틴트)
- **색수차 기본 강도 0.3 (항상 미세하게 존재)**
- 우하단 타임코드 표시 (HH:MM:SS 형식, 새벽 2시~5시대)
- 간헐적 테이프 글리치 (30~60초 랜덤 간격, 0.3초 지속)
