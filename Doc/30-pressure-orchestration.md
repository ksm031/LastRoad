# 30. 동시 압박 조율 (Pressure Orchestration)

**목적**: Last Road는 "산만하게 조작을 잘해야 하는 게임"이 정체성이다. 하지만 *산만함*과 *혼란*은 다르다. 두 시스템이 같은 1초에 같은 자원(시각·청각·손·인지)을 동시에 요구하면 플레이어는 우선순위를 세울 수도, 처리할 수도 없다 — 긴장이 아닌 무력감이 발생한다.

이 문서는 게임 내 모든 압박 시스템이 *언제 동시에 발동할 수 있고 언제 잠겨야 하는지*를 단일 출처로 정의한다. 각 적·라디오·와이퍼·창·사슴머리 문서는 이 규칙을 참조한다.

---

## 1. 압박 분류 — 채널 × 지속시간

### 1.1 채널 (어느 자원을 요구하는가)

| 채널 | 의미 | 자원 예시 |
|------|------|----------|
| **시각(VIS)** | 화면 어디를 보는가 | 전방 도로, 룸미러, 라디오 줌, 와이퍼 시야, 인벤토리 UI, 조수석 환영 |
| **청각(AUD)** | 어느 소리에 반응하는가 | 라디오 방송, 창 들숨 경고, 엔진 노킹, 컬트 합창, BO 흡수음 |
| **손(HND)** | 어느 입력을 하는가 | 핸들 ←→, 가속↑↓, F(룸미러), V(라디오), Z(와이퍼), 마우스 드래그/클릭 |
| **인지(COG)** | 어느 판단을 하는가 | 속도 선택, 차선 변경 방향, 정차 여부, 컬트 관통/회피, 사슴머리 통과 속도 |

### 1.2 지속시간 (얼마나 오래 자원을 점유하는가)

| 단계 | 시간 | 의미 |
|------|------|------|
| **스파이크(SPK)** | 1~3초, 단일 결정 | 창 회피, 사슴머리 통과 속도 결정, 점퍼 부착 직후, BO 흡수, 행렬 관통 결정 |
| **지속(SUS)** | 10~30초, 연속 관리 | 라디오 죽음의 주파수, 빗물 누적, 갓길 수색 중, 점퍼 부착 중, 비 구간 |
| **배경(BG)** | 항상 켜져 있음 | 괴물 접근, 기름 소모, 정신력 채도, 부적 효과, 조수석 환영, 앞유리 균열 |

## 2. 시스템 분류 매트릭스

각 시스템이 어느 채널 × 어느 지속시간에 속하는지 명시.

| 시스템 | 채널 | 지속시간 | 비고 |
|--------|------|---------|------|
| 괴물 접근 | COG | BG | 룸미러 확인 빈도가 압박 강도 결정 |

| 정신력·채도 | VIS | BG | 무채색화 |
| 조수석 환영 | VIS | BG | 정신력 50/30/10 단계 |
| 부적 효과 발광 | VIS | BG | 대시보드 인형 흔들림 |
| 앞유리 균열 | VIS | BG | 누적 손상 표시 |
| 전방 장애물 (포트홀·낙석) | VIS+COG | SPK | 차선 변경 1.5~3초 |
| 와쳐 회피 | VIS+COG | SPK | 차선 변경 |
| 러너 인식·돌진 | VIS+COG | SPK | 가속 결정 1~2초 |
| 워커 타이밍 | VIS+COG | SPK | 빈 공간 통과 |
| 앰부서 등장 | VIS+COG | SPK | 0.5초 반응 |
| 점퍼 부착 | VIS+HND | SUS | 시야 차단 + 핸들 흔들기 |

| 라디오 죽음의 주파수 | VIS+HND | SUS | V키 줌 + 다이얼 드래그 |
| 와이퍼 작동 결정 | HND | SPK | Z키 1회 |
| 비 구간 시야 관리 | VIS | SUS | 빗물 누적 30초 |
| 갓길 수색 | VIS+HND | SUS | 인벤 8~13초 |
| BO 도로 오브 수집 | VIS+HND | SPK | 차선 미세 조정 |
| 정비 구간 | (없음) | — | 모든 압박 해제 |

## 3. 동시 발생 규칙

### 3.1 핵심 규칙

> **같은 채널에서 스파이크 2개를 동시에 발생시키지 않는다.**

배경(BG)은 다른 모든 압박과 자유롭게 공존한다. 지속(SUS)은 스파이크(SPK) 1개와 공존 가능. 스파이크끼리는 서로 다른 채널일 때만 동시 발생.

### 3.2 동시 발생 매트릭스

| | 시각 SPK | 청각 SPK | 손 SPK | 인지 SPK |
|---|---------|---------|--------|---------|
| 시각 SPK | ❌ | ✅ | ✅ | ⚠️ |
| 청각 SPK | ✅ | ❌ | ✅ | ⚠️ |
| 손 SPK | ✅ | ✅ | ❌ | ✅ |
| 인지 SPK | ⚠️ | ⚠️ | ✅ | ❌ |

- ✅ 허용
- ❌ 금지 — 한 채널 내 동시 스파이크 불가
- ⚠️ 조건부 — 인지 부담이 가벼우면 허용. 둘 다 무거운 결정(사슴머리 + 행렬 관통)은 금지.

### 3.3 구체적 충돌 예시

다음 조합은 절대 같은 1초 안에 발생시키지 않는다.

| 충돌 | 채널 | 해결책 |
|------|------|--------|
| 창 윈드업 + 사슴머리 등장 | VIS+COG | 최소 5초 간격 |
| 창 윈드업 + 라디오 죽음의 주파수 전환 | VIS | 5초 간격 |
| 행렬 컬트 + 사슴머리 | COG | 다른 구간에 배치 |
| 앰부서 + 와이퍼 끔 + 컬트 행렬 | VIS 과부하 | 동시 발생 금지 |
| 점퍼 부착 직후 + 창 윈드업 | VIS (점퍼가 시야 절반 가림) | 점퍼 부착 후 8초간 창 빈도 -50% |

## 4. 시스템 상호 잠금 (Inter-System Locks)

특정 시스템이 활성화된 동안 다른 시스템의 신규 트리거를 보류하거나 약화시킨다. 게임을 쉽게 만드는 것이 아니라 **"하나 처리하는 동안 다른 게 쌓이지 않는다"는 약속**.

| 활성 시스템 | 잠그는 대상 | 동작 |
|-----------|-----------|------|
| 라디오 줌인 (V키) | 창 윈드업 | 신규 윈드업 보류 (V키 해제 후 최소 2초 뒤 발동) |
| 라디오 줌인 | 죽음의 주파수 전환 | 이미 시작된 전환은 진행. 신규 전환은 V 해제 후로 |
| 인벤토리 열림 (B키, 차 멈춤) | 라디오 전환, 창, 적 스폰 | 모두 보류. 단 괴물 접근은 정상 (시간 흐름) |
| 점퍼 부착 중 | 신규 점퍼 | 등장 안 함 |
| 점퍼 부착 중 | 창 | 빈도 -50% |
| 점퍼 부착 중 | 사슴머리 | 등장 안 함 (스테이지 6 한정 적용) |
| 창 비행 중 (0.8~1.2초) | 신규 창 윈드업 | 비행 종료 후 최소 5초 |
| 사슴머리 통과 ±0.5초 | 창, 라디오 전환, 적 스폰 | 모두 정지 (의식적 순간 보장) |
| 사슴머리 통과 직후 5초 | 모든 적 스폰 | 정지 (회복 윈도우) |
| 행렬 컬트 통과 ±0.5초 | 창, 라디오 전환 | 보류 |
| 정신력 0 진입 직후 | 환각 위협 외 모든 신규 스폰 | 환각이 우선 압박 |
| 와이퍼 끔 + 시야 30% 이하 | 앰부서 | 등장 안 함 (시야 회복 후 가능) |
| 정비 구간 | 전체 | 모든 압박 해제 |

## 5. 숨 비트 (Breath Beat)

각 스테이지에 **5~10초 정적 윈도우**를 일정 간격으로 보장한다. 자연 위협만 있고 적·라디오 전환·창은 발동하지 않는다. 플레이어가 룸미러를 한 번 보고 인벤토리를 정리하고 호흡을 가다듬을 시간.

| 스테이지 | 숨 비트 간격 | 윈도우 길이 |
|---------|-----------|-----------|
| 1 | 60초 | 15초 (튜토리얼 — 여유) |
| 2 | 75초 | 12초 |
| 3 | 90초 | 10초 |
| 4 | 100초 | 8초 |
| 5 | 120초 | 7초 |
| 6 | 150초 | 5초 (가장 짧은 호흡) |

호흡 없이 4분 이상 풀 압박이 유지되면 사람은 적응하지 못하고 무기력해진다. 숨 비트는 *난이도를 깎는 것*이 아니라 *난이도를 유지 가능하게 만드는 페이싱 장치*다.

## 6. 적응형 압박 (Adaptive Pressure)

플레이어의 현재 상태에 따라 압박 강도를 동적으로 조정한다. 게임이 "당신이 지금 처리 중인 일을 인식하고 있다"는 신호.

| 플레이어 상태 | 조정 |
|------------|------|
| 정신력 20 이하 | 라디오 죽음의 주파수 전환 주기 +20% (이미 충분히 힘들다) |
| 정신력 0 진입 | 환각 위협 빈도 +50%, 다른 적 스폰 -30% |
| 펑크 2개 이상 | 창 빈도 -30%, 신규 적 스폰 -20% |
| 구동계 0% (고장) | 창 빈도 -50%, 사슴머리 외 모든 스폰 -30% |
| 점퍼 부착 중 | §4 잠금 규칙 적용 |
| 사슴머리 통과 직후 10초 | 모든 적 스폰 정지 |
| 기름 15% 이하 | 폐차 등장 확률 +30% (구원 가능성) |
| 정비 구간 직전 1km | 모든 신규 스파이크 보류 (도착 보장) |
| BO 누적 200 초과 | 도로 오브 스폰 -20% (한계 효용 체감) |

게임은 플레이어를 죽이려는 게 아니라 *처리 가능한 페이스를 유지하면서 점진적으로 압박을 쌓는다.*

## 7. 스테이지별 압박 타임라인

각 스테이지 길이는 약 5~7분으로 가정. 분 단위로 어느 시스템이 활성·휴면인지 명시.

### 7.1 스테이지 1 — 튜토리얼 (5분)

```
0:00 ──── 1:00 ──── 2:00 ──── 3:00 ──── 4:00 ──── 5:00
[BG] 괴물 70 km/h ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[BG] 정신력 100→90 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[SPK] 포트홀                 ▲              ▲
[SPK] 와쳐                          ▲                    ▲
[SUS] 갓길 폐차 (안전)        ▓▓▓                ▓▓▓
[숨 비트] 정적              ___              ___        ___
```

규칙:
- 라디오 죽음의 주파수: 발동 안 함
- 창: 발동 안 함
- 컬트: 갓길만 (드뭄)
- 와이퍼: 비 없음
- 도망자: 등장 없음
- 사슴머리: 등장 없음
- 단 두 개의 적 시스템(포트홀, 와쳐)을 5분에 걸쳐 학습

### 7.2 스테이지 3 — 첫 행렬 컬트 + 첫 창 (6분)

```
0:00 ──── 1:00 ──── 2:00 ──── 3:00 ──── 4:00 ──── 5:00 ──── 6:00
[BG] 괴물 90 km/h ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[BG] 정신력 ~70 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[SUS] 라디오 죽음의 주파수      ▓▓▓        ▓▓▓        ▓▓▓
[SPK] 창 (1.5초 윈드업)                ♦              ♦         ♦
[SPK] 행렬 컬트                          ●                    ●
[SPK] 점퍼                  ▲                    ▲
[SPK] 와쳐·러너·앰부서   ▲   ▲     ▲      ▲      ▲    ▲
[숨 비트]                  __              __              __
```

규칙:
- 창 ♦와 라디오 전환 ▓ 간격 최소 5초
- 행렬 컬트 ● 와 창 ♦ 간격 최소 8초 (둘 다 인지 스파이크)
- 점퍼 부착 중에는 창 빈도 -50%
- 라디오 안전 구간 폭 1.5 MHz (3스텝) — 찾기 쉬움

### 7.3 스테이지 5 — 야간 + 우천 (7분)

```
0:00 ──── 1:00 ──── 2:00 ──── 3:00 ──── 4:00 ──── 5:00 ──── 6:00 ──── 7:00
[BG] 괴물 110 km/h ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[BG] 정신력 채도 50% ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[SUS] 비/와이퍼 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
[SUS] 라디오 (75초 주기)   ▓▓▓      ▓▓▓      ▓▓▓      ▓▓▓      ▓▓▓
[SPK] 창 (1.0초)             ♦         ♦         ♦         ♦
[SPK] 행렬 컬트                   ●              ●              ●
[SPK] 점퍼·앰부서·워커  ▲▲   ▲    ▲   ▲▲     ▲     ▲   ▲    ▲▲
[SPK] 환각 (정신력 40 이하)              ◇                ◇
[숨 비트]                    __                    __
```

규칙:
- 비는 풀타임 — 와이퍼 관리 지속
- 라디오 안전 구간 폭 1.0 MHz (2스텝) — 찾기 어려움
- 창 ♦ 와 행렬 ● 간격 최소 8초
- 와이퍼 끔 + 시야 30% 이하 시 앰부서 보류
- 정신력 40 이하 진입 시 환각 ◇ 등장. 환각은 다른 적 스파이크와 같은 1초에 발생 안 함
- 숨 비트 2회 — 7분 중 14초의 정적

### 7.4 스테이지 6 — 사슴머리 + 모든 시스템 (8분)

```

[SUS] 라디오 (60초)  ▓▓▓  ▓▓▓  ▓▓▓  ▓▓▓  ▓▓▓  ▓▓▓  ▓▓▓  ▓▓▓
[SPK] 창 (0.8초)        ♦    ♦    ♦    ♦    ♦       ♦    ♦    ♦
```

## 8. 스폰 매니저 구현 지침

`spawn_config.gd` 및 각 적 시스템의 스폰 로직은 본 문서의 규칙을 따라야 한다. 핵심 의사 코드:

```gdscript
# 추상 스폰 결정 흐름
func can_spawn(enemy_type, current_time) -> bool:
    # 1. 시스템 잠금 체크
    if is_locked(enemy_type): return false

    # 2. 채널 × 지속시간 충돌 체크
    var slot = get_pressure_slot(enemy_type)
    if active_spikes_in_channel(slot.channel) > 0 and slot.duration == SPK:
        return false

    # 3. 숨 비트 윈도우 체크
    if is_in_breath_beat(current_time): return false

    # 4. 적응형 압박 체크
    if player_state_lockout(enemy_type): return false

    # 5. 스파이크 간격 체크 (최소 간격 미충족 시 거부)
    if time_since_last_spike(slot.channel) < MIN_SPIKE_GAP:
        return false

    return true
```

각 시스템(`watcher_system.gd`, `jumper_system.gd`, 신규 `walker_system.gd`, 행렬 컬트, 사슴머리, 창 발사 로직)은 이 함수를 통과한 경우에만 트리거 실행.

플레이테스트 중 압박 조율 검증을 위한 디버그 오버레이를 권장한다.

## 10. 다른 문서와의 관계

- 본 문서가 모든 스폰·트리거 타이밍의 **단일 출처**다.
- 각 시스템 문서(`08-monster-chase`, `09-wiper`, `18-radio`, `19-enemies`)는 자체 스폰 규칙이 아닌 본 문서를 참조한다.
- 신규 적·시스템 추가 시 본 문서의 분류 매트릭스(§2)에 항목 추가가 필수.
- 밸런스 조정 시 본 문서의 적응형 압박(§6)과 숨 비트(§5)부터 검토.
