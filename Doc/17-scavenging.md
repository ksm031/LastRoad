# 17. 갓길 수색 시스템

**목적**: 멈추는 행위 자체가 위험인 게임에서, 멈춰서 얻는 보상과 그 대가(괴물 접근 + 시간 압박)를 인벤토리 조작으로 직접 체감하게 한다.

---

## 폐차 스폰 시스템

폐차는 각 구간 갓길에 랜덤 위치로 배치된다. 스폰 결정 시점은 구간 진입 시.

### 스폰 매니저 (검토 중)

레포데 매니저 방식 참고. 플레이어의 현재 자원 수준을 읽어 드롭 구성을 조정한다.

```
기름 부족 → 기름통 포함 폐차 스폰 확률 상승
현금 부족 → 귀중품 등급 잡품 드롭 확률 상승
파츠 전반 손상 → 중고 파츠 드롭 확률 상승
```

자원이 풍족할 때는 드롭 구성이 더 무작위적으로 동작. 절박할수록 필요한 게 보이는 구조.

> 스폰 매니저는 현재 검토 단계. 확정 전까지는 단순 랜덤 드롭 테이블로 구현.

### 기본 드롭 테이블

폐차에서 나오는 아이템은 두 종류다. **즉시 사용 가능한 소모품**과 **거점에서 팔아 현금으로 바꾸는 잡품**. 

> **중요**: 폐차 수색에서는 블러드 오브를 획득할 수 없다. 블러드 오브는 적 타격과 도로 위 떠있는 오브를 통해서만 획득 가능. 폐차 파밍은 순수하게 **현금(₩)을 위한 행동**으로 설계되었다.

#### 소모품

| 아이템 | 스폰 확률 | 효과 | 사용 시점 |
|--------|---------|------|---------|
| 기름통 (10L) | 25% | 연료 +10L | 주행 중 즉시 |
| 담배 | 15% | 정신력 +20 | 주행 중 즉시 |
| 응급 패치킷 | 20% | 타이어 1개 펑크 1회 임시 봉합 (다음 정비 구간 도착까지) | 주행 중 인벤 |

#### 잡품 (정비 구간 상인에게 판매 → 현금)

각 잡품은 폐차마다 **독립 확률**로 스폰 판정. 한 폐차에서 여러 아이템이 동시에 등장 가능.

**고철류** (흔함)

| 아이템 | 스폰 확률 | 판매가 |
|--------|---------|------|
| 고철 덩어리 | 60% | ₩300 |
| 알루미늄 캔 묶음 | 45% | ₩500 |
| 동선 묶음 | 30% | ₩1,000 |

**차량 부품류** (보통)

| 아이템 | 스폰 확률 | 판매가 |
|--------|---------|------|
| 와이퍼 블레이드 | 25% | ₩1,000 |
| 오일 필터 | 22% | ₩1,500 |
| 스파크 플러그 세트 | 18% | ₩2,000 |
| 중고 배터리 | 13% | ₩3,000 |
| 사이드미러 | 9% | ₩4,000 |

**생활용품** (보통)

| 아이템 | 스폰 확률 | 판매가 |
|--------|---------|------|
| 통조림 | 22% | ₩2,000 |
| 손전등 | 18% | ₩3,000 |
| 상비약 세트 | 12% | ₩5,000 |
| 공구 세트 | 8% | ₩7,000 |

**귀중품** (희귀)

| 아이템 | 스폰 확률 | 판매가 |
|--------|---------|------|
| 스마트폰 | 4% | ₩10,000 |
| 지갑 | 6% | ₩10,000 |
| 금반지 | 2% | ₩20,000 |
| 군용 물자 | 2% | ₩25,000 |

> 위 값은 `inventory_manager.gd`의 `WRECK_DROP_RATES` / 판매가 정의와 일치한다. 확률 합계가 100%를 넘는 이유: 각 아이템 종류가 폐차마다 독립적으로 판정되어 동시에 여러 종류가 등장 가능. 밸런스 조정은 코드 값을 통해 진행.

#### 폐차 한 대당 기대 수익 (이론치)

| 카테고리 | 기대 수익 |
|---------|---------|
| 고철류 (3종) | ₩705 (180+225+300) |
| 차량 부품류 (5종) | ₩1,690 |
| 생활용품 (4종) | ₩2,140 |
| 귀중품 (4종) | ₩1,900 |
| **소계** | **약 ₩6,435 / 폐차** |

플러스 소모품 가치: 기름통(0.25개) + 담배(0.15개) + 패치킷(0.20개) — 직접 사용 시 ₩4,000~₩6,000 가치.

실제 수익은 폐차당 머문 시간(인벤 수색 진행도)에 비례. 완전 수색은 비현실적이므로 50~70% 정도가 일반적 수익.

폐차 인벤토리 크기는 **폐차 차종에 따라 다르다**. 열은 8로 고정, 행은 10~16 사이에서 1행 단위로 증가한다 (`inventory_manager.gd` WRECK_COLS=8, WRECK_ROWS=10~16). 슬롯이 많을수록 수색 시간이 길어지므로 폐차 크기 자체가 위험도 지표가 된다.

| 인벤토리 크기 | 총 슬롯 수 | 완전 탐색 시간 |
|-------------|----------|-------------|
| 8 × 10 (최소) | 80칸 | 8초 |
| 8 × 13 (중간) | 104칸 | 10.4초 |
| 8 × 16 (최대) | 128칸 | 12.8초 |

**완전 탐색은 가능하지만 위험하다.** 정차 중 괴물은 8m/s로 접근하므로 한 폐차 완전 수색 동안 약 64~102m 접근. 즉 한 스테이지에 최대 2~3대만 완전 파밍 가능. 그 이상 욕심을 내면 다음 스테이지 진입 시 괴물이 이미 임박 단계.

| 머문 시간 | 탐색 행 수 | 탐색 슬롯 수 | 괴물 접근 거리 |
|---------|----------|-----------|------------|
| 5초 | ~6행 | ~48칸 (소형 폐차 60%) | 40m |
| 10초 | ~12행 | ~96칸 (중형 풀 / 대형 75%) | 80m |
| 15초 | 풀 (소~중) / ~12행 (대형) | 80~120칸 | 120m |
| 20초+ | 풀 (전체) | 80~128칸 | 160m+ |

수색 속도는 스탯·업그레이드로 단축 가능 (기본값 0.1초/칸).

## 수색 트리거

| 조건 | 동작 |
|------|------|
| 차량 속도 **완전 정지(0 km/h)** + 폐차 인접 | 화면 좌측 또는 우측(폐차 방향)에 수색 안내 프롬프트 표시 |
| 안내 키 입력 | 인벤토리 UI 진입 |
| 차량 이동 시작 | 인벤토리 강제 종료 |

프롬프트는 **완전 정지 상태에서만** 뜬다. 저속 통과 중에는 표시되지 않는다. 폐차 방향과 프롬프트 위치가 일치한다. 왼쪽 갓길 폐차 → 프롬프트 화면 좌측.

## 인벤토리 UI 구조

```
┌──────────────────────────────────────────────────┐
│                                                  │
│  [내 차 트렁크 — 좌측]    [폐차 인벤토리 — 우측]  │
│  ┌────────────────┐       ┌────────────────┐     │
│  │ ██ │    │ ██  │       │ ?? │ ?? │ ??  │     │
│  │    │ ██ │     │       │ ?? │ ?? │ ??  │     │
│  │    │    │     │       │    │    │     │     │
│  └────────────────┘       └────────────────┘     │
│                                                  │
│  [버리기 영역 — 하단 중앙]                        │
│  ┌──────────────────────────────────────────┐   │
│  │  여기에 놓으면 버려짐                     │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  [룸미러 — 상단 중앙, 항상 표시]                  │
│                                                  │
└──────────────────────────────────────────────────┘
```

- **내 차 트렁크(좌)**: 현재 보유 아이템과 빈 슬롯 전체 표시. 즉시 접근 가능.
- **폐차 인벤토리(우)**: 수색 전까지 내용물 비공개. 수색이 진행된 칸만 드러남.
- **버리기 영역(하단)**: 아이템을 올려두면 즉시 제거. 트렁크 공간 확보 용도.

## 수색 진행 방식

폐차 인벤토리는 **칸(슬롯) 단위**로 수색된다. 수색 순서는 좌측 상단 → 우측 하단, 한 줄씩 진행.

```
수색 진행 순서:
[ 1 ] [ 2 ] [ 3 ]
[ 4 ] [ 5 ] [ 6 ]
[ 7 ] [ 8 ] [ 9 ]
```

### 칸당 프로그레스 바

각 칸 위에 **원형 프로그레스 바**가 표시된다. 한 칸이 100% 차오르면 그 칸의 내용물이 드러나고 다음 칸으로 넘어간다.

| 파라미터 | 값 |
|---------|-----|
| 칸 1개당 수색 시간 | 0.1초 |
| 수색 방향 | 좌→우, 위→아래 (한 줄 단위) |

### 세로로 긴 아이템 처리 규칙

아이템이 세로로 2칸 이상을 차지하는 경우, **해당 아이템의 최상단 행 1칸만 수색해도 아이템 전체가 드러난다**. 이미 드러난 아이템이 차지하는 나머지 칸은 수색 없이 스킵된다.

```
예시: 세로 2칸짜리 파츠가 2열 1~2행에 위치한 경우

수색 1행:  [칸①완료] → [파츠 전체 드러남. 2행 해당칸 스킵]
수색 1행:  [칸③ 진행] ...

결과: 2행 전체 수색 없이 파츠를 획득 가능
```

이 규칙 덕분에 **인벤토리 상단에 큰 아이템이 있을수록 수색 효율이 높아진다**. 드롭 배치 운이 수색 속도에 영향을 준다.

## 아이템 이동 조작

### 기본 조작

| 동작 | 마우스 | 컨트롤러 |
|------|--------|---------|
| 커서 이동 | 마우스 이동 | 왼쪽 스틱 |
| 아이템 집기 | 클릭 | A 버튼 |
| 슬롯에 놓기 | 빈 슬롯 클릭 | 슬롯 위에서 A 버튼 |
| 뒤보기 | F 키 | R2 / RT |

아이템을 집은 상태에서는 커서에 아이템이 붙어 표시된다. 놓을 수 없는 슬롯(용량 초과, 타입 불일치 등)은 시각적으로 구분된다.

### 뒤보기 중 아이템 캔슬

아이템을 **집은 상태에서 F키(뒤보기)를 누르면** 아이템이 원래 슬롯으로 자동 반환된다.

```
아이템 집기 → F키 누름
  → 아이템 원래 슬롯 복귀
  → 룸미러 포커싱 모드 전환 (괴물 거리 확인)
  → F키 떼면 인벤토리로 복귀
```

숙련 플레이어는 이 메커니즘으로 **수색과 뒤보기를 빠르게 교차**하며 위험 판단을 최적화할 수 있다.

## 실시간 진행 규칙

인벤토리가 열려 있는 동안에도 게임 시간은 멈추지 않는다.

| 상황 | 동작 |
|------|------|
| 인벤토리 열림 | 괴물 접근 지속. 시간 계속 흐름 |
| F키 누름 (뒤보기) | 수색 프로그레스 바 **일시 정지**. 룸미러 확인 가능 |
| F키 뗌 | 수색 재개 |
| 아이템 집은 상태에서 F키 | 아이템 반환 후 뒤보기 |
| 차량 이동 시작 | 인벤토리 강제 종료. 미이동 아이템 원위치 |
| 인벤토리 닫기 | 수동으로 닫거나 이동 시 종료 |

### 재방문 불가

수색을 중단하고 떠난 폐차는 **재방문할 수 없다**. 도로는 단방향이며 이미 지나친 구간으로 돌아가는 것 자체가 불가능하다.

## 예시 시나리오

> 2구간 갓길 오른쪽에 폐차가 보인다. 룸미러 얼굴이 긴장 표정이다. F를 눌러 확인하니 경계 단계. 멈추기로 한다. 차를 세우자 오른쪽에 수색 프롬프트가 뜬다. 키를 누르면 인벤토리가 열린다.
>
> 폐차 인벤(3×3)의 수색이 시작된다. 1행 1칸부터 프로그레스 바가 돌아간다. 1행 2칸에서 동선 묶음이 드러났다. 집어서 내 트렁크 빈 슬롯에 놓는다. 수색이 3칸째로 넘어가는 도중 불안해서 F키를 누른다. 수색이 멈추고 룸미러가 열린다. 위험 단계 진입. 서둘러야 한다.
>
> F키를 뗀다. 수색이 재개된다. 2행까지 드러나자 기름통이 보인다. 집으려는데 트렁크가 꽉 찼다. 파츠 하나를 버리기 영역으로 옮기고 기름통을 집어 트렁크에 넣는다. 3행은 수색할 여유가 없다. 차를 출발시키자 인벤토리가 닫힌다. 3행에 무엇이 있었는지는 영원히 모른다.
