# 6. 위협 시스템

**목적**: 점층적 공포 노출. 처음엔 일상적 위협, 후반엔 설명 불가능한 존재.

## 위협 카테고리

### A. 자연 위협 (1~2구간 중심)

| 위협 | 페널티 | 회피 방법 |
|------|--------|---------|
| 포트홀 | 타이어 -5, 차체 -3 | 차선 변경 |
| 낙석 | 차체 -15, 엔진 -8 | 속도 줄이고 회피 |
| 짙은 안개 | 시야 범위 -50%, 지속 5초 | 감속 (회피 불가) |
| 동물 사체 | 타이어 -3 | 차선 변경 |
| 이동식 검문소 | 속도 강제 감소 (기름 낭비) | 해당 차선 우회 |

### B. 적 (전 구간, 점층적)

도로 위 적의 종류·행동 패턴·충돌 효과 상세는 [19-enemies.md](19-enemies.md) 참조.

구간별 등장 조합 요약:

| 구간 | 등장 적 |
|------|--------|
| 1구간 | 와쳐 |
| 2구간 | 와쳐, 러너, 앰부서 |
| 3구간 | 와쳐, 러너, 점퍼, 앰부서 |
| 4구간 | 전 적 + 워커 + 사슴머리 |

#### 사슴머리 (보스형 위협)

- 4구간 특정 지점에서 도로 중앙에 등장
- 이동하지 않음. 헤드라이트를 바라보며 서있음
- **통과 방법 1**: 속도를 유지하고 그냥 지나침 → 아무 일도 일어나지 않음
- **통과 방법 2**: 속도를 줄이거나 멈춤 → 정신력 -40, 주변 적 전체 활성화
- **통과 방법 3**: 차량으로 밟음 → 충돌 없이 통과되나 정신력 -30, 이후 라디오 죽음의 구간 비율 증가
- 백미러 확인 시: 통과 후에도 같은 자리에 서있음

### C. 환각 위협 (정신력 50 이하 시 등장)

정신력이 낮아지면 실제 위협과 구분이 안 되는 환각이 등장한다.

- 환각은 충돌해도 파츠 손상 없음
- 그러나 회피 행동(핸들 꺾기)으로 실제 갓길 충돌 유발 가능
- 환각과 실제를 구분하는 방법: 라디오 소리가 끊기는지 여부 (힌트, 명시 안 함)
