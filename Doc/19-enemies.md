# 19. 적 디자인

**목적**: 각 적이 플레이어에게 요구하는 대응이 다르다. 속도 판단·순발력·지속 조작이 혼재해 구간마다 다른 압박을 만든다.

> 기존 06-threats.md의 컬트 위협 섹션을 대체한다. 자연 위협·환각 위협은 [06-threats.md](06-threats.md) 참조.

---

## 설계 원칙

적은 세 종류로 나뉜다.

| 분류 | 대상 | 충돌 결과 |
|------|------|---------|
| **트레이드오프 적** | 와쳐·러너·점퍼·워커·앰부서·컬트원 | 부품 내구도 감소 + **블러드 오브 획득** |
| **회피 전용 적** | 사슴머리 | 통과 시 속도 기반 피해. BO 없음 |
| **수확형 존재** | 도망자 | 소지품 드롭. 부품 손상 없음. BO 없음 |

블러드 오브 시스템 도입으로 "치면 손해"가 "치면 보상 + 비용"의 트레이드오프로 바뀌었다. 적을 칠지 피할지가 매 순간 핵심 결정. 자세한 BO 매핑은 [29-blood-orb.md](29-blood-orb.md) 참조.

플레이어 멘탈 모델: **모든 적은 자원이다. 비용을 감당할 수 있을 때만 쳐라.**

---

## 공통 충돌 효과 (트레이드오프 적 기준)

별도 명시가 없는 한 적과 충돌 시 아래 효과가 적용된다. BO·부품 손상 상세 매핑은 [29-blood-orb.md](29-blood-orb.md) §1 참조.

| 효과 | 값 |
|------|-----|
| 블러드 오브 획득 | 적 종류별 (3~25 BO) |
| 부품 내구도 감소 | 충돌 방향별 LF/RF/LB/RB/구동계 (1~5%) |
| 순간 속도 감소 | 적 종류별 |
| 정신력 감소 | 적 종류별 (인간형은 -15~-25, 비인간은 -3~-8) |

## 와쳐 (Watcher)

**한 줄 요약**: 도로 위에 가만히 서서 시선을 고정하는 정적 장애물.

| 항목 | 내용 |
|------|------|
| 스폰 위치 | 도로 임의 차선 |
| 이동 | 없음 |
| 블러드 오브 | 3 BO |
| 부품 손상 | LF/RF -3%, 구동계 -1% |
| 정신력 | -3 |

아무것도 하지 않는다는 점이 핵심이다. 플레이어가 먼저 발견하고 차선을 바꿔야 한다. 헤드라이트에 서서히 드러나는 실루엣이 첫 등장 시 공포감을 준다. BO 보상이 낮아 일부러 칠 이유가 적다 — "가장 무서운데 가장 안 쓸모 있는 적".

---

## 러너 (Runner)

**한 줄 요약**: 플레이어를 인식하면 도로 안으로 달려드는 적. 느리게 달리면 반드시 맞는다.

| 항목 | 내용 |
|------|------|
| 스폰 위치 | 도로 좌우 갓길 끝 |
| 기본 이동속도 | 3 m/s |
| 활성화 조건 | 플레이어 차량을 인식하는 순간 도로 방향으로 달리기 시작 |
| 블러드 오브 | 5 BO |
| 부품 손상 | LF/RF -3% |
| 정신력 | -5 |

### 설계 의도

러너의 이동속도(3 m/s)와 도로 폭을 기반으로, **일정 속도 이하로 통과하면 반드시 충돌하도록** 설계한다. 플레이어는 러너가 달리기 시작하는 것을 보는 순간 속도를 유지하거나 올려 그 구간을 빠르게 벗어나야 한다.

```
러너 인식 → 달리기 시작
플레이어: 가속해서 러너가 도로에 진입하기 전에 통과 → 안전
플레이어: 감속 또는 저속 유지 → 도로 진입한 러너와 충돌
```

밸런스는 구현 후 속도 임계값을 조정해 맞춘다.

## 점퍼 (Jumper)

**한 줄 요약**: 충돌하면 차 위로 올라타 시야를 막는 적. 핸들을 흔들어 떼어내야 한다.

| 항목 | 내용 |
|------|------|
| 스폰 위치 | 도로 임의 차선 (와쳐와 동일한 방식으로 서있음) |
| 이동 | 없음 (충돌 전까지) |
| 충돌 시 | 차량에 깔리지 않고 **보닛 위로 올라탐** |

### 보닛 위 상태

| 효과 | 값 |
|------|-----|
| 시야 차단 | 보닛 위 점퍼 스프라이트가 전방 도로를 가림 |
| 정신력 감소 | -1/초 |
| 다른 점퍼와 충돌 | 공통 충돌 효과 적용 (올라탄 점퍼는 그대로 유지) |

> 충돌 자체로는 BO·부품 손상 발생하지 않는다. 점퍼는 "탑승 후 탈출" 보상 구조.

### 탈출 — 차량 물리 상태

차량의 실제 물리 상태가 탈출 게이지를 채운다. 버튼을 좌우로 흔드는 미니게임이 아니라, 실제로 차가 방향을 바꾸고 속도가 있을 때 게이지가 오른다.

| 파라미터 | 값 | 비고 |
|---------|-----|------|
| 탈출 게이지 목표 | 240 | 가득 차면 점퍼 떨어짐 |
| 기본 충전 계수 | 40.0 | 조향·속도 조건 만족 시 초당 누적 |
| 충전 공식 | `(조향 속도 / 35.0) × (현재 속도 / 240.0) × 40.0 × 반응 계수` | game_world.gd 구현과 동일 |

```
탈출 게이지 충전 속도 = 조향 변화 강도 × 속도 계수 × 40.0
조향 속도 정규화 = 핸들 입력 강도 (m/s 단위)
속도 계수 = 현재속도 / 240 (240 픽셀/초 = 최대 정규 속도)
```

**현실적 탈출 시간**:
- 고속(140km/h) + 활발한 차선 변경: 약 6초 (240 / 40)
- 중속(80km/h) + 평균 조향: 약 12~15초
- 저속(40km/h) + 직진: 30초+ (사실상 못 떼냄)

장애물을 피하는 과정 자체가 점퍼 탈출에 기여한다. 부착 중 정신력은 매초 -1 깎이므로 빠를수록 좋다.

### 탈출 보상

탈출 성공 시 **8 BO 획득**. 점퍼는 충돌 시점이 아닌 **탈출 시점에 BO가 지급**되는 유일한 적. 들고 다니는 동안 정신력이 깎이는 비용을 감수하고 BO를 회수하는 구조.

## 워커 (Walker)

**한 줄 요약**: 도로 끝에서 끝까지 좌우로만 이동하는 적. 타이밍을 읽어야 한다.

| 항목 | 내용 |
|------|------|
| 스폰 위치 | 도로 위 임의 Y 위치 (전방 일정 거리) |
| 이동 | 도로 좌측 끝 ↔ 우측 끝 왕복. Y축 이동 없음 |
| 이동속도 | **4 m/s** (도로 폭 ~10m 횡단에 약 2.5초) |
| 도로 점유 폭 | 1 차선 (자기 크기 + 0.5m 여유) |
| 블러드 오브 | 6 BO |
| 부품 손상 | LF/RF -3%, 구동계 -1% |
| 정신력 | -5 |

Y축으로 접근하지 않으므로 플레이어가 직접 달려드는 구조다. 워커의 현재 위치를 보고 타이밍을 잡아 빈 공간으로 통과해야 한다. 차량 기본 속도(22 m/s) 기준으로 워커 1대가 시야에 들어와 도로를 횡단할 때 플레이어에게 약 1.5~2초의 판단 시간이 주어진다.

---

## 앰부서 (Ambusher)

**한 줄 요약**: 갓길 수풀에 숨어있다가 갑자기 뛰쳐나오는 적. 반응 속도를 시험한다.

| 항목 | 내용 |
|------|------|
| 대기 위치 | 갓길 밖 나무·수풀 안 (화면에 보이지 않음) |
| 활성화 조건 | 플레이어 차량이 일정 거리 이내로 접근 |
| 등장 방식 | 수풀에서 도로 방향으로 달려 나옴 |
| 도로 진입 후 | **정지. 와쳐와 동일하게 서있음** |
| 블러드 오브 | 7 BO |
| 부품 손상 | LF/RF -4% (측면 충돌 시 LB 또는 RB -2% 추가) |
| 정신력 | -8 |

### 설계 의도

와이퍼·라디오 조작 중에 앰부서가 등장하면 멀티태스킹 한계를 시험한다. 갓길 수색 중 폐차 근처에 배치하면 "멈춰서 파밍하는 행위"에 대한 추가 위험 요소가 된다.

수풀이 없는 구간(4구간 황폐 지형)에서는 등장 불가. 수풀 밀도가 높은 구간에서 집중 배치.

---

## 컬트원 (Cult Member)

**한 줄 요약**: 후드 입은 집단. 보는 것만으로도 정신력이 깎인다. 도로를 횡단하는 행렬일 때만 충돌·BO 획득 가능.

### 분류

| 종류 | 위치 | 충돌 가능 | 비고 |
|------|------|---------|------|
| **갓길 컬트** | 도로 좌우 갓길 (도로 밖) | 불가 | 시각적 공포. 차를 따라 고개 돌림 |
| **행렬 컬트** | 도로를 천천히 횡단 (외줄 3~5명) | 가능 | BO 획득 기회 |
| **컬트 우두머리** | 행렬 선두/후미 1명. 검정 후드, 큰 덩치 | 가능 | 게임 내 단일 적 최대 BO 보상 |

### 갓길 컬트 (Roadside Cult)

| 항목 | 내용 |
|------|------|
| 스폰 위치 | 도로 좌우 갓길, 도로 밖 |
| 이동 | 없음. 차량을 향해 고개를 돌림 |
| 충돌 | 불가능 (도로 진입 안 함) |
| 정신력 감소 (목격) | -5 (스쳐 지나감) ~ -10 (헤드라이트 직접 비춤) |
| 블러드 오브 | 없음 |

도로 진입하지 않으므로 BO 획득 불가능. **그들은 만질 수 없는 공포**다. 단순 시각적 압박 장치.

### 행렬 컬트 (Procession)

| 항목 | 내용 |
|------|------|
| 스폰 빈도 | 스테이지 3 이후, 구간당 1~2회 |
| 행렬 구성 | 외줄 3~5명. 우두머리 1명 포함 |
| 이동 방식 | 갓길 → 반대 갓길로 도로 횡단 (1 m/s) |
| 도로 통과 시간 | 약 4초 (행렬 전체) |
| 차량 통과 시간 | 약 0.5초 (가속 시) |

#### 충돌 효과

| 대상 | 블러드 오브 | 부품 손상 | 정신력 |
|------|----------|---------|--------|
| 일반 컬트원 1명 | 10 BO | LF/RF -3% | -15 |
| 컬트 우두머리 | 25 BO | LF/RF -5%, 구동계 -2~3% | -25 |
| 행렬 관통 (3~5명) | 30~50 BO + 25 (우두머리 명중 시) | LF/RF 누적 -9~-20%, 구동계 -2~3% | -45~-75 |

#### 플레이어 선택

| 행동 | 결과 |
|------|------|
| 회피 (빈 공간 통과) | 정신력 -2 (시선) |
| 후미 1~2명만 치고 통과 | 부분 보상 + 부분 손상 |
| 전 행렬 관통 | 최대 보상 + 최대 손상. 정신력 거의 절반 손실 위험 |
| 우두머리만 정확 명중 | 25 BO + 강타 손상 |

### 시각 연출

- 행렬 등장 시: 라디오에서 죽음의 주파수 점유 시도 (지직 잡음)
- 차량 접근에 따라 컬트가 한 명씩 고개를 돌림 (도미노 효과)
- 우두머리만 정면을 응시 — 자신의 길을 간다
- 무채색화: 일반 후드 검정 #1A1818, 우두머리 후드는 정신력 낮을수록 더 또렷
- 차창에 빗물 있는 경우 9-wiper의 와이퍼 리듬과 맞물려 보였다 안 보였다 반복

### 설계 의도

- **갓길 컬트는 일관된 호러 정체성 보존** — 만질 수 없는 시선
- **행렬 컬트만이 BO 채널** — 호러를 손상시키지 않으면서 보상 도입
- **우두머리 25 BO는 단일 최대 보상** → 위험 빌드 핵심 사냥감
- 정신력 -15~-25의 인간형 충돌 비용 → `찢어진 사진` `빈 약통` 빌드와 강한 시너지

## 스테이지별 등장 조합 (초안)

| 스테이지 | 주요 적 | 컬트 | 도망자 | 비고 |
|---------|--------|------|--------|------|
| 1 | 와쳐 | 갓길만 (드뭄) | — | 단순 회피 학습 |
| 2 | 와쳐, 러너, 앰부서 | 갓길 | ✅ | 속도 판단 + 순발력. 도망자 첫 등장 |
| 3 | 와쳐, 러너, 점퍼, 앰부서 | 갓길 + **행렬 첫 등장** | ✅ | 핸들 흔들기 + 행렬 판단 |
| 4 | 전 적 + 워커 | 갓길 + 행렬 (구간당 1) | ✅ | 복합 압박 |
| 5 | 전 적 + 워커 | 갓길 밀집 + 행렬 (구간당 2) | ✅ | 4구간 대비 밀도 증가. 완전 야간 — 헤드라이트 필수 |
| 6 | 전 적 + 워커 + 사슴머리 | 갓길 밀집 + 행렬 (구간당 2~3) | — | 최고 밀도. 사슴머리 2~3회 고정. 도망자 미등장 |

> 각 적의 정확한 스폰 타이밍·간격·다른 시스템과의 충돌 회피는 [30-pressure-orchestration.md](30-pressure-orchestration.md)의 시스템 분류 매트릭스·동시 발생 규칙·상호 잠금에 따른다. 본 표는 등장 적의 종류만 정의한다.

## 사슴머리 (Deer Head)

**한 줄 요약**: 도로 전 차선을 점유하는 거대한 존재. 회피할 수 없다. 속도만이 피해를 줄인다.

| 항목 | 내용 |
|------|------|
| 스폰 위치 | 도로 전 차선 중앙 (회피 불가) |
| 이동 | 없음. 헤드라이트를 바라보며 서있음 |
| 충돌 방식 | 차가 사슴머리를 통과함. 일반 충돌 없음 |
| 등장 빈도 | 스테이지 6 고정 2~3회 |

### 통과 피해

| 통과 속도 | 정신력 | 부품 내구도 (LF/RF/LB/RB/구동계) | 추가 효과 |
|---------|-------|-----------|---------|
| 80 km/h 이상 | -15 | 손상 없음 | — |
| 40~79 km/h | -30 | 5개 부품 모두 -8% | — |
| 40 km/h 미만 / 정지 | -50 | 5개 부품 모두 -20% | 주변 적 전체 즉시 활성화 |

> 사슴머리는 **BO를 지급하지 않는다**. 회피 전용 위협으로 분류 — 통과 자체가 게임의 의식적 순간.

### 연출

- 헤드라이트에 서서히 드러나는 거대 실루엣. 뿔이 가장 마지막에 보인다.
- 통과 순간 채도 급락. 속도가 낮을수록 감소폭 증가.
- 백미러: 통과 후에도 같은 자리에 서있다. F키로 확인 가능.

## 도망자 (Fleeing One)

**한 줄 요약**: 등을 보인 채 도로를 달아나는 존재. 치면 소지품이 흩어진다. 안 치면 그냥 지나친다.

| 항목 | 내용 |
|------|------|
| 스폰 위치 | 도로 중앙. 플레이어 전방 35m (jiwon_system.gd SPACING_Z 기준) |
| 이동 방향 | 플레이어와 동일 방향. 등을 보인 채 달림 |
| 이동속도 | **5 m/s** (18 km/h, 차량 기본 속도의 약 1/4) |
| 회피 시간 | 차량 기본 속도(22 m/s) 기준 시야 진입 후 약 2초 안에 차선 변경 결정 필요 |
| 충돌 시 | 소지품 드롭. 부품 손상 없음. **블러드 오브 없음** (잡품 드롭 시스템 유지). 순간 화면 컷으로 처리 |
| 미충돌 시 | 5~8초 후 갓길로 이탈. 아무 일 없음. 정신력 변화 없음 |

### 비주얼 설계

컬트와 명확히 구분된다. "등을 보인 것만 쳐도 된다"는 규칙을 실루엣으로 전달.

| 항목 | 컬트 | 도망자 |
|------|------|--------|
| 방향 | 플레이어를 향함 | 등을 보임. 반대 방향으로 달림 |
| 복장 | 후드·로브 | 방한복·작업복 계열 |
| 소지품 | 없음 | 큰 배낭 또는 보따리. 달릴 때 위아래로 튀어오름 |
| 느낌 | 집단·의식적 | 혼자·도망 중 |

### 드롭 아이템

전투 보상이 아닌 개인 소지품. 잡품으로 정비 구간 상인에게 판매 가능.

| 아이템 | 분류 | 판매가 |
|--------|------|--------|
| 지갑 | 잡품 | ₩3,000~8,000 (내용물 랜덤) |
| 사진 한 장 | 잡품 | ₩500 |
| 처방전 | 잡품 | ₩1,000 |
| 열쇠 묶음 | 잡품 | ₩800 |
| 담배 | 소모품 | 정신력 +20. 즉시 사용 가능 |

### 충돌 연출

충돌 장면을 직접 보여주지 않는다. 순간 화면 컷(0.2초)으로 처리하고 아이템만 도로에 흩어진다. 플레이어가 "일어난 일"을 상상으로 채운다.

흩어진 아이템은 차량이 지나치며 자동 수집되지 않는다. 멈춰서 수색하거나 포기한다.

### 라디오 연동

도망자를 칠 때마다 이후 런의 라디오 일반 주파수 실종 신고 숫자가 1 증가한다.

```
[기본]        "27번 국도 일대 실종 신고가 이번 달만 세 건..."
[1회 충돌 후] "...네 건..."
[2회 충돌 후] "...다섯 건..."
```

게임이 직접 연결하지 않는다. 플레이어가 숫자 변화를 인식하는 시점은 사람마다 다르다.

### 설계 의도

치는 행위가 명확한 보상을 주지만 불편함을 남긴다. 절박한 상황(기름 바닥·현금 부족)에서 도망자가 나타날 때 선택의 무게가 달라진다. 진엔딩의 "내가 누군가를 해쳤는가" 테마와 연결된다.
