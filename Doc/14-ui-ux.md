# 14. UI/UX

## HUD 구성 (최소화 원칙)

화면 자체가 상태를 전달하므로 HUD를 최소화한다.

```
┌─────────────────────────────────────────────┐
│      [룸미러 — 상단 중앙, 고정]               │
│   ┌────────────────────────┐                │
│   │  기본: 주인공 얼굴       │                │
│   │  F키: 후방 포커싱 확대   │                │
│   └────────────────────────┘                │
│                                             │
│           [Pseudo 3D 도로 화면]              │
│                                             │
│  ┌─────────────────────────────────┐        │
│  │ VHS 오버레이 (항상)              │        │
│  └─────────────────────────────────┘        │
│                                             │
│  [운전자 혼잣말 자막 — 하단 중앙]             │
│                                             │
│  [타임코드 — 우하단]   [라디오 채널 아이콘 — 우상단] │
└─────────────────────────────────────────────┘
```

명시적으로 표시하는 수치: **없음**

플레이어가 상태를 파악하는 방법:
- 기름: 화면 어두워짐 + 엔진 소리
- 파츠: 화면 흔들림 / 시야 축소
- 정신력: VHS 글리치 강도 **+ 룸미러 얼굴 표정**
- 괴물과의 거리: **F키 포커싱 후 룸미러 내 괴물 크기**

## 룸미러 인터랙션 상세

| 상태 | 룸미러 표시 | 조건 |
|------|-----------|------|
| 기본 | 주인공 얼굴 (정신력 연동 표정) | 항상 |
| 포커싱 | 후방 확대 (괴물 확인 가능) | F키 누르는 동안 |
| 포커싱 해제 잔상 | 얼굴 위 괴물 실루엣 0.5초 | 정신력 30 이하 + 포커싱 해제 직후 |

### 포커싱 전환 타이밍

```
F키 누름
  → 0.0~0.3초: 룸미러 1.0x→1.8x 확대
  → 0.2초~: 얼굴 페이드아웃, 후방 페이드인
  → 유지: 괴물 거리 확인 가능
F키 뗌
  → 0.0~0.2초: 후방 페이드아웃, 얼굴 페이드인
  → 0.2~0.4초: 룸미러 1.8x→1.0x 축소
  → (정신력 30↓): 잔상 0.5초 표시
```

> 후방 씬 구현·괴물 거리 단계는 [08-monster-chase.md](08-monster-chase.md) 참조.

## 온보딩

튜토리얼 텍스트 없음. 첫 구간은 위협이 없고 자연스럽게 조작을 익히도록 설계. 첫 갓길 폐차를 지나칠 때 운전자가 혼잣말로 힌트를 준다.

```
[폐차 옆을 그냥 지나침]
"...저기 뭔가 있는 것 같던데. 멈출까? ...그냥 가자."

[다음 폐차 등장 시]
"...기름이 좀 필요한데. 저기 멈춰볼까."
```
