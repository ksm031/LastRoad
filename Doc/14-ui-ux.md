# 14. UI/UX

## HUD 구성 (최소화 원칙)

화면 자체가 상태를 전달하므로 HUD를 최소화한다.

```
┌─────────────────────────────────────────────┐
│      [룸미러 — 상단 중앙, 고정]               │
│   ┌────────────────────────┐                │
│   │  기본: 주인공 얼굴       │                │
│   │  F키: 후방 포커싱 확대   │                │
│   └────────────────────────┘                │
│                                             │
│           [Pseudo 3D 도로 화면]              │
│                                             │
│                                             │
│  [운전자 혼잣말 자막 — 하단 중앙]             │
│                                             │
│  [시계 02:47:33 — 우하단]   [라디오 채널 아이콘 — 우상단] │
└─────────────────────────────────────────────┘
```

명시적으로 표시하는 수치: **없음**

플레이어가 상태를 파악하는 방법:
- 기름: 화면 어두워짐 + 엔진 소리
- 차량 전체 상태(대략): **앞유리 균열** (아래 참조)
- 파츠 세부 상태: 인벤토리를 열어 확인
- 정신력: **채도 감소 강도** + 룸미러 얼굴 표정
- 괴물과의 거리: **F키 포커싱 후 룸미러 내 괴물 크기**

### 앞유리 균열 — 차량 상태 간접 표시

차량이 충격을 받을수록 앞유리에 균열이 생긴다. 숫자 없이 차량 상태를 직관적으로 전달하는 시각 장치.

| 균열 단계 | 표시 | 의미 |
|---------|------|------|
| 없음 | 균열 없음 | 양호 |
| 1단계 | 균열 1~2줄 (구석) | 경미한 손상 |
| 2단계 | 균열 3~5줄 (중앙까지 뻗음) | 상당한 손상 |
| 3단계 | 균열 전체 확산 + 일부 파편 | 위험 수준 |

균열은 장식이 아니라 실제 시야를 일부 가린다. 3단계에서는 전방 도로 일부가 균열에 가려진다.

세부 파츠 상태(각 소켓 내구도, 공기압 수치 등)는 인벤토리에서만 확인 가능.

## 주행 중 인벤토리

주행 중 **B키**로 트렁크 인벤토리를 열 수 있다. 아이템 사용과 차량 상태 확인이 여기서 이루어진다.

```
┌──────────────────────────────────────────┐
│  차량 상태                               │
│  엔진 [▓▓▓▓░] 타이어 [▓▓░░░] 공기압 72%│
│  브레이크 [▓▓▓▓▓] 핸들 [▓▓▓░░]         │
│  연료탱크 [▓▓▓▓▓] 헤드라이트 [▓▓░░░]   │
│                                          │
│  트렁크                                  │
│  [기름통] [담배] [타이어패치킷] [잡품]   │
│                                          │
│  아이템 선택 후 사용 가능                │
└──────────────────────────────────────────┘
```

인벤토리가 열려 있는 동안 **차는 관성으로 주행**된다. 조작이 불가능해지기 때문에 완전히 멈춘 뒤 열거나, 위험을 감수하고 달리는 채로 열 수 있다.

아이템별 사용 조건:
| 아이템 | 사용 조건 |
|-------|---------|
| 담배 | 제한 없음 |
| 기름통 | 제한 없음 |
| 타이어 패치킷 | 완전 정지 상태에서만 |

## 룸미러 인터랙션 상세

| 상태 | 룸미러 표시 | 조건 |
|------|-----------|------|
| 기본 | 주인공 얼굴 (정신력 연동 표정) | 항상 |
| 포커싱 | 전체 화면 후방 뷰. 전방 도로 완전 차단 | F키 토글 또는 룸미러 좌클릭 |
| 포커싱 해제 잔상 | 얼굴 위 괴물 실루엣 0.5초 | 정신력 30 이하 + 포커싱 해제 직후 |

### 포커싱 전환 타이밍

```
[열기] F키 입력 또는 룸미러 좌클릭
  → 0.0~0.3초: 룸미러 전체 화면으로 확대
  → 0.2초~: 얼굴 페이드아웃, 후방 페이드인
  → 유지: 괴물 거리 확인 가능. 전방 도로 완전 차단

[닫기] F키 재입력 또는 우클릭
  → 0.0~0.2초: 후방 페이드아웃, 얼굴 페이드인
  → 0.2~0.4초: 룸미러 전체 화면 → 원래 크기로 축소
  → (정신력 30↓): 잔상 0.5초 표시
```

> 후방 씬 구현·괴물 거리 단계는 [08-monster-chase.md](08-monster-chase.md) 참조.

## 온보딩

튜토리얼 텍스트 없음. 첫 구간은 위협이 없고 자연스럽게 조작을 익히도록 설계. 첫 갓길 폐차를 지나칠 때 운전자가 혼잣말로 힌트를 준다.

```
[폐차 옆을 그냥 지나침]
"...저기 뭔가 있는 것 같던데. 멈출까? ...그냥 가자."

[다음 폐차 등장 시]
"...기름이 좀 필요한데. 저기 멈춰볼까."
```
