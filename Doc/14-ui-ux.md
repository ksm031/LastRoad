# 14. UI/UX

## HUD 구성 (최소화 원칙)

화면 자체가 상태를 전달하므로 HUD를 최소화한다.

```
┌─────────────────────────────────────────────┐
│  [룸미러 — 상단 중앙]    [재화 카운터 — 우상단]│
│   ┌────────────────────┐    ₩ 12,500         │
│   │  기본: 주인공 얼굴   │    ◉ 23 BO         │
│   │  F키: 후방 포커싱   │    📻 채널 아이콘    │
│   └────────────────────┘                     │
│                                             │
│           [Pseudo 3D 도로 화면]              │
│                                             │
│  [부적 6슬롯 — 대시보드 상단, 인형처럼 매달림]│
│  🐶  🧭  🎲  🔦  🕯️  🃏                       │
│                                             │
│  [운전자 혼잣말 자막 — 하단 중앙]             │
│                                             │
│  [시계 02:47:33 — 우하단]                    │
└─────────────────────────────────────────────┘
```

명시적으로 표시하는 수치: **재화 2종 (₩, BO) 만**

플레이어가 상태를 파악하는 방법:
- 기름: 화면 어두워짐 + 엔진 소리
- 차량 전체 상태(대략): **앞유리 균열** (아래 참조)
- 파츠 세부 상태: 인벤토리를 열어 확인
- 정신력: **채도 감소 강도** + 룸미러 얼굴 표정
- 괴물과의 거리: **F키 포커싱 후 룸미러 내 괴물 크기**

### 앞유리 균열 — 차량 상태 간접 표시

차량이 충격을 받을수록 앞유리에 균열이 생긴다. 숫자 없이 차량 상태를 직관적으로 전달하는 시각 장치.

| 균열 단계 | 표시 | 의미 |
|---------|------|------|
| 없음 | 균열 없음 | 양호 |
| 1단계 | 균열 1~2줄 (구석) | 경미한 손상 |
| 2단계 | 균열 3~5줄 (중앙까지 뻗음) | 상당한 손상 |
| 3단계 | 균열 전체 확산 + 일부 파편 | 위험 수준 |

균열은 장식이 아니라 실제 시야를 일부 가린다. 3단계에서는 전방 도로 일부가 균열에 가려진다.

세부 파츠 상태(5개 부품 내구도: LF/RF/LB/RB 타이어 + 구동계)는 인벤토리에서만 확인 가능. 상세는 [05-parts.md](05-parts.md) §4 참조.

## 재화 카운터 — 우상단 고정 HUD

게임 내에서 명시적 수치로 표기되는 유일한 정보. 두 재화는 사용처가 완전히 다르므로 한눈에 비교되도록 같은 박스에 배치한다.

```
   ┌──────────────────────┐
   │  ₩  12,500           │  ← 현금 (Cash)
   │  ◉   23  BO          │  ← 블러드 오브
   │  📻  [F2]            │  ← 라디오 채널 아이콘
   └──────────────────────┘
```

| 항목 | 위치 | 폰트/색상 | 갱신 |
|------|------|----------|------|
| ₩ (현금) | 우상단, BO 위 | DS-DIGII.TTF, 흰색 | 잡품 판매·슬롯머신 사용 시 즉시 |
| ◉ BO (블러드 오브) | 우상단, ₩ 아래 | DS-DIGII.TTF, 진홍색 | 적 충돌·도로 오브 흡수 시 즉시 |
| 📻 라디오 채널 | 우상단, BO 아래 | 픽셀 아이콘 | 채널 전환 시 |

### 획득 피드백

- **₩ 획득** (정비 구간 잡품 판매): 숫자 카운트업 0.5초 + 흰색 펄스
- **BO 획득** (적 충돌·오브 흡수): 숫자 카운트업 0.3초 + 진홍색 펄스 + 화면 중앙 → 우상단으로 짧은 BO 입자 트레일
- **BO 소모** (정비 구간 부적 구매): 숫자 카운트다운 + 짧은 깜빡임

### 위치 정당화

- 좌측은 룸미러가 점유한다(상단 중앙). 정신력에 따라 룸미러 얼굴이 바뀌므로 시선이 자주 향한다.
- 재화 카운터는 자주 볼 필요가 없다(정비 구간 직전에만 의식). 우상단은 시선이 자주 가지 않는 안전한 위치.
- 채널 아이콘과 같은 박스에 배치 — 모두 "메타 상태(주행에 직접 관여하지 않음)" 정보다.

## 부적 슬롯 시각화 — 대시보드 인형 마운트

부적 6슬롯은 모두 **대시보드 상단**에 가로로 일렬 배치된다. 각 부적은 작은 인형/오브젝트 형태로 매달려 있고, 차량 움직임에 따라 흔들린다. 차 안에 무언가를 매다는 운전자의 습관 — **세계관·시스템·UI가 동일한 비주얼로 통합되는 지점**.

```
        ┌────────────────────────────────────────┐
        │     ╲│╱   ╲│╱   ╲│╱   ╲│╱   ╲│╱   ╲│╱ │  ← 매달린 줄
        │     [1]   [2]   [3]   [4]   [5]   [6] │  ← 부적 6슬롯
        │   ┌────────────────────────────────────┤
        │   │     대시보드 (계기판)               │
        │   └────────────────────────────────────┤
        └────────────────────────────────────────┘
```

### 슬롯 위치 규칙

| 슬롯 | 화면 X 좌표 | 비고 |
|------|------------|------|
| 1번 | 240px | 좌단 |
| 2번 | 400px | |
| 3번 | 560px | 룸미러 바로 아래 좌측 |
| 4번 | 720px | 룸미러 바로 아래 우측 |
| 5번 | 880px | |
| 6번 | 1040px | 우단 |

대시보드 상단(Y 약 460~500px)에 매달리도록 배치. 빈 슬롯은 작은 흡착컵 또는 줄만 보인다 (부적 자리임을 암시).

### 흔들림 (Sway) 시뮬레이션

매달린 부적은 차량 움직임을 따라간다.

| 동작 | 부적 반응 |
|------|---------|
| 가속 | 뒤로 살짝 기울어짐 (관성) |
| 감속·브레이크 | 앞으로 흔들림 |
| 좌회전 | 부적이 우측으로 쏠림 |
| 우회전 | 부적이 좌측으로 쏠림 |
| 충돌 | 강한 진동 (1초) |
| 포트홀 | 짧은 수직 흔들림 |

흔들림 폭은 차량 속도에 비례. 정차 중에는 미세하게만 흔들린다.

### 부적 상태 시각 표현 (28-charms.md §UX 피드백과 동기화)

| 상태 | 시각 표현 |
|------|---------|
| 빈 슬롯 | 흡착컵 또는 줄만 보임 |
| 부적 장착 (조건 미충족) | 정적 매달림 |
| 조건 충족 (효과 활성) | 미세한 빛/색 펄스 + 흔들림 폭 +20% |
| 게이지 누적 중 | 부적에 점진적으로 빛이 차오름 |
| 효과 발동 순간 | 짧게 강한 발광 → 페이드 |
| 듀오 시너지 활성 | 페어 부적 둘이 같은 색으로 동기 펄스 |
| 효과 소진 (1회용 발동 후) | 색이 빠진 채 매달림 (다음 정비 구간에서 회복) |

### 시야 간섭

부적은 대시보드 영역(Y 500~720px)을 살짝 침범하여 매달리지만, 도로 영역(Y 0~500px)은 침범하지 않는다. 도로 시야 가림은 없다.

## 주행 중 인벤토리

주행 중 **B키**로 트렁크 인벤토리를 열 수 있다. 아이템 사용과 차량 상태 확인이 여기서 이루어진다.

```
┌──────────────────────────────────────────┐
│  차량 내구도 (5분할)                     │
│  LF [▓▓▓▓░]  RF [▓▓▓░░]                 │
│  LB [▓▓▓▓▓]  RB [▓▓▓▓▓]                 │
│  Drivetrain [▓▓▓░░]                     │
│                                          │
│  트렁크                                  │
│  [기름통] [담배] [잡품]                  │
│                                          │
│  아이템 선택 후 사용 가능                │
└──────────────────────────────────────────┘
```

인벤토리가 열려 있는 동안 **차는 관성으로 주행**된다. 조작이 불가능해지기 때문에 완전히 멈춘 뒤 열거나, 위험을 감수하고 달리는 채로 열 수 있다.

아이템별 사용 조건:
| 아이템 | 사용 조건 |
|-------|---------|
| 담배 | 제한 없음 |
| 기름통 | 제한 없음 |

## 룸미러 인터랙션 상세

| 상태 | 룸미러 표시 | 조건 |
|------|-----------|------|
| 기본 | 주인공 얼굴 (정신력 연동 표정) | 항상 |
| 포커싱 | 전체 화면 후방 뷰. 전방 도로 완전 차단 | F키 토글 또는 룸미러 좌클릭 |
| 포커싱 해제 잔상 | 얼굴 위 괴물 실루엣 0.5초 | 정신력 30 이하 + 포커싱 해제 직후 |

### 포커싱 전환 타이밍

```
[열기] F키 입력 또는 룸미러 좌클릭
  → 0.0~0.3초: 룸미러 전체 화면으로 확대
  → 0.2초~: 얼굴 페이드아웃, 후방 페이드인
  → 유지: 괴물 거리 확인 가능. 전방 도로 완전 차단

[닫기] F키 재입력 또는 우클릭
  → 0.0~0.2초: 후방 페이드아웃, 얼굴 페이드인
  → 0.2~0.4초: 룸미러 전체 화면 → 원래 크기로 축소
  → (정신력 30↓): 잔상 0.5초 표시
```

> 후방 씬 구현·괴물 거리 단계는 [08-monster-chase.md](08-monster-chase.md) 참조.

## 거점 UI (정비 구간)

거점 도달 시에만 등장하는 풀스크린 UI. 픽셀 스타일 인터페이스. 상세 시스템은 [20-maintenance.md](20-maintenance.md) 참조.

```
┌──────────────────────────────────────────┐
│  ₩ 12,500       ◉ 23 BO                 │
│                                          │
│  5개 부품 내구도                          │
│  LF [▓▓▓▓░ 78%]  RF [▓▓▓░░ 52%]         │
│  LB [▓▓▓▓▓ 95%]  RB [▓▓▓▓▓ 95%]         │
│  Drivetrain     [▓▓▓░░ 60%]             │
│                                          │
│  파츠 업그레이드 (6종 / Lv 0~5)           │
│  엔진       Lv2 [● ● ○ ○ ○] →Lv3 ₩25,000│
│  연료탱크   Lv1 [● ○ ○ ○ ○] →Lv2 ₩12,000│
│  연비       Lv0 [○ ○ ○ ○ ○] →Lv1 ₩5,000 │
│  타이어     Lv1 [● ○ ○ ○ ○] →Lv2 ₩12,000│
│  브레이크   Lv0 [○ ○ ○ ○ ○] →Lv1 ₩5,000 │
│  헤드라이트 Lv0 [○ ○ ○ ○ ○] →Lv1 ₩5,000 │
│                                          │
│  부적 슬롯 (6/6)                          │
│  🐶 흔들리는 강아지 인형                  │
│  🧭 낡은 나침반                           │
│  [빈 슬롯 × 4]                           │
│                                          │
│  트렁크 (4/20)                           │
│  [기름통×2] [잡품×1] [부적×1]            │
│                                          │
│  [수리] [잡품 판매] [부적 상점] [슬롯머신]│
│  [출발] [경로 선택]                       │
└──────────────────────────────────────────┘
```

- ₩ / BO 카운터는 주행 중 우상단 HUD와 동일 폰트·색상 유지 (시각 일관성)
- 5개 부품 내구도는 색상 코드(녹/노/빨)와 % 동시 표기
- 파츠 업그레이드는 선형 5레벨 게이지 (○●), 다음 단계 비용 표기
- 부적은 6슬롯 횡렬, 빈 슬롯 명시

## 온보딩

튜토리얼 텍스트 없음. 첫 구간은 위협이 없고 자연스럽게 조작을 익히도록 설계. 첫 갓길 폐차를 지나칠 때 운전자가 혼잣말로 힌트를 준다.

```
[폐차 옆을 그냥 지나침]
"...저기 뭔가 있는 것 같던데. 멈출까? ...그냥 가자."

[다음 폐차 등장 시]
"...기름이 좀 필요한데. 저기 멈춰볼까."
```
