# 플레이테스트 체크리스트 — `claude/monster-rubber-band` 브랜치

이 브랜치의 코드는 **Godot에서 한 번도 실행되지 않았다** (작성 환경에 Godot 없음). 정적 교차 검증(메서드/속성 이름, 괄호, 들여쓰기)만 통과. 아래 순서로 확인하면 문제를 빨리 찾는다.

## 0. 열자마자
- [ ] 에디터가 스크립트 파싱 오류를 내는가? 새 파일: `spear_system.gd` `mover_system.gd` `pressure_director.gd` `monologue_system.gd`. `.uid` 자동 생성 경고는 무시
- [ ] `Asset/Sound/SFX/*.wav` 9개 임포트되는가 (22.05kHz 16bit mono)
- [ ] 메인 메뉴 → 시작 → 스플래시 → 주행 진입까지 크래시 없음. 엔진 소리 들림

## 1. 괴물 고무줄 (가장 중요)
- [ ] 스테이지 1 시작 직후 백미러 지평선에 괴물이 **작게 보이는가** (안 보이면 `rearview_renderer.gd:58` `0.06` → `0.10`)
- [ ] 정차하면 10초 안에 미러에서 커지는가. 다시 밟으면 20~40초 안에 작아지는가
- [ ] 넘패드 `5/6` 상한, `7/8` 계수, `9` 리셋 — 콘솔에 수치 찍히는가
- [ ] 폐차 10초 루팅 후 복귀가 "위험하지만 가능"한가 (불가능하면 계수 0.10 → 0.08)
- [ ] 스테이지 4~6: 엔진 무업글로 살아남을 수 있는가 → 아니면 `MONSTER_SPEEDS` 하향 필요

## 2. 주행 손맛
- [ ] 바위 충돌 후 복귀 ~8초 (이전 15초)
- [ ] 90km/h 이상에서 차선 변경이 약간 무거운가 (`HI_STEER_*`)
- [ ] 연료: 90km/h 순항 만땅 **~4.8분** (이전 ~2.7분 — 이중 소모 버그 수정됨). 너무 넉넉하면 `FUEL_DRAIN_MULT` 1.0 → 1.2

## 3. 창 던지기 (스테이지 3+; 넘패드 0으로 스킵)
- [ ] 괴물이 상한의 60% 안으로 오면(≈90) 미러 테두리 **붉은 펄스** → 미러 속 한쪽 팔+창이 보이는가. 크기/위치가 이상하면 `rearview_renderer.gd _on_spear_fx_draw`
- [ ] 손 반대편으로 피하면 whoosh + 옆을 스침, 같은 편이면 명중(셰이크·핸들 잠금 0.5초·5부품 -10%)
- [ ] 전방으로 날아가는 검은 창이 보이는가 (`spear_system.gd _draw`)
- [ ] 라디오 줌(V)·인벤토리(Tab)·점퍼 탑승 중엔 새 창이 안 오는가

## 4. 이동형 적 (임시 스프라이트: 붉은=러너, 푸른=워커, 연두=앰부서, 검정=컬트)
- [ ] 러너(2+): 갓길에서 내 차선으로 달려옴. 막판에 꺾으면 피해지는가. 너무 쉽거나 어려우면 `RUNNER_LANE_SPEED` 0.75
- [ ] 워커(4+): 좌우 왕복. 틈으로 통과 가능한가
- [ ] 앰부서(2+): 갑자기 튀어나와 섬. 반응 가능한가 (`AMB_TRIGGER_DZ` 13)
- [ ] 행렬(3+): 3~5명 외줄, 선두가 크고 어두움. 한 명만 칠 수 있는가. 전체 관통 시 정신력 급감
- [ ] 충돌 시 처치/튕김 판정이 와쳐와 같게 작동하는가

## 5. 붕괴 상태 (넘패드 `-` 연타로 정신력 0)
- [ ] 2초 암전 + 노크 3회 → "라디오가 안 돌아가" → 다이얼이 안 돌아가는가(금속음만)
- [ ] 우측으로 차가 쏠리고, 가끔 가속이 빠지고, 최고속이 낮은가. 도로 오브가 사라졌는가
- [ ] 넘패드 `4`(담배) → >10% → "손이 움직여" → 7초 안에 안전 주파수로 → 탈출. 못 돌리면 재잠금
- [ ] >30%에서 "숨을 쉬자" + 정상 복귀. 정비 구간 진입 시 자동 종료

## 6. 부적 (상점에서 BO로 구매, 넘패드 2로 돈)
- [ ] 아무거나 3개 장착 후 콘솔/체감으로 효과 확인. 특히: `heavy_weight`(제동↑ 최고속↓), `burnt_clutch`(연료 30% 미만 최고속↑), `broken_speedometer`(가속 중 라디오 안 돌아감), `metal_cross`(잡히는 순간 1회 구원)
- [ ] 새 런 시작 시 부적이 비워지는가 (이전엔 안 비워졌음)

## 7. 혼잣말 / 사운드 / 숨 비트
- [ ] 런 시작 "...또 시작이네." / 와쳐 접근 / 연료 40% / 괴물 임박 자막이 뜨는가. 너무 잦으면 `monologue_system.gd COOLDOWNS`
- [ ] 조용한 구간에서 가끔 죄책감 대사 (런당 ≤3)
- [ ] 스테이지 중간에 적이 없는 ~10초 구간(숨 비트)이 체감되는가
- [ ] 6스테이지 클리어 → 페이드 + 4줄 → 메뉴

## 8. 알려진 근사/미구현
- 러너·워커·앰부서·컬트 전용 아트 없음 · 사슴머리·도망자·갓길 컬트 없음
- `dead_man_watch`는 되감기 대신 거리 초기화 · `rusty_padlock` 트렁크 -2칸 미적용 · 부적 시너지 페어 없음
- 모든 폐차에 `big_engine` 테스트 아이템이 강제 삽입됨 (`inventory_manager.gd`) — 의도 확인 필요
