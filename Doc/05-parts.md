# 5. 차량 파츠 업그레이드 시스템

**목적**: 차량의 부품은 주행 중 획득하여 갈아 끼우는 형태가 아니라, **정비 구간에서 돈(₩)을 지불하여 영구적으로 강화하는 선형 업그레이드 시스템**이다. 돈을 모아 어떤 파츠부터 업그레이드할지 결정하는 것이 성장 전략의 핵심이다.

---

## 1. 업그레이드 항목 (7종)

총 7개의 부품 카테고리가 있으며, 각 부품은 0레벨(순정)부터 최대 5레벨까지 업그레이드할 수 있다.

| 파츠 카테고리 | 핵심 스탯 | 설명 |
|-------------|----------|------|
| **엔진 (Engine)** | 최고속도, 가속도 | 1단계: 튜닝된 흡기 → 5단계: 실험용 V8 블록 |
| **연료탱크 (Fuel Tank)** | 최대 연료 용량 | 1단계: 보조 격벽 → 5단계: 대형 커스텀 드럼 |
| **연비 관리 (Turbine)** | L/km 소모율 개선 | 1단계: 오일 필터 개선 → 5단계: 나노 코팅 실린더 |
| **타이어 (Tires)** | 조향 안정성, 차체 흔들림 제어 | 1단계: 사계절 타이어 → 5단계: 전천후 오프로드 셋 |
| **브레이크 (Brakes)** | 제동력 (감속 속도) | 1단계: 메탈 패드 교체 → 5단계: ABS 마스터 실린더 |
| **헤드라이트 (Headlight)**| 전방 시야 확보 거리 | 1단계: 반사판 청소 → 5단계: 초고출력 LED 서치라이트 |
| **네비게이션 (Navigation)** | 주행 정보 표시 범위 | 0단계: 없음 → 5단계: HUD 상시 표시. 상세는 §1.1 참조 |

---

### 1.1. 네비게이션 레벨 상세

Lv 0이 "네비 없음"인 유일한 파츠. 레벨이 오를수록 표시 정보의 범위가 확장된다.

| 레벨 | 추가 표시 정보 | 설명 |
|------|--------------|------|
| **Lv 0** | 없음 | 대시보드에 네비 화면 없음 |
| **Lv 1** | 도착지까지 남은 거리 | 현재 스테이지 종점까지 몇 m 남았는지 표시 |
| **Lv 2** | 폐차 위치 | 전방 갓길 폐차의 대략적 위치를 미리 표시. 수색 여부를 사전에 결정 가능 |
| **Lv 3** | 괴물 거리 | 뒤따라오는 괴물이 현재 몇 m 뒤에 있는지 표시. 룸미러를 열지 않아도 거리 파악 가능 |
| **Lv 4** | 적 등장 위치 | 전방에 등장할 적의 위치를 미리 표시 (와쳐·워커·앰부서 등). 회피 경로 사전 계획 가능 |
| **Lv 5** | HUD 상시 표시 | 루팅 UI·라디오·룸미러 등 어떤 화면을 열어도 네비 정보가 항상 HUD에 고정 표시 |

> Lv 3 이전에는 괴물 거리를 알기 위해 F키로 룸미러를 열어야 한다 (전방 시야 차단). Lv 3은 이 비용을 제거하는 핵심 업그레이드다.

---

## 2. 업그레이드 비용

업그레이드 비용은 레벨 구간마다 공통적으로 적용된다.

| 레벨 구간 | 업그레이드 비용 |
|---------|---------------|
| **Lv 0 → Lv 1** | ₩ 5,000 |
| **Lv 1 → Lv 2** | ₩ 12,000 |
| **Lv 2 → Lv 3** | ₩ 25,000 |
| **Lv 3 → Lv 4** | ₩ 48,000 |
| **Lv 4 → Lv 5** (Max) | ₩ 90,000 |

*총 1개 부품을 만렙(5)까지 올리는 데 필요한 비용: ₩ 180,000*
*모든 부품 풀 업그레이드 시 필요 비용: ₩ 1,260,000 (7종 × 180,000)*

---

## 3. 업그레이드 방법 및 규칙

*   **장소**: 스테이지 클리어 후 진입하는 **정비 구간 (상점)**에서만 가능하다. 주행 중에는 업그레이드나 파츠 교체가 불가능하다.
*   **재화**: 갓길 폐차 수색을 통해 얻은 '잡품(고철, 차량 부품, 생활용품 등)'을 상점에 팔아 얻은 **현금(₩)**으로 결제한다.
*   **영구 적용**: 런(Run) 내내 해당 업그레이드는 유지되며 파괴되거나 닳지 않는다. (단, 5개 부품 내구도·정신력·연료는 별개로 관리된다 — §4 참조.)
*   **직관적 선택**: 플레이어가 현재 런에서 가장 고통받고 있는 부분(기름이 부족한가? 시야가 좁은가? 괴물에게 자꾸 쫓기는가?)을 파악하고, 그에 맞는 파츠에 돈을 투자해야 한다.

---

## 4. 차량 내구도 시스템

기존의 통합된 체력(차체 내구도) 대신, **5개의 세부 구동계/타이어 부품 내구도**로 나뉘어 관리된다. 인벤토리(Tab)를 열면 이 5개 파츠의 상태가 시각적으로 표시되며, 100%는 초록색, 50%는 노란색, 0%는 빨간색으로 표기된다.

*   **LF_tire (좌측 전륜 타이어)**
*   **RF_tire (우측 전륜 타이어)**
*   **LB_tire (좌측 후륜 타이어)**
*   **RB_tire (우측 후륜 타이어)**
*   **Drivetrain (구동계 - 중앙 트랜스미션/엔진축)**

내구도는 **충돌로만 감소**한다. 시간 경과·주행 거리에 따른 자연 감소는 없다. 공기압 같은 별도 레이어도 없다.

---

### 4.1. 타이어 펑크 (Tire Flat)

개별 타이어의 내구도가 0%가 되면 펑크 상태가 된다. 펑크 개수와 위치 조합에 따라 효과가 달라진다.

#### 펑크 1개

| 항목 | 효과 |
|------|------|
| 최고속도 | -25% |
| 가속력 | -30% |
| 핸들 응답 | -20% |
| 차량 쏠림 | 펑크 방향으로 자동 쏠림. 조향 보정 필요 |
| 사운드 | 도로 마찰음 지속 |
| 시각 | 차체가 펑크 방향으로 살짝 기울어진 자세 |

#### 펑크 2개 — 위치 조합별 효과

| 조합 | 효과 |
|------|------|
| **같은 쪽 (LF+LB 또는 RF+RB)** | 최고속도 -50%, 가속력 -55%. 매우 강한 한쪽 쏠림 (보정해도 천천히 빠짐) |
| **대각선 (LF+RB 또는 RF+LB)** | 최고속도 -50%, 가속력 -55%. 좌우 진동 → 시야 미세 떨림 → 정신력 -0.5/초 |
| **앞 또는 뒤 (LF+RF 또는 LB+RB)** | 최고속도 -50%, 가속력 -55%. 쏠림 없음 (대칭). 단, 충돌 시 차체 추가 손상 +50% |

#### 펑크 3개 이상

| 항목 | 효과 |
|------|------|
| 최고속도 | 20km/h 고정 |
| 가속력 | -80% |
| 핸들 응답 | -60% |
| 회피 | 사실상 불가능 |
| 사슴머리·앰부서 | 거의 확정 충돌 |

> 펑크는 다음 정비 구간에 도달해야 수리 가능. 주행 중 회복 수단 없음.

---

### 4.2. 구동계 고장 (Drivetrain Failure)

중앙 구동계(Drivetrain)의 내구도가 0%가 되면 동력 전달이 끊기거나 심각한 마찰이 발생한다.

| 항목 | 효과 |
|------|------|
| 최고속도 | **30km/h 강제 제한** |
| 가속력 | -75% |
| 연비 | **+200% (3배 소모)** |
| 시야 | 화면 미세 흔들림 (시각 정보 — 정신력에는 영향 없음) |
| 엔진 RPM | 가끔 폭주 (붉은 영역 진입, 시각 경고) |
| 라디오 | 잡음 +50% (전기 시스템 간섭) |
| 간헐적 엔진 정지 | 30초마다 0.5초간 가속 페달 무효 |

구동계가 망가진 채로 오래 주행하면 금세 앵꼬가 난다. 정비 구간 도달 자체가 도전이 된다.

---

### 4.3. 복합 상태

타이어 펑크 + 구동계 고장이 동시 발생하면 효과는 누적 적용된다. 가장 절망적인 상태:

| 조합 | 결과 |
|------|------|
| 타이어 1개 펑크 + 구동계 0% | 최고속도 25km/h, 한쪽 쏠림, 연비 3배, 간헐적 정지 — 사실상 게임 진행 불가 |
| 타이어 3개 펑크 + 구동계 0% | 최고속도 15km/h. 사망 카운트다운 |

이 상태에 도달하기 전에 **정비 구간으로 후퇴**하거나 **다음 스테이지를 포기**하는 결정을 강제한다.

---

### 4.4. 수리

5개 부품 각각 정비 구간에서 개별 수리. 수리 비용은 손상도 비례.

| 부품 | 수리 단가 (1% 회복당) |
|------|---------------------|
| 타이어 (LF/RF/LB/RB 동일) | ₩50 |
| 구동계 | ₩150 |

펑크 또는 구동계 고장 상태(0%)에서 회복은 단가 ×1.5 추가.

---

### 4.5. 충돌 → 부품 손상 매핑 규칙

이 게임의 모든 부품 손상은 두 축의 곱으로 결정된다: **위치(어느 부품)** × **강도(얼마나)**. 다른 문서들(19-enemies, 29-blood-orb, 08-monster-chase, 06-threats)에서 적·상황별로 명시하는 손상값은 이 규칙의 적용 결과다.

#### 위치 — 충돌 접촉점

| 접촉점 | 손상 부품 |
|--------|---------|
| 정면 (도로 적 직진 충돌) | LF + RF 동시 |
| 좌측 (회피 부족, 갓길 좌측 풀숲) | LF 단독 |
| 우측 (회피 부족, 갓길 우측 풀숲) | RF 단독 |
| 측면 후방 (앰부서 갓길 진입, 차량 좌측·우측 측면 충돌) | LB 또는 RB |
| 전 방향 균등 (사슴머리 통과, 창 관통) | 5개 부품 균등 |

#### 강도 — 충돌 대상

| 대상 | 전륜 (해당 위치) | 구동계 |
|------|------|-------|
| 가벼운 정적 (와쳐, 워커) | -3% | -1% |
| 가벼운 동적 (러너, 컬트원) | -3% | — |
| 무거운 (앰부서) | -4% (측면 LB/RB -2% 추가 가능) | — |
| 강타 (바위, 컬트 우두머리) | -5% | -2~3% |
| 점퍼 | 0% (탑승 비용으로 전환: 정신력 -1/초) | 0% |
| 사슴머리 (80km/h 이상) | 손상 없음 | 손상 없음 |
| 사슴머리 (40~79km/h) | 전 부품 -8% | -8% |
| 사슴머리 (40km/h 미만) | 전 부품 -20% | -20% |
| 괴물의 창 명중 | 전 부품 -10% | -10% |

#### 적용 원칙

1. **전륜(LF/RF)이 기본 손상부**. 게임의 거의 모든 충돌은 정면 → 전륜에 누적.
2. **후륜(LB/RB)은 측면 충돌 한정**. 앰부서·갓길 접촉·차선 변경 중 사고 등.
3. **구동계는 강한 충돌에서만 손상**. 가벼운 인간형 적과의 일반 충돌로는 거의 안 닳음.
4. **누적 100% 도달 시 펑크/구동계 고장**. 같은 부품에 손상이 집중되면 빠르게 펑크 도달.
5. **사슴머리·창 = 5개 부품 균등**. "공평한 망가짐"이 이들의 의식적 특성이다 — 한쪽으로 쏠리지 않고 전체를 일률적으로 깎는다.

#### 부적 영향

부적이 손상 결과를 조정하는 경우(예: `안전운전 부적`, `거꾸로 달린 부적`, `두꺼운 타이어 패치`, `무거운 추`)는 위 표에서 산출된 값에 곱연산으로 적용된다. 각 부적의 정확한 효과는 [28-charms.md](28-charms.md) 참조.

## 5. 빌드와의 연계

파츠 업그레이드 자체는 선형적이고 확정적이다. 하지만 이를 **부적(Charms)** 시스템과 결합하여 시너지를 창출한다.

*   *예시:* 엔진(최고속도)을 5레벨까지 올린 후, 부적 중 "속도가 높을수록 정신력 회복" 능력을 가진 인형을 장착하면 '스피드 회복 빌드'가 완성된다.
*   *예시:* 연료탱크와 연비를 우선 업그레이드하고, "파밍 속도 증가 & 괴물 접근 증가" 부적을 장착하면 여유로운 연료를 바탕으로 갓길 파밍에 집중하는 '하이에나 빌드'를 굴릴 수 있다.
