# 5. 파츠 소켓 시스템

**목적**: 로그라이크식 랜덤 아이템 획득 + 내구도 관리로 "좋은 걸 가져도 잃을 수 있다"는 긴장감 생성.

## 소켓 구조

차량에 5개의 고정 소켓 존재. 소켓이 비어있으면 기본 성능으로 동작.

```
[ 엔진 소켓 ] [ 타이어 소켓 ] [ 라이트 소켓 ] [ 연료탱크 소켓 ] [ 차체 소켓 ]
```

## 파츠 등급

| 등급 | 색상 | 내구도 범위 | 특징 |
|------|------|-----------|------|
| 고물 (Junk) | 회색 | 15~25 | 기본 페널티 소폭 감소 |
| 중고 (Used) | 흰색 | 40~60 | 해당 소켓 기능 정상화 |
| 희귀 (Rare) | 노란색 | 25~45 | 성능 보너스 추가, 내구도 낮음 |
| 저주받은 (Cursed) | 붉은색 | 60~90 | 강력한 효과 + 부작용 존재 |

## 소켓별 효과 예시

| 소켓 | 중고 장착 효과 | 희귀 예시 효과 | 저주받은 예시 효과 |
|------|-------------|-------------|----------------|
| 엔진 | 연비 1.0→0.8 L/km | 연비 0.6 L/km | 연비 0.5 L/km, 정신력 소모 +10% |
| 타이어 | 험로 페널티 제거 | 감속 시간 단축 | 핸들 응답 향상, 가끔 의도치 않게 미끄러짐 |
| 라이트 | 시야 범위 정상화 | 위협 탐지 거리 +30% | 시야 최대화, 정신력 소모 +20% (더 멀리, 더 많이 봄) |
| 연료탱크 | 최대 용량 +20L | 기름 소모 추가 감소 | 용량 +40L, 수리비 2배 |
| 차체 | 충돌 내구도 +20 | 트렁크 +1칸 | 트렁크 +2칸, 충돌 시 파츠 손상 확률 +30% |

## 내구도 감소 트리거

| 상황 | 감소량 |
|------|-------|
| 포트홀 통과 | 타이어 -5, 차체 -3 |
| 낙석 충돌 | 차체 -15, 엔진 -8 |
| 컬트 장애물 충돌 | 차체 -20 |
| 컬트 라이트 타격 이벤트 | 라이트 -25 |
| 사슴머리 통과 | 모든 파츠 -5 |

## 파츠 파괴 시

내구도 0 도달 → 파츠 소켓에서 제거됨. 트렁크에도 사라짐. 기본 성능으로 복귀. 수리 불가.

**타이어 소켓은 예외.** 내구도 0이 되어도 즉시 제거되지 않고 **펑크(Flat) 상태**로 전환된다. 자세한 내용은 아래 타이어 시스템 참조.

---

## 타이어 펑크 & 공기압 시스템

타이어 소켓은 다른 파츠와 달리 2단계 손상 구조를 가진다.

### 단계 1 — 내구도 손상 (정상 → 펑크)

일반 파츠와 동일하게 내구도가 감소한다. **내구도 0 도달 시 펑크 상태 진입.** 소켓에서 제거되지 않고 공기압 시스템이 활성화된다.

### 단계 2 — 공기압 하락 (펑크 상태)

| 파라미터 | 값 |
|---------|-----|
| 초기 공기압 | 100% |
| 펑크 시 하락 속도 | -0.1%/초 |
| 패치 후 하락 | 중단 (공기압은 회복 안 됨) |
| 완전 회복 방법 | 거점 정비 타임에 타이어 교체 |

공기압은 **패치 후에도 회복되지 않는다.** 패치 시점의 공기압이 다음 거점까지 유지된다.

### 공기압 → 주행 성능 하락

| 공기압 | 최고속도 | 가속도 | 핸들 응답 | 차량 흔들림 |
|--------|--------|--------|---------|-----------|
| 100% | ×1.0 | ×1.0 | ×1.0 | 없음 |
| 80% | ×0.95 | ×0.95 | ×0.95 | 미세 |
| 60% | ×0.85 | ×0.82 | ×0.85 | 눈에 띔 |
| 40% | ×0.70 | ×0.65 | ×0.70 | 심함 |
| 20% | ×0.50 | ×0.45 | ×0.50 | 매우 심함 |
| 0% | ×0.25 | ×0.20 | ×0.30 | 극심. 조작 한계 |

차량 흔들림은 VHS 화면 흔들림으로 표현된다. 공기압이 낮을수록 화면 좌우 흔들림 진폭이 커진다.

### 타이어 응급패치킷 사용

| 조건 | 값 |
|------|-----|
| 사용 가능 조건 | **완전 정지** 상태 |
| 효과 | 타이어 내구도 → 20 회복. 공기 누출 중단 |
| 공기압 변화 | 없음 (패치 시점의 공기압 유지) |
| 비고 | 펑크 전 예방적 사용 불가. 펑크 상태에서만 사용 가능 |

```
펑크 발생
  → 공기압 하락 시작 (-0.1%/초)
  → 차를 세우고 패치킷 사용
  → 누출 중단. 공기압은 현재값 고정
  → 거점까지 낮은 공기압으로 주행
  → 거점 정비 타임: 타이어 교체 시 공기압 100% 복구
```

### 예시 시나리오

> 포트홀 세 개를 연속으로 밟아 타이어 내구도가 0이 됐다. 펑크. 공기압이 빠지기 시작한다. 뒤에서 괴물이 경계 단계다. 지금 멈추면 8m/s로 가까워진다. 30초를 버티다 차를 세우니 공기압이 97%. 패치 후 누출은 멈췄지만 공기압은 97%다. 거점까지 거의 정상 주행이 가능하다.
>
> 반면 괴물이 임박해서 2분을 달리다 멈췄다면 공기압은 88%. 핸들이 느려지고 화면이 미세하게 흔들린다. 거점까지 이 상태로 달려야 한다.

## 파츠 획득 및 장착

### 획득처

| 획득처 | 등급 확률 | 비고 |
|--------|---------|------|
| 갓길 폐차 수색 (희귀 직드롭) | 고물 60% / 중고 35% / 희귀 5% | 확률 낮음. 트렁크에 보관 |
| 거점 상인 구매 | 중고 50% / 희귀 40% / 저주받은 10% | 현금 지불. 주요 획득 루트 |
| 컬트 제단 근처 | 저주받은 70% / 희귀 30% | 희귀 직드롭 |
| 특수 이벤트 | 고정 드롭 (시나리오별 상이) | — |

### 장착 시점

파츠 교체 및 신규 장착은 **정비 타임(스테이지 클리어 후)에만 가능**. 주행 중에는 장착 불가.

주행 중 가능한 응급 처치:
- **타이어 응급패치킷** 사용 → 타이어 내구도 소량 회복 (교체 아님)

### 수리

거점 정비 타임에 현금을 지불해 내구도를 복구한다. 등급이 높을수록 수리비가 비싸다.

```
수리비(₩) = (최대내구도 - 현재내구도) × 등급계수 × 단가
등급계수: 고물 0.5 / 중고 1.0 / 희귀 1.5 / 저주받은 2.0
단가: TBD
```

## 예시 시나리오

> 라이트 소켓에 희귀 파츠가 끼워져 있다. 내구도 8 남음. 폐차 수색 중 중고 라이트 파츠가 나왔다. 트렁크에 넣어 뒀다. 거점에 도착하니 현금이 부족해 희귀 파츠 수리비를 낼 수 없다. 중고로 교체할지, 현금을 더 모아 다음 거점에서 희귀를 살릴지 선택해야 한다.
