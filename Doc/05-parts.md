# 5. 파츠 시스템

**목적**: 랜덤 스탯 분배로 같은 등급이라도 성격이 다른 파츠가 나온다. 무엇을 끼우느냐가 플레이 스타일을 결정한다.

---

## 차량 스탯

| 스탯 | 설명 |
|------|------|
| 최고속도 | 차량이 낼 수 있는 최대 속도 |
| 가속도 | 속도 상승 반응 속도 |
| 브레이크 성능 | 제동력. 멈추는 데 필요한 거리 |
| 핸들 응답 | 방향 전환 반응 속도 |
| 연비 | 주행 거리당 기름 소모량 (L/km) |
| 최대 연료 용량 | 탱크에 담을 수 있는 기름 최대치 |
| 타이어 내구도 | 0 도달 시 펑크 상태 진입 |
| 헤드라이트 범위 | 전방 가시거리 |
| 차체 내구도 | 충돌 충격 흡수량 (돈으로 업그레이드) |
| 트렁크 용량 | 아이템 적재 슬롯 수 (돈으로 업그레이드) |

## 기본 파츠

소켓은 비울 수 없다. 게임 시작 시 6개 소켓 전부에 **기본 파츠**가 장착된 상태로 시작한다. 기본 파츠는 보너스도 페널티도 없는 기준값 파츠다. 등급 없음. 내구도가 있으며 낮아질수록 성능 저하가 발생한다 (일반 파츠와 동일).

더 좋은 파츠를 얻으면 교체하고, 기존 파츠를 버리거나 트렁크에 보관할 수 있다.

---

## 파츠 종류

파츠는 6종이다. 각 소켓에 하나씩 장착한다. 비어있으면 기본 수치로 동작한다.

| 파츠 | 영향 스탯 | 분배 방식 |
|------|---------|---------|
| 엔진 | 최고속도, 가속도, 연비 | 랜덤 분배 |
| 타이어 | 최고속도, 브레이크 성능 | 랜덤 분배 |
| 브레이크 | 브레이크 성능 | 단일 스탯 |
| 핸들 | 핸들 응답 | 단일 스탯 |
| 연료탱크 | 최대 연료 용량, 연비 | 랜덤 분배 |
| 헤드라이트 | 헤드라이트 범위 | 단일 스탯 |

---

## 랜덤 분배 규칙

스탯이 여러 개인 파츠(엔진·타이어·연료탱크)는 **등급이 총합을 결정하고, 스탯 간 분배는 랜덤**이다.

같은 희귀 엔진이라도:
```
엔진 A: 최고속도 ★★★  가속도 ★☆☆  연비 ★☆☆  (속도 특화)
엔진 B: 최고속도 ★☆☆  가속도 ★☆☆  연비 ★★★  (연비 특화)
엔진 C: 최고속도 ★★☆  가속도 ★★☆  연비 ★☆☆  (균형형)
```

총합은 동일하지만 성격이 다르다.

## 파츠 등급별 스탯 상한

각 등급의 **한 스탯 몰빵 시 최대 보너스**다. 실제 분배는 랜덤이므로 이 수치를 그대로 받을 확률은 낮다.

### 엔진 (최고속도 / 가속도 / 연비)

기준 최고속도 80 km/h, 기준 연비 5.5 L/km.

| 등급 | 최고속도 최대 | 가속도 최대 | 연비 개선 최대 |
|------|------------|-----------|--------------|
| 고물 | +10 km/h | +10% | -0.3 L/km |
| 중고 | +20 km/h | +20% | -0.6 L/km |
| 희귀 | +35 km/h | +35% | -1.0 L/km |
| 저주받은 | +55 km/h | +55% | -1.5 L/km |

예: 중고 엔진 연비 몰빵 → 소모율 4.9 L/km, 만땅 주행 거리 약 8.2 km.

### 타이어 (최고속도 / 브레이크 성능)

| 등급 | 최고속도 최대 | 브레이크 성능 최대 |
|------|------------|----------------|
| 고물 | +5 km/h | +15% |
| 중고 | +10 km/h | +30% |
| 희귀 | +18 km/h | +55% |
| 저주받은 | +28 km/h | +85% |

### 연료탱크 (최대 용량 / 연비)

기준 용량 40 L.

| 등급 | 최대 용량 최대 | 연비 개선 최대 |
|------|------------|--------------|
| 고물 | +5 L | -0.3 L/km |
| 중고 | +10 L | -0.5 L/km |
| 희귀 | +18 L | -0.9 L/km |
| 저주받은 | +28 L | -1.4 L/km |

예: 희귀 탱크 용량 몰빵 → 58 L, 만땅 주행 거리 약 10.5 km.

### 브레이크 / 핸들 / 헤드라이트 (단일 스탯)

| 등급 | 보너스 |
|------|------|
| 고물 | +20% |
| 중고 | +40% |
| 희귀 | +70% |
| 저주받은 | +110% |

## 파츠 등급

| 등급 | 색상 | 총합 수치 | 내구도 범위 |
|------|------|---------|-----------|
| 고물 (Junk) | 회색 | 낮음 | 15~25 |
| 중고 (Used) | 흰색 | 보통 | 40~60 |
| 희귀 (Rare) | 노란색 | 높음 | 25~45 |
| 저주받은 (Cursed) | 붉은색 | 매우 높음 + 부작용 | 60~90 |

> 희귀는 총합이 높은 대신 내구도가 낮다. 저주받은은 강력하지만 파츠별 고유 부작용이 붙는다.

### 저주받은 파츠 부작용

| 파츠 | 부작용 | 발동 조건 |
|------|--------|---------|
| 엔진 | **불규칙 가속** — 1~2초간 최고속도 +20% 초과 가속. 브레이크로 취소 가능하나 0.3초 반응 지연 | 20~40초 무작위 간격 |
| 타이어 | **자연 공기압 손실** — 펑크 없이도 -0.03%/초로 공기압 감소. 패치킷으로 막을 수 없음 | 장착 즉시 상시 |
| 브레이크 | **간헐적 고착** — 1~1.5초간 브레이크 자동 작동 (속도 급감). 예고 없음 | 30~60초 무작위 간격 |
| 핸들 | **조향 반전** — 1.5초간 좌우 조향 반전. 화면 테두리 빨간 깜빡임으로 0.3초 사전 예고 | 20~40초 무작위 간격 |
| 연료탱크 | **연료 누출** — 추가 소모 +1.5 L/km (실질 7.0 L/km). 정비 구간 수리 시 일시 중단 | 장착 즉시 상시 |
| 헤드라이트 | **간헐적 블랙아웃** — 0.5~1.5초간 헤드라이트 완전 꺼짐. 예고 없음 | 15~30초 무작위 간격 |

## 타이어 펑크 & 공기압 시스템

타이어 소켓은 다른 파츠와 달리 2단계 손상 구조를 가진다. 타이어 내구도는 별도 스탯이 아니며 파츠 자체 내구도와 동일하다.

### 단계 1 — 내구도 손상 (정상 → 펑크)

내구도가 0 도달 시 **펑크 상태** 진입. 소켓에서 제거되지 않고 공기압 시스템이 활성화된다.

### 단계 2 — 공기압 하락 (펑크 상태)

| 파라미터 | 값 |
|---------|-----|
| 초기 공기압 | 100% |
| 펑크 시 하락 속도 | -0.1%/초 |
| 패치 후 하락 | 중단 (공기압은 회복 안 됨) |
| 완전 회복 방법 | 정비 구간에서 타이어 교체 |

### 공기압 → 주행 성능 하락

| 공기압 | 최고속도 | 가속도 | 핸들 응답 | 차량 흔들림 |
|--------|--------|--------|---------|-----------|
| 100% | ×1.0 | ×1.0 | ×1.0 | 없음 |
| 80% | ×0.95 | ×0.95 | ×0.95 | 미세 |
| 60% | ×0.85 | ×0.82 | ×0.85 | 눈에 띔 |
| 40% | ×0.70 | ×0.65 | ×0.70 | 심함 |
| 20% | ×0.50 | ×0.45 | ×0.50 | 매우 심함 |
| 0% | ×0.25 | ×0.20 | ×0.30 | 극심. 조작 한계 |

차량 흔들림은 VHS 화면 흔들림으로 표현된다.

### 타이어 응급패치킷

| 조건 | 값 |
|------|-----|
| 사용 방법 | 인벤토리를 열어 사용 |
| 사용 가능 조건 | 완전 정지 상태에서만 |
| 효과 | 공기 누출 중단. 내구도 회복 없음 |
| 공기압 변화 | 없음 (패치 시점 공기압 유지) |
| 비고 | 펑크 상태에서만 사용 가능 |

## 내구도 감소와 성능 저하

파츠는 파괴되지 않는다. 내구도가 낮아질수록 해당 소켓의 스탯이 감소하며, 내구도 0에서는 기본 파츠보다도 성능이 나빠진다. 정비 구간에서 수리해야 정상화된다.

| 내구도 | 성능 상태 |
|--------|---------|
| 100~50% | 정상. 스탯 그대로 |
| 50~20% | 소폭 저하 |
| 20~1% | 급격한 저하 |
| 0% | 기본 파츠 이하로 악화. 해당 소켓 스탯이 오히려 마이너스 |

타이어는 예외 — 내구도 0 시 펑크 상태 진입 (공기압 시스템 작동).

## 획득 및 장착

### 획득처

| 획득처 | 등급 확률 |
|--------|---------|
| 갓길 폐차 수색 | 고물 60% / 중고 35% / 희귀 5% |
| 정비 구간 상점 (랜덤 진열) | 중고 50% / 희귀 40% / 저주받은 10% |

### 장착 시점

파츠 교체는 **정비 구간에서만** 가능. 주행 중 장착 불가.

주행 중 가능한 응급 처치: 타이어 응급패치킷 사용.

### 교체 시 기존 파츠 처리

새 파츠로 교체하면 기존 파츠는 트렁크로 이동한다. 트렁크가 가득 찬 경우 버림칸에 임시 보관된다. 정비 화면을 나가면 버림칸의 아이템은 확정 삭제된다 (원복 불가). 나가기 전까지는 버림칸에서 다시 꺼낼 수 있다.

### 수리

정비 구간에서 현금 지불로 내구도 복구.

```
수리비(₩) = (최대내구도 - 현재내구도) × 등급계수 × 단가
등급계수: 고물 0.5 / 중고 1.0 / 희귀 1.5 / 저주받은 2.0
단가: TBD
```
