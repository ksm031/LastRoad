# 5. 파츠 소켓 시스템

**목적**: 로그라이크식 랜덤 아이템 획득 + 내구도 관리로 "좋은 걸 가져도 잃을 수 있다"는 긴장감 생성.

## 소켓 구조

차량에 5개의 고정 소켓 존재. 소켓이 비어있으면 기본 성능으로 동작.

```
[ 엔진 소켓 ] [ 타이어 소켓 ] [ 라이트 소켓 ] [ 연료탱크 소켓 ] [ 차체 소켓 ]
```

## 파츠 등급

| 등급 | 색상 | 내구도 범위 | 특징 |
|------|------|-----------|------|
| 고물 (Junk) | 회색 | 15~25 | 기본 페널티 소폭 감소 |
| 중고 (Used) | 흰색 | 40~60 | 해당 소켓 기능 정상화 |
| 희귀 (Rare) | 노란색 | 25~45 | 성능 보너스 추가, 내구도 낮음 |
| 저주받은 (Cursed) | 붉은색 | 60~90 | 강력한 효과 + 부작용 존재 |

## 소켓별 효과 예시

| 소켓 | 중고 장착 효과 | 희귀 예시 효과 | 저주받은 예시 효과 |
|------|-------------|-------------|----------------|
| 엔진 | 연비 1.0→0.8 L/km | 연비 0.6 L/km | 연비 0.5 L/km, 정신력 소모 +10% |
| 타이어 | 험로 페널티 제거 | 감속 시간 단축 | 핸들 응답 향상, 가끔 의도치 않게 미끄러짐 |
| 라이트 | 시야 범위 정상화 | 위협 탐지 거리 +30% | 시야 최대화, 정신력 소모 +20% (더 멀리, 더 많이 봄) |
| 연료탱크 | 최대 용량 +20L | 기름 소모 추가 감소 | 용량 +40L, 수리비 2배 |
| 차체 | 충돌 내구도 +20 | 트렁크 +1칸 | 트렁크 +2칸, 충돌 시 파츠 손상 확률 +30% |

## 내구도 감소 트리거

| 상황 | 감소량 |
|------|-------|
| 포트홀 통과 | 타이어 -5, 차체 -3 |
| 낙석 충돌 | 차체 -15, 엔진 -8 |
| 컬트 장애물 충돌 | 차체 -20 |
| 컬트 라이트 타격 이벤트 | 라이트 -25 |
| 사슴머리 통과 | 모든 파츠 -5 |

## 파츠 파괴 시

내구도 0 도달 → 파츠 소켓에서 제거됨. 트렁크에도 사라짐. 기본 성능으로 복귀. 수리 불가.

## 파츠 획득 및 장착

### 획득처

| 획득처 | 등급 확률 | 비고 |
|--------|---------|------|
| 갓길 폐차 수색 (희귀 직드롭) | 고물 60% / 중고 35% / 희귀 5% | 확률 낮음. 트렁크에 보관 |
| 거점 상인 구매 | 중고 50% / 희귀 40% / 저주받은 10% | 현금 지불. 주요 획득 루트 |
| 컬트 제단 근처 | 저주받은 70% / 희귀 30% | 희귀 직드롭 |
| 특수 이벤트 | 고정 드롭 (시나리오별 상이) | — |

### 장착 시점

파츠 교체 및 신규 장착은 **정비 타임(스테이지 클리어 후)에만 가능**. 주행 중에는 장착 불가.

주행 중 가능한 응급 처치:
- **타이어 응급패치킷** 사용 → 타이어 내구도 소량 회복 (교체 아님)

### 수리

거점 정비 타임에 현금을 지불해 내구도를 복구한다. 등급이 높을수록 수리비가 비싸다.

```
수리비(₩) = (최대내구도 - 현재내구도) × 등급계수 × 단가
등급계수: 고물 0.5 / 중고 1.0 / 희귀 1.5 / 저주받은 2.0
단가: TBD
```

## 예시 시나리오

> 라이트 소켓에 희귀 파츠가 끼워져 있다. 내구도 8 남음. 폐차 수색 중 중고 라이트 파츠가 나왔다. 트렁크에 넣어 뒀다. 거점에 도착하니 현금이 부족해 희귀 파츠 수리비를 낼 수 없다. 중고로 교체할지, 현금을 더 모아 다음 거점에서 희귀를 살릴지 선택해야 한다.
