# 27. 라디오 스크립트

## 설계 원칙

라디오는 두 세계가 같은 기계에서 나온다.

**일반 주파수**: 세상은 아무것도 모른다. DJ는 따뜻하고, 날씨를 알려주고, 사연을 읽는다. 그 무지가 공포다.

**죽음의 주파수**: 그녀가 있던 세계다. 그가 평생 도망치려 했던 것. 연옥에서 그 세계가 라디오로 들어온다.

**말씨**: 90년대 초 서울 방송체. DJ는 격식 있고 약간 극적이다. 뉴스는 딱딱하다. 사연은 편지를 낭독하듯 읽는다.

---

## 일반 주파수

### DJ 멘트

```
"안녕하십니까, 청취자 여러분. 지금 이 시각은 새벽 세 시 십 분을
 가리키고 있습니다. 저는 오늘 새벽도 여러분 곁에 함께하겠습니다."

"이 늦은 시간, 라디오 앞에 계신 청취자 여러분. 어떤 사연을 안고
 계십니까. 먼 길을 달리고 계신 분도 계시겠지요. 저는 이 스튜디오에서
 그 모습을 그려보고 있습니다."

"오늘 새벽은 안개가 다소 끼겠다고 합니다. 운전 중이신 청취자 여러분,
 전조등 꼭 켜시고 안전 운전 부탁드리겠습니다."

"잠시 후 청취자 여러분의 사연을 읽어드리겠습니다.
 오늘 밤도 사연 보내주신 분들, 감사합니다."

"지금 이 시각, 어디선가 이 노래를 듣고 계실 청취자 여러분께
 이 곡을 보내드리겠습니다."

"새벽녘이 되면 공기가 달라지지요. 조금만 있으면 동이 틉니다.
 조금만 더 힘내시기 바랍니다, 청취자 여러분."
```

---

### 뉴스 단신

정시마다 아나운서 목소리로 교체. 딱딱하고 건조하다.

**기본 (진엔딩 퍽 해금 전):**
```
"경찰 당국에 따르면 27번 국도 일대에서 이번 달 들어
 실종 신고 세 건이 접수된 것으로 확인됐습니다.
 실종자들은 모두 야간 이동 중 가족과의 연락이 두절된 것으로
 알려졌으며, 경찰은 현재 수색 작업을 진행 중에 있습니다.
 경찰 당국은 해당 구간 야간 통행 시 각별한 주의를 당부했습니다."
```

**도망자 충돌 1회 후:**
```
"...네 건이 접수된 것으로 확인됐습니다."
```

**2회 후:**
```
"...다섯 건이 접수된 것으로 확인됐습니다."
```

숫자만 바뀐다. 아나운서 톤은 매번 동일하다.

### 청취자 사연

DJ가 편지를 낭독하듯 읽는다.

**사연 A:**
```
DJ: "자, 이번에는 청취자 여러분의 사연을 읽어드리겠습니다.
    경기도에서 연락 주셨습니다.

    '남자친구가 어젯밤 27번 국도를 지나간다고 하고서 연락이
    닿지 않습니다. 원래 이맘때면 도착했어야 하는데요.
    조금 걱정이 됩니다.'

    이렇게 보내주셨군요.
    별일 없기를 바랍니다.
    이분께 노래 한 곡 보내드리겠습니다."
```

*노래가 시작된다. DJ는 더 언급하지 않는다.*

**사연 B:**
```
DJ: "장거리 운전 중이신 청취자 분께서 사연 보내주셨습니다.
    '혼자 밤새 달리고 있습니다. 라디오가 없었으면 어쩔 뻔
    했습니다.' 하고 쓰셨네요.
    무사히 도착하시길 바랍니다.
    좋은 노래 한 곡 드리겠습니다."
```

**사연 C (진엔딩 퍽 해금 이후, 드물게):**
```
DJ: "...27번 국도를 이용하시는 청취자 여러분께
    당부 말씀 드리겠습니다.
    한 청취자 분께서 연락을 주셨는데요,
    가족 분이 해당 구간에서 연락이 끊어졌다고 하십니다.
    혹시 관련 정보를 알고 계신 분은 경찰에 신고해 주시기
    바랍니다."

    잠시 침묵.

    "...자, 다음 곡 이어서 들으시겠습니다."
```

### 날씨·교통

```
 곳도 있겠습니다. 해당 지역을 통행하시는 분들께서는
 감속 운행하시기 바랍니다."

"오늘 새벽 최저 기온은 영하 2도까지 내려가겠으며,
 일부 도로 결빙이 예상됩니다. 각별히 주의하시기 바랍니다."

"27번 국도 ○○분기점 부근에서 사고 처리가 진행 중에 있습니다.
 해당 구간 우회를 권고 드립니다."
```

## 죽음의 주파수

그녀가 속했던 세계에서 오는 신호. 주기적으로 특정 주파수를 점령한다.

**설계 원칙**: 난수방송(numbers station)처럼 다룬다. 수신자가 있는지, 메시지가 있는지, 누가 송신하는지 — 게임은 끝까지 설명하지 않는다. 숫자에 의미가 있는지조차 불분명하다. 플레이어가 연결하면 연결한 것이고, 그렇지 않아도 된다.

### 초기 (런 1~3회)

무엇인지 모른다. 수신 자체가 우연처럼 느껴진다.

```
(낮은 목소리들이 겹쳐 웅얼거림)

"...스물셋. 스물넷. 스물다섯. 스물여섯..."

(정적)

"...스물일곱."

(정적. 다시 웅얼거림)
```

---

### 중기 (런 4~6회)

윤곽이 생긴다. 이름을 부르는 것처럼 들린다.

```
(찬송가 멜로디. 가사는 들리지 않음)

"...권○○. 정○○. 최○○. 박○○..."

(정적)

"...돌아오너라."

(찬송가 재개)
```

---

### 후기 (진엔딩 퍽 해금 후)

이름 목록 사이에서 무언가 익숙한 것이 들린다.

```
(이름 목록 낭독 중)

"...이○○. [이름 첫 음절]. 김○○..."
```

| 유기 횟수 | 들리는 것 |
|---------|---------|
| 0회 | 이름 같은 소리. 불명확 |
| 1회 후 | 첫 음절 |
| 2회 후 | 두 음절 |
| 3회 후 | 세 음절 |

---
