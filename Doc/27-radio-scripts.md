# 27. 라디오 스크립트

## 설계 원칙

라디오는 두 세계가 같은 기계에서 나온다.

**일반 주파수**: 세상은 아무것도 모른다. DJ는 따뜻하고, 날씨를 알려주고, 사연을 읽는다. 그 무지가 공포다.

**죽음의 주파수**: 그녀가 있던 세계다. 그가 평생 도망치려 했던 것. 연옥에서 그 세계가 라디오로 들어온다.

---

## 일반 주파수

### DJ 멘트

방송 시간대: 새벽 2시~5시. DJ는 한 명. 이름은 나오지 않는다. 목소리는 따뜻하고 약간 피곤하다. 새벽 라디오를 혼자 진행하는 사람의 말투.

```
"좋은 새벽입니다. 지금 이 시간에 듣고 계신 분들, 어디로 가시는 걸까요.
 저는 스튜디오에서 상상해봅니다. 새벽 세 시의 목적지."

"오늘도 안개가 좀 끼겠다고 하네요. 운전하시는 분들 전조등 꼭 켜주시고요.
 특히 지방 국도 구간, 가시거리 많이 줄어듭니다. 조심해서 가세요."

"새벽에 음악 틀어달라고 문자 주셨는데요. 저도 사실 이 시간이 좋아요.
 너무 조용해서 무서울 것 같지만, 막상 앉아있으면 되게 고요하거든요."

"지금 몇 분이나 들으시는지 모르겠지만. 저는 여기 있습니다.
 어디 가시는 거든 잘 도착하세요."
```

---

### 뉴스 단신

자정 이후 정시마다 짧게 들어간다. 아나운서 목소리로 교체.

**기본 (진엔딩 퍽 해금 전):**
```
"경찰에 따르면 27번 국도 일대에서 이번 달 들어 실종 신고
 세 건이 접수됐습니다. 모두 야간 이동 중 연락이 끊겼으며,
 현재 수색이 진행 중입니다. 해당 구간 야간 통행 시
 각별한 주의를 당부 드립니다."
```

**도망자 충돌 1회 후:**
```
"...네 건이 접수됐습니다."
```

**2회 후:**
```
"...다섯 건이 접수됐습니다."
```

숫자만 바뀐다. 나머지는 동일하다. DJ는 매번 같은 톤으로 읽는다.

---

### 청취자 사연

런 중 한 번, 랜덤 타이밍에 재생된다. 다음 중 하나.

**사연 A:**
```
DJ: "문자 주셨는데요. '남자친구가 어제 밤에 27번 국도 간다고 하고
    연락이 안 돼요. 원래 이 시간엔 들어오는데. 좀 이상한 것 같아서요.'

    ...많이 걱정되시겠어요. 별일 없었으면 좋겠습니다.
    신청곡 틀어드릴게요."
```

*노래가 시작된다. DJ는 더 언급하지 않는다.*

**사연 B:**
```
DJ: "새벽에 혼자 장거리 운전하신다고요. 힘드시겠어요.
    무사히 도착하시길 바라겠습니다. 좋은 노래 하나 드릴게요."
```

**사연 C (진엔딩 퍽 해금 이후, 드물게):**
```
DJ: "...27번 국도 지나가시는 분 계시면 조심하세요.
    청취자분이 가족이 거기서 연락 끊겼다고 하시는데.
    혹시 아시는 분 있으면 경찰에 신고 부탁드립니다."

    잠깐 침묵.

    "...그러면 다음 곡 이어서 가겠습니다."
```

---

### 날씨·교통

짧고 건조하다. 정보만 전달한다.

```
"현재 27번 국도 구간 안개 농도 짙음. 가시거리 50미터 이하.
 감속 운행 바랍니다."

"새벽 기온 영하 2도. 결빙 구간 주의하시기 바랍니다."

"27번 국도 OO분기점 부근 사고 처리 중. 우회 권고."
```

## 죽음의 주파수

그녀가 속했던 세계에서 오는 신호. 주기적으로 특정 주파수를 점령한다.

### 초기 (런 1~3회, 진엔딩 퍽 해금 전)

정체를 알 수 없는 소리. 종교적인지 아닌지도 불분명하다.

```
(낮은 목소리들이 겹쳐서 웅얼거림)

"...스물셋. 스물넷. 스물다섯. 스물여섯..."

(정적)

"...스물일곱."

(정적. 다시 웅얼거림)
```

숫자가 무엇의 숫자인지는 밝히지 않는다.

---

### 중기 (런 4~6회)

윤곽이 생긴다. 이름을 부르는 것처럼 들린다.

```
(찬송가 멜로디. 가사는 들리지 않음)

"...권○○. 정○○. 최○○. 박○○..."

(정적)

"...돌아와."

(찬송가 재개)
```

"돌아와"가 누구에게 하는 말인지 명확하지 않다.

---

### 후기 (진엔딩 퍽 해금 후)

이름 목록 사이에서 무언가 익숙한 것이 들린다. 한 음절씩.

```
(이름 목록 낭독 중)

"...이○○. [이름 첫 글자]. 김○○..."

(계속된다. 한 음절만 또렷했다)
```

A 엔딩을 반복할수록 또렷해지는 음절이 늘어난다.

| 유기 횟수 | 들리는 것 |
|---------|---------|
| 0회 | 이름 같은 소리. 불명확 |
| 1회 후 | 첫 음절 |
| 2회 후 | 두 음절 |
| 3회 후 | 세 음절 |

---

### B 엔딩 진입 순간

사슴머리를 통과하는 순간, 죽음의 주파수가 단 한 번 완전히 또렷해진다.

```
(모든 잡음이 사라진다)

"[주인공 풀네임]."

(정적)
```

이름 하나. 그리고 차가 멈춘다.

---

## 두 채널의 교차

같은 런 안에서 두 채널이 우연처럼 호응하는 순간들.

| 일반 주파수 | 죽음의 주파수 (이후 청취 시) |
|-----------|----------------------|
| "실종 신고 세 건" | "...셋. 넷. 다섯..." |
| "무사히 도착하세요" | "...돌아와..." |
| "27번 국도 주의" | (이름 목록) |

게임이 연결하지 않는다. 플레이어가 연결한다.
