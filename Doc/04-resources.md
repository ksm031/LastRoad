# 4. 자원 시스템

**목적**: 네 자원이 서로 다른 방식으로 플레이어를 압박. 기름=즉각, 정신력=연출, 현금=장기 전략, 블러드 오브=매 런의 정체성.

## 자원 1 — 기름 (Fuel)

| 파라미터 | 값 |
|---------|-----|
| 최대 용량 | 40 L (기본) / 연료탱크 파츠 업그레이드 레벨에 따라 증가 |
| 기본 소모율 | 5.5 L/km |
| 0L 도달 시 | 차량 최고속도 급격히 감소. 이동은 가능하나 사실상 기어가는 수준 |
| 획득처 | 거점 상인 구매, 갓길 폐차 수색 |

## 자원 2 — 현금 (Cash)

트렁크 공간을 차지하지 않는다. 수치로만 관리되며 정비 구간에서만 사용 가능.

| 파라미터 | 값 |
|---------|-----|
| 단위 | 원 (₩) |
| 획득처 | 갓길 폐차 수색 → 잡품을 인벤토리에 보관 → 정비 구간 상점에서 판매 |
| 사용처 | 파츠 업그레이드, 부품 내구도 수리(LF/RF/LB/RB 타이어·구동계), 기름 구매, 아이템 구매 |

> 잡품 종류·판매가는 [17-scavenging.md](17-scavenging.md), 파츠 업그레이드 비용·부품 수리 단가는 [05-parts.md](05-parts.md) 참조.

## 자원 3 — 정신력 (Sanity)

| 파라미터 | 값 |
|---------|-----|
| 최대값 | 100 |
| 0 도달 시 | **붕괴 상태** 진입. 사망이 아님. 상세는 아래 § 붕괴 상태 참조 |
| 감소 트리거 | 갓길 컬트 목격(-5~-10), 행렬 컬트 충돌(-15, 우두머리 -25), 사슴머리 통과(-15~-50, 통과 속도별 차등), 죽음의 주파수(-2/초), 적 충돌(와쳐/러너 -3~-5, 워커 -5, 앰부서 -8, 점퍼 부착 중 -1/초), 창 명중(-25) |

> 각 적의 정확한 정신력 비용은 [19-enemies.md](19-enemies.md) 참조. 5개 부품 손상 매핑은 [05-parts.md §4.5](05-parts.md) 참조.

### 정신력 0 — 붕괴 상태

정신력이 0에 도달하면 즉사가 아닌 **붕괴(崩壞) 상태**에 진입한다. 이 상태의 핵심은 **회복 경로가 존재하지만 상태 자체가 회복을 방해한다**는 것이다.

#### 진입 시 단발 이벤트

| 순서 | 내용 |
|------|------|
| 즉시 | 화면 **2초 암전** (블랙아웃). 모든 조작 불가 |
| 암전 중 | 트렁크 두드리는 소리 2~3회 (내러티브 연결: [24-story.md](24-story.md)) |
| 화면 복귀 | 라디오가 죽음의 주파수로 강제 전환 + **잠금** |

#### 지속 패널티 (붕괴 상태 유지 중)

| 분류 | 패널티 | 설계 의도 |
|------|--------|---------|
| **라디오 잠금** | 죽음의 주파수에서 벗어날 수 없음 | 죽음의 주파수 = -2/초. 회복 시도와 소모가 맞물리는 함정 |
| **조향 우측 쏠림** | 조향 입력 없을 때 우측으로 15% 힘이 지속 가해짐 | "그녀가 앉던 자리" 방향으로 차가 당겨지는 감각 |
| **간헐적 가속 해제** | 8~12초마다 0.5초간 가속 입력 무효 | 발이 저절로 떨어지는 감각. 속도 미세 감소 |
| **최고 속도 제한** | 최고 속도 80% | 심리적 무너짐이 몸에 전달 |
| **BO 수집 불가** | 도로 BO 오브 비표시 + 적 타격 BO 드롭 없음 | 정신이 무너져 수확할 여유 없음 |
| **담배 효율 저하** | 회복량 30% 감소 (+20 → +14) | 손이 떨려 제대로 피우지 못함 |
| **적 스폰 변화** | 환각 위협 빈도 +50%, 다른 적 스폰 -30% | [30-pressure-orchestration.md §6](30-pressure-orchestration.md) 참조 |

#### 탈출 시나리오 — 7초의 창

붕괴 상태의 핵심 구조: 담배 한 개(+14)로 정신력을 10 이상으로 올리는 순간 라디오 잠금이 해제된다. 이 **7초의 창** 안에 죽음의 주파수를 벗어나야 한다. 성공하면 -2/초 소모가 멈추고 점진 회복이 가능해진다.

```
담배 사용 (+14) → 정신력 14
→ 라디오 잠금 해제 (정신력 > 10)
→ 7초 안에 주파수 변경 → 죽음의 주파수 탈출
→ 정신력 >10 유지 : 조향·가속 패널티 해제
→ 정신력 >30 복귀  : 붕괴 상태 완전 종료
```

| 회복 임계 | 해제되는 패널티 |
|----------|----------------|
| 정신력 > 10 | 라디오 잠금 해제, 자동 쏠림 해제, 간헐적 가속 해제 |
| 정신력 > 30 | 최고 속도 정상화, BO 수집 재개, 담배 효율 정상화 |

> 붕괴 상태 시각·청각 연출 상세는 [07-sanity-visuals.md](07-sanity-visuals.md) 참조.

### 정신력 회복 방법

정신력은 **담배와 정비 구간**에서만 회복된다. 주행 중 자동 회복(시간 경과·라디오 등)은 존재하지 않는다.

| 방법 | 회복량 | 조건 |
|------|-------|------|
| 담배 아이템 사용 | +20 | 인벤토리에서 사용 |
| 정비 구간 도착 시 자동 회복 | 50 미만이면 50까지 | 정비 구간 진입 순간 |

정비 구간 자동 회복은 **최솟값 보장** 방식. 정신력이 이미 50 이상이면 추가 회복 없음.

### 정신력 → 시각 채널 연동

정신력은 **세 채널로 동시에 표현된다**. 숫자 없이 화면 자체가 상태계.

1. **채도 감소** — 화면 전반에서 색이 빠짐 (붉은색 제외). [07-sanity-visuals.md](07-sanity-visuals.md) 참조.
2. **룸미러 얼굴 표정** — 아래 표 참조.
3. **조수석 환영** — 정신력 50/30/10 임계에서 점진 등장. [07-sanity-visuals.md — 조수석 환영](07-sanity-visuals.md) 참조.

### 룸미러 얼굴 표정

| 정신력 | 표정 | 픽셀 표현 |
|--------|------|---------|
| 100~70 | 무표정·집중 | 눈 정면, 입 일자 |
| 70~50 | 긴장 | 눈 약간 확대, 미간 주름 1픽셀 |
| 50~30 | 공포 | 눈 크게, 땀 2픽셀, 입 벌어짐 |
| 30~10 | 공황 | 눈 흔들림 애니메이션 (2프레임 루프), 얼굴 떨림 |
| 10 이하 | 해리 | 눈이 초점 없이 허공. 깜빡임 중단 |

표정 전환은 즉각적이지 않다. 정신력 변화 후 **1.5초에 걸쳐 부드럽게 전환**. 플레이어가 얼굴을 보며 자연스럽게 감정 이입하게 된다.

**얼굴의 선행 반응**: 괴물이 임박 단계에 진입하면 플레이어가 포커싱 키를 누르기 전에 얼굴이 먼저 공황 표정으로 바뀐다. 경보이자 공포 연출.

> 정신력 → 화면 VHS 효과 상세는 [07-vhs.md](07-vhs.md) 참조. 룸미러 UI 동작은 [08-monster-chase.md](08-monster-chase.md) 참조.

## 자원 4 — 블러드 오브 (Blood Orb)

| 파라미터 | 값 |
|---------|-----|
| 단위 | BO (Blood Orb) |
| 획득처 | 적 타격, 도로 위 떠있는 오브 수집 |
| 사용처 | 정비 구간 상점에서 부적(Charms) 구매 |

| 누적 | 정비 구간 진입해도 소멸하지 않음. 누적된 BO로 부적 구매 |
