# 4. 자원 시스템

**목적**: 세 자원이 서로 다른 방식으로 플레이어를 압박. 기름=즉각, 정신력=연출, 현금=장기 전략.

## 자원 1 — 기름 (Fuel)

| 파라미터 | 값 |
|---------|-----|
| 최대 용량 | 기본값 TBD / 연료탱크 파츠 등급·스탯 분배에 따라 증가 |
| 기본 소모율 | 1.0 L/km |
| 0L 도달 시 | 차량 정지 → 즉시 게임 오버 (특정 엔딩으로 분기) |
| 획득처 | 거점 상인 구매, 갓길 폐차 수색 |

## 자원 2 — 현금 (Cash)

트렁크 공간을 차지하지 않는다. 수치로만 관리되며 정비 구간에서만 사용 가능.

| 파라미터 | 값 |
|---------|-----|
| 단위 | 원 (₩) |
| 획득처 | 갓길 폐차 수색 → 잡품을 인벤토리에 보관 → 정비 구간 상점에서 판매 |
| 사용처 | 파츠 구매, 파츠 수리, 기름 구매, 아이템 구매 |
| 수리비 계산 | `수리비 = (최대내구도 - 현재내구도) × 등급계수 × 단가` |
| 등급계수 | 고물 0.5 / 중고 1.0 / 희귀 1.5 / 저주받은 2.0 |

> 잡품 종류·판매가, 거점 상인 재고·가격표는 [17-scavenging.md](17-scavenging.md) 참조.

## 자원 3 — 정신력 (Sanity)

| 파라미터 | 값 |
|---------|-----|
| 최대값 | 100 |
| 0 도달 시 | 사망이 아님. 화면 완전 왜곡, 환각 위협 등장, 조작 딜레이 +0.3초 |
| 감소 트리거 | 컬트 목격 (-5~-20), 사슴머리 조우 (-30), 라디오 컬트 채널 (-2/초), 밟고 지나침 (-10~-25) |

### 정신력 회복 방법

| 방법 | 회복량 | 조건 |
|------|-------|------|
| 담배 아이템 사용 | +20 | 주행 중 즉시 사용 가능 |
| 라디오 정상 채널 유지 | +1/10초 | 주행 중 |
| 정비 구간 도착 시 자동 회복 | 50 미만이면 50까지 | 정비 구간 진입 순간 |

정비 구간 자동 회복은 **최솟값 보장** 방식. 정신력이 이미 50 이상이면 추가 회복 없음.

### 정신력 → 룸미러 얼굴 표정 연동

정신력은 VHS 글리치 강도와 함께 **룸미러 얼굴 표정**으로 이중 표현된다. 숫자 없이 두 채널로 상태를 전달.

| 정신력 | 표정 | 픽셀 표현 |
|--------|------|---------|
| 100~70 | 무표정·집중 | 눈 정면, 입 일자 |
| 70~50 | 긴장 | 눈 약간 확대, 미간 주름 1픽셀 |
| 50~30 | 공포 | 눈 크게, 땀 2픽셀, 입 벌어짐 |
| 30~10 | 공황 | 눈 흔들림 애니메이션 (2프레임 루프), 얼굴 떨림 |
| 10 이하 | 해리 | 눈이 초점 없이 허공. 깜빡임 중단 |

표정 전환은 즉각적이지 않다. 정신력 변화 후 **1.5초에 걸쳐 부드럽게 전환**. 플레이어가 얼굴을 보며 자연스럽게 감정 이입하게 된다.

**얼굴의 선행 반응**: 괴물이 임박 단계에 진입하면 플레이어가 포커싱 키를 누르기 전에 얼굴이 먼저 공황 표정으로 바뀐다. 경보이자 공포 연출.

> 정신력 → 화면 VHS 효과 상세는 [07-vhs.md](07-vhs.md) 참조. 룸미러 UI 동작은 [08-monster-chase.md](08-monster-chase.md) 참조.

|--------|---------|--------------------------|
| 기름통 1통 | 1칸 (10L) | — |
| 담배 1개 | 1칸 | — |
| 잡품 | 1칸/개 | — |
