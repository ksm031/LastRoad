# 13. 사운드 디자인

## 음악 방향

음악 없음이 기본. 엔진 소리와 라디오만 존재. 침묵이 공포다.

## 라디오 사운드

| 채널 | 음악 장르 | 레퍼런스 분위기 |
|------|---------|-------------|
| 일반 주파수 | 새벽 FM 라디오 | 실제 새벽 라디오 방송 톤 |
| 죽음의 주파수 | 단조 찬송가, 단음 반복, 숫자 낭독, 거꾸로 재생 파편 | 그레고리안 찬트 + 숫자 방송 혼합 |

> 라디오 채널의 게임플레이 효과는 [11-narrative.md](11-narrative.md) 참조.

## 효과음 카테고리

| 카테고리 | 예시 |
|---------|------|
| 엔진 | 속도별 RPM 변화, 손상 시 노킹음, 구동계 고장 시 마찰음 |
| 도로 | 포트홀 충격음, 풀숲 스치는 소리, 동물 사체 밟는 둔탁한 소리 |
| 타이어 | 정상 마찰음, 펑크 후 도로 마찰음(개수별 증폭), 펑크 발생 순간 파열음 |
| 적 충돌 | 와쳐(가벼운 둔탁), 러너(살점 부딪힘), 워커(둔중한 충격), 앰부서(금속 + 살점), 사슴머리(저주파 진동 + 채도 급락 SFX) |
| 컬트 | 갓길 컬트 — 존재 감지음 없음 (의도적 무음). 행렬 컬트 — 멀리서부터 들리는 단조 합창. 우두머리 — 저주파 드론 |
| 블러드 오브 | 오브 흡수 시 짧은 고주파 "팅" + 진홍색 펄스. 적 충돌 시 같은 톤의 더 짧은 변주 |
| 정신력 연출 | 정신력 하락 시 엔진음에 왜곡 필터. 저역 강조 |
| 환각 위협 | 일반 적과 동일 사운드 (구분 불가). 충돌 시 소멸 — 짧은 역재생 "쉭" 톤 |
| 운전자 | 혼잣말 (보이스 or 자막, TBD) |
| 와이퍼 | 1단 스윕음 (1.8초 주기), 2단 스윕음 (0.9초 주기) |
| 빗소리 | 루프. 비 오는 구간에서만 재생 |
| UI | ₩ 획득 — 종이 부스럭. BO 획득 — 진홍색 펄스 톤. 부적 효과 발동 — 부적별 고유 글리프 톤 |

## 타이어 펑크 사운드 상세

| 펑크 상태 | 사운드 |
|---------|-------|
| 1개 | "탕!" 파열음 → 도로 마찰음 1배 루프 + 한쪽 쏠림 시 갓길 풀 마찰 간헐 |
| 2개 같은 쪽 | 1개 사운드의 2배 음량, 강한 쏠림 마찰음 |
| 2개 대각선 | 좌우 진동음 (스테레오 패닝 좌우 교차) + 미세 떨림 톤 |
| 2개 앞·뒤 | 마찰음만 2배. 쏠림 없음. 충돌 시 차체 삐걱거리는 추가 톤 |
| 3개 이상 | 거의 멈춘 듯한 둔중한 마찰음. 림(휠) 긁히는 금속 톤 추가 |

## 구동계 고장 사운드

| 상태 | 사운드 |
|------|-------|
| 구동계 50% 이하 | 가속 시 미세한 마찰음 |
| 구동계 20% 이하 | 가속 시 명확한 마찰음 + 가끔 RPM 폭주음 (붉은 영역) |
| 구동계 0% (고장) | 지속 마찰음 + 30초마다 0.5초간 엔진 정지음 ("쿨럭") + 라디오 잡음 +50% 추가 |

## 컬트 행렬 사운드 상세

| 거리 | 사운드 |
|------|-------|
| 100m+ (시야 외) | 단조 합창 페이드 인. 가사 불분명, 저음 강조 |
| 50m~100m | 합창 명확화. 발 끌리는 소리 추가 |
| 0~50m (행렬 통과 중) | 합창 + 발 끌림 + 횡단 시 의식적 침묵 (가까울수록 합창 페이드 아웃) |
| 충돌 순간 | 합창 즉시 정지 + 둔탁한 충격음 + BO 흡수 톤 |

## 사슴머리 사운드

| 시점 | 사운드 |
|------|-------|
| 등장 (시야 진입) | 저주파 드론 (서브베이스 30Hz대) — 스피커 진동만 느껴짐 |
| 접근 중 | 드론 지속 + 라디오에 간섭 노이즈 |
| 통과 순간 | 짧은 무음 (0.2초) → 채도 급락 SFX (필터 스윕) |
| 통과 후 | 백미러 응시 시 미세 드론 잔존 |

## 다이내믹 오디오 규칙

- 정신력 50 이하: 엔진음에 왜곡 필터 추가
- 정신력 20 이하: 라디오와 엔진음이 혼합되어 뭐가 뭔지 불분명해짐
- 기름 15% 이하: 엔진 헛돌음 사운드 간헐적 재생
- 구동계 0%: 라디오 잡음 +50% (전기 시스템 간섭)
- 펑크 2개 대각선: 스테레오 좌우 교차 진동음 → 멀미 유도

## BO/₩ 사운드 디자인 원칙

두 재화는 사운드 톤이 명확히 구분되어야 한다. 현금은 일상의 소리(종이), BO는 비일상의 소리(고주파 글리프). 화면을 보지 않아도 어느 재화를 얻었는지 청각만으로 알 수 있도록.

| 재화 | 획득 톤 | 소모 톤 |
|------|--------|--------|
| ₩ | 종이 부스럭 + 가벼운 동전 짤랑 | 짧은 종이 찢김 |
| BO | 고주파 "팅" + 진홍 펄스 (0.15초) | 둔탁한 흡수음 + 미세 잔향 |
