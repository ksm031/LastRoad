# 13. 사운드 디자인

## 음악 방향

음악 없음이 기본. 엔진 소리와 라디오만 존재. 침묵이 공포다.

## 라디오 사운드

| 채널 | 음악 장르 | 레퍼런스 분위기 |
|------|---------|-------------|
| 정상 채널 | 새벽 FM 라디오 | 실제 새벽 라디오 방송 톤 |
| 잡음 채널 | 화이트 노이즈 + 필터링된 목소리 | 숫자 방송, 수신 불량 |
| 컬트 채널 | 단조 찬송가, 단음 반복 | 그레고리안 찬트 계열 |

> 라디오 채널의 게임플레이 효과는 [11-narrative.md](11-narrative.md) 참조.

## 효과음 카테고리

| 카테고리 | 예시 |
|---------|------|
| 엔진 | 속도별 RPM 변화, 손상 시 노킹음 |
| 도로 | 포트홀 충격음, 풀숲 스치는 소리 |
| 컬트 | 존재 감지음 없음 (의도적 무음), 접촉 시 저음 충격 |
| VHS | 테이프 노이즈, 글리치 사운드 |
| 운전자 | 혼잣말 (보이스 or 자막, TBD) |
| 와이퍼 | 1단 스윕음 (1.8초 주기), 2단 스윕음 (0.9초 주기), 고장 시 삐걱임 |
| 빗소리 | 루프. 비 오는 구간에서만 재생 |

## 다이내믹 오디오 규칙

- 정신력 50 이하: 엔진음에 왜곡 필터 추가
- 정신력 20 이하: 라디오와 엔진음이 혼합되어 뭐가 뭔지 불분명해짐
- 기름 15% 이하: 엔진 헛돌음 사운드 간헐적 재생
